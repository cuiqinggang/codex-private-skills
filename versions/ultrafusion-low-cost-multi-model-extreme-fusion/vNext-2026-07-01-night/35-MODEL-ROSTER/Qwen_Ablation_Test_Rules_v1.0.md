# Qwen3.5-Flash 消融测试规则 v1.0

## 测试目的

通过对比实验决定 Qwen3.5-Flash 是否值得进入默认阵容。

## 测试设计

同一问题跑两套流程：

### 流程 A：Core-3
GPT + DeepSeek-V4-Pro + MiniMax-M2.7

### 流程 B：Core-3 + Qwen
GPT + DeepSeek-V4-Pro + MiniMax-M2.7 + Qwen3.5-Flash

## 比较指标

1. D_Final 最终分数是否提升
2. 扣分项是否减少
3. Qwen 是否提供独有有效事实
4. Qwen 是否发现其他模型遗漏的反例
5. Qwen 是否修复逻辑断点
6. Qwen 是否改善结构
7. Qwen 是否引入幻觉、重复、浅层噪声
8. C 层是否需要花大量成本排除 Qwen 低质量内容

## 保留条件（满足任一即可）

1. 6 题中至少 2 题提供独有有效贡献
2. 平均 D_Final 分数提升 ≥ 1.5 分
3. 至少 1 次发现其他主力模型遗漏的关键事实或反例
4. 没有明显增加 C 层噪声
5. 性价比明显优于其他替补模型

## 剔除条件（满足任一即剔除）

1. 平均 D_Final 分数提升 < 1 分
2. 6 题中 5 题没有独立贡献
3. 经常输出浅层、重复、常识性内容
4. 引入明显幻觉或弱证据强结论
5. C 层需要经常排除 Qwen 低质量内容

## 任务路由修正

如果 Qwen 在某类任务有效、某类无效，不一刀切：
- 简单资料粗筛：可启用 Qwen
- 长上下文低成本粗读：可启用 Qwen
- 高风险医学/法律/金融：默认不启用
- 复杂深度推理：默认不启用
