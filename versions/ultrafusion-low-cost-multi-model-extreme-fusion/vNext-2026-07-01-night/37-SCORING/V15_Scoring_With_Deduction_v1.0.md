# V15 评分 + 扣分体系 v1.0

## 基础评分公式

```
FinalScore = V15_BaseScore − DeductionPoints + UniqueContributionBonus
```

## V15 四维 BaseScore

| 维度 | 权重 | 满分 | 评分标准 |
|------|------|------|----------|
| 准确 | 40% | 100 | 事实正确、引用准确、无幻觉 |
| 完备 | 25% | 100 | 覆盖所有关键维度 |
| 结构 | 20% | 100 | 逻辑清晰、可执行 |
| 深度 | 15% | 100 | 分析透彻、洞察独到 |

BaseScore = 准确×0.4 + 完备×0.25 + 结构×0.2 + 深度×0.15

## 总分等级

| 分数 | 等级 |
|------|------|
| ≥95 | A+ 卓越 |
| 90-94 | A 优秀 |
| 85-89 | B+ 良好 |
| 80-84 | B 合格 |
| 70-79 | C 可接受 |
| <70 | D 不合格/需重做 |

## 评分流程

1. 各模型独立输出
2. C 层融合后自评
3. D 层终审评分
4. 输出 D_Final 含评分明细
