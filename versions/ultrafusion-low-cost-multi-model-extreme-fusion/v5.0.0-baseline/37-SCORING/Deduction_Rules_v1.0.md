# 扣分细则 v1.0

## 扣分表

| 扣分项 | 扣分范围 | 触发条件 |
|--------|----------|----------|
| 关键事实错误 | −15 到 −40 | 可核查的事实性错误 |
| 编造具体数据/标准号/文献编号 | −20 到 −50 | 明显编造或无法溯源 |
| 幻觉引用或虚假来源 | −30 到 −60 | 引用的来源不存在 |
| 弱证据写成强结论 | −10 到 −25 | 推断当事实 |
| 没有回答用户核心问题 | −15 到 −40 | 偏题或偷换概念 |
| 逻辑链跳步明显 | −10 到 −25 | 中间推理缺失 |
| 前后矛盾 | −10 到 −30 | 同一答案内矛盾 |
| 重复啰嗦、凑字数 | −5 到 −15 | 同义反复无新信息 |
| 结构混乱、无法执行 | −10 到 −25 | 用户无法按此操作 |
| 忽略重要限制条件 | −10 到 −30 | 用户明确限定被忽略 |
| 医疗/法律/金融强结论无提醒 | −30 到 −70 | 高风险领域缺免责 |
| 模板执行失败 | −10 到 −30 | V15 格式要求未满足 |
| 拒答但未说明替代路径 | −10 到 −20 | 拒答但未给方向 |
| 输出截断未提示继续 | −5 到 −15 | 截断未标注 |

## 硬失败条件（直接 FAIL）

1. **伪造缺失模型回答** — 编造未参与的模型输出
2. **伪造引用、数据、标准** — 编造文献编号/标准号
3. **高风险问题给出危险强建议** — 可能导致严重后果
4. **关键事实错误且未修正** — 核查后仍有严重错误
5. **完全偏离用户问题** — 回答毫不相关
6. **观察位低质量答案被强行写入最终结论** — 未经融合的低质内容
7. **C 层未注入 V15** — 触发 UF_PROMPT_ASSEMBLY_FAIL
8. **D 层未注入 V15** — 触发 UF_PROMPT_ASSEMBLY_FAIL
9. **D 层没有执行陌生稿复检** — 缺少 counter-example testing
