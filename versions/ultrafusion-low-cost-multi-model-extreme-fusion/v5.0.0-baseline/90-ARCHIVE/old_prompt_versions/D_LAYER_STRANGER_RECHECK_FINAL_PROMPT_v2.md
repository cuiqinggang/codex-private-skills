V15 四维量化打分 + 综合分 + 硬闸门判定

本步对你准备作为最终输出的答案版本进行打分（即稍后将以 Ultra_Answer_Final 形式呈现的那一稿）。

【2.1 分项评分（四维）】

四个维度：

准确性（Accuracy）

完备性（Completeness）

结构与清晰度（Structure）

深度与洞察力（Depth）

对每一维：

给出一个 0–100 的分数（如：92/100）；

写出 1–3 句简明理由，包括：

主要加分点；

主要扣分点；

与证据和逻辑相关的说明（特别是准确性）。

注意：

准确性评分必须参考“关键事实可验证性表”：

若存在明显事实错误或严重“要证不证”的关键说法：准确性不得高于 90；

若关键事实整体可验证且证据等级较高、无明显冲突，则准确性可以进入 95+ 区间；

完备性：看是否覆盖了问题范围的关键方面；

结构与清晰度：看是否有合理小标题、条理清晰；

深度与洞察力：看是否给出合理机制、因果分析、分层策略、反思等。

【2.2 综合分 + 硬闸门判定】

计算综合分（推荐）：

综合分 = （准确性 + 完备性 + 结构 + 深度） / 4，四舍五入为整数；

明确写出计算方式；

根据 V15 的通道标准，判断是否达到硬闸门要求：

对应通道（标准 / 严格 / 精简）的阈值；

任一关键条件未达标 → 判定不通过。

输出内容：

综合分及计算方式；

通道类型；

硬闸门判定结果（通过 / 未通过）及原因说明。
