## 三、人工介入来源判定

判定顺序：读取原始动作证据 -> 确认所属任务和环节 -> 确认操作者 -> 记录次数 -> 再作验收分类。

不得仅凭 USER 消息角色、出现“粘贴”一词、模型自报数字、浏览器类型、页面标题、同一内容出现于两个窗口而认定人工操作。

自动化输入或粘贴不算人工；预先定义的正常首次任务提交不算中途接管；已受理后的人工转交、修复或推进必须依真实证据计入，不能事后改名为“首次提交”来豁免。

同一动作在多个窗口显示须按原始事件去重。缺少来源证据或证据相互矛盾时，写待核实；不得据此调用人工原因的 FAIL 路由。报告值与核验值分开保存，不能用报告摘要循环证明报告本身。

候选逻辑：skills/first-principles-physical-limit-convergence/runtime/acceptance_isolation_guard_v1.py。
回归：skills/first-principles-physical-limit-convergence/tests/test_acceptance_isolation_guard_v1.py。

调用方必须实际核查来源记录，才能填写 verified；代码本身不读取本机日志，也不能认证调用方提供的证据真假。接入正式回报与裁决入口之前，不得宣称已经在本机强制生效。
