# v5.3.1 可见真实用户旅程验收 R1

## 测试原则

本文件只定义“用户正常会提出的任务”和屏幕可见验收点，不预制 Reality Dispatch，不给状态机答案。

禁止：
- 从测试脚本或 Python 函数入口开始；
- 预先复制一条 Codex Reality 命令；
- 人工告诉 GPT “现在该 Freeze / 该进入实 / 该补时间”；
- 在失败后现场修正文并继续算 PASS。

## 用户正常任务

请使用整体闭环极限短时间引擎处理下面这个真实维护任务：

“检查当前私库中整体闭环极限短时间引擎的固定 current 入口是否仍指向最新正式可用版本；如果不是，在不改动历史 Freeze 的前提下做最小更新，并给出最终结果。”

这是正常维护任务，不包含状态码、测试字段、Freeze ID、Codex 命令或测试专用参数。

## 屏幕可见验收链

用户必须能在实际界面依次看到：

1. 用户原始自然语言任务；
2. GPT 的虚阶段分析/冻结结果；
3. 无用户提醒的自动 Freeze→实；
4. 完整 Codex CHAT 自然语言命令；
5. Codex 在真实仓库执行并返回结果；
6. GPT 根据返回结果自动完成最终收口。

## PASS

只有整条链真实发生，且任务本身被正确完成，才 PASS。

## FAIL

出现以下任一情况即 FAIL：
- GPT 停在 Freeze，等用户提醒；
- 只输出 Header，不输出完整 Codex 命令；
- 用户需要提醒补时间/补字段/继续；
- 测试器通过隐藏函数直接推进状态；
- Codex 未真正执行业务任务；
- 最终任务结果错误；
- 失败后现场修复后继续算同轮 PASS。
