# v4.x → v5.0 规则归约

## 保留
- 唯一目标 min(T_VALID)
- 只有虚、实
- Reality Foundation是虚阶段事实输入，不是第三步
- 成熟方案优先；未知事实最低成本取得
- 虚冻结唯一方案与任务T*
- 实只执行、计时、验证
- Reality Delta回虚
- 一Freeze一次REAL
- 每代最多6次，第6次失败换代
- 结构性错误可提前换代
- 虚→实原子交付
- 现实入口与执行器能力分离
- 现实结果必须有真实时间和证据一致性

## 合并
原来的大量“必须/禁止/注意”合并为：
状态字段、唯一转换表、虚→实门、REAL PASS门、FAIL回虚门、适配器策略。

## 从v5运行时删除
历史版本解释文字、重复自然语言门禁、GPT手写定位首行、历史单次工具故障、把GitHub/浏览器/GPU/JEV等实现当顶层步骤。

v4.x继续保留为Git历史和演化证据，但v5运行不读取。

## 架构变化
过去：AI理解规则 -> AI决定是否遵守。
现在：AI产生候选结果 -> 状态机决定是否允许发生。
