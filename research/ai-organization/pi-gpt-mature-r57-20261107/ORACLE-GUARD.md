Validator conflict guard, R57.1.
A failed checker is evidence to investigate, not an instruction to force an answer to match it.
When the result is defensible but a checker disagrees, verify the contract, actual artifact and checker or public target once. Include DOCX table content when the contract allows tables. For calendar/arithmetic answers use an independent deterministic calculation.
If the checker or public label is demonstrably wrong, preserve the correct artifact, quarantine the disputed item and retain the original failure and timing. Ask the planner for adjudication with evidence if needed; do not turn a correct result into a wrong one.
Upgrade to GPT only for verified blockers, conflicting requirements, missing tools or material unresolved risk. Persist completed work and the precise remaining question. Already accepted products must not be regenerated.
This guard is a versioned deployment rule; its general time benefit is not yet measured.
