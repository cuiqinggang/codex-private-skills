# Remotion 输出要求 v1.6

## 基本规格
- 画幅：竖屏 9:16
- 分辨率：1080×1920
- 帧率：30fps
- 总时长：15秒 / 450帧

## 实现方式建议
1. 以 30 张关键帧为主视觉素材。
2. 每张图按 `timeline_v1.6.csv` 对应秒点进入。
3. 采用轻微 Ken Burns：scale 1.0→1.04、局部平移、少量裁切。
4. 切换方式以硬切、快切、轻微交叉淡入为主，不做花哨转场。
5. AI UI 高亮可以在 Remotion 中叠加少量 glow/line/callout，但不得遮挡人物视线逻辑。
6. 号码落版不得添加广告口号，只保留锁定两行文字。

## 验收输出
- `npm run dev` 可预览。
- 能导出 mp4 或至少给出 render 命令。
- 生成 `report.md`。
