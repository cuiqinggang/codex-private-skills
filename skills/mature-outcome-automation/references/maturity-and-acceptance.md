# 成熟依据与首次联通验收

资料核查日期：2026-09-08。以下是原始成熟模式/协议，不代表存在与你全部组件完全一致、无需适配的一键产品。本技能是这些模式在现有组件上的轻量配置尝试；没有复制或部署新工作流引擎。

| 成熟来源 | 可复用能力 | 当前处理 |
|---|---|---|
| [Anthropic Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) | 路由、主控与工作者、评价反馈；复杂度按需增加 | 采用简单组合方式；不绑定其模型或服务 |
| [Agent Client Protocol](https://agentclientprotocol.com/get-started/introduction) | 兼容客户端和编码智能体间标准通信 | 只复用目标环境已有 ACP；它不是网页 GPT 通用接口 |
| [LangGraph Persistence](https://docs.langchain.com/oss/python/langgraph/persistence) | 检查点及中断恢复 | 已有系统缺少可靠恢复时的成熟候选；本试行版不新增其依赖 |

0.2.0 已明确绑定用户指定的资源总调度与专用浏览器，按任务检索使用 find-skills；详见 components.md。公开模式参考不替代现成组件。

## 首次验证范围

先发现目标机现有专用浏览器、路由器、代理入口和技能版本，读必要说明；不全盘扫描、不重装成熟组件。新流程用可逆测试任务及独立测试目录，不修改生产设置。

| 场景 | 应验证的实际成果 | 不能替代它的证据 |
|---|---|---|
| 现成组件分工 | 调度由资源总调度负责、联网使用专用封装、缺口检索用 find-skills、编写命令使用一次质量门禁 | 新造第二套路由或审核器 |
| 简单路线 | 已知成熟技能完成小任务，产物与输入匹配 | 只打印“成功” |
| 网页完整往返 | 专用浏览器发送完整规则及任务，读回完整方案；本地按方案产出可验证结果 | 打开网页、看到输入框、ACK 单项 |
| 经济路线 | 实际可用 DeepSeek/其他代理收到任务并返回可用结果 | 配置写了模型名 |
| 单次命令审核 | 同一执行版本存在一次真实审核；执行端只核对新事实 | 多份自评或只有固定声明 |
| 恢复与重复防护 | 模拟失去回执后按原任务号查回结果，没有重复发送/写入 | 只重复打印相同任务号 |
| 缺失路线 | 一条路线不可用时，已授权替代路线仍达同一验收，或准确呈现有限阻塞 | 把失败改写通过 |
| 按需观察 | 默认自动推进；用户询问能读到目标、简洁依据、实测和下一动作；无需回复放行 | 强制先展示表格或等用户确认 |
| ECC（条件项） | 真需要长任务时按实际版本和真实独立角色完成验收 | 普通任务硬启动 ECC |

判定只覆盖实际跑过的路线；未跑写未测。模拟测试不能记为用户电脑端到端通过。一次主路径实测通过标“该路径试运行通过”；全部必需路径与恢复实测后才标整体联通通过。
