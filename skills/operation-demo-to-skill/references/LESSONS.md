# 可执行经验与检查清单

材料：任务合同、上游固定提交的录制/总结实现、本轮独立 JSONL 与实测失败。价值判断符合减少重复错误、形成 SOP、形成可验证模板、改善长期工作流四项，进入技能固化。

1. 自检也可能采集敏感信息。假 pynput 不会禁用真实 mss/window polling；严格无敏感测试必须同时替换输入、窗口、截图、AX。保留真实引擎的事件队列、JPEG 写入和 STOP 逻辑。
2. Windows 不提供 rm。自检临时目录用 shutil.rmtree，打印最终 PASS 放在清理成功之后；调用者证据目录保留且不覆盖。
3. 输出箭头和中文不能依赖系统码页。Python 入口/子进程明确 UTF-8，摘要 capture_output 明确 encoding。环境只在子进程生效。
4. PASS 文字不是验收。收集真实退出码、断言、原始事件、输出文件和墙钟数据；所有模拟数据标记不能证明人类操作。
5. 文件演示应重现可观察结果。使用 stdlib 写文件/复制即可；不要为文件操作开发桌面自动化，禁止覆写既有目录。

SOP：确认授权及定位 → 复用预检 → 录制并完结 → 总结且读原始事件 → 提取意图/参数/验收 → 冻结候选 → 真实运行 → 回读哈希与输出 → 报告限制 → 追加使用日志。

本版只沉淀实际验证的 Windows 小修复与安全样例；未观测真实人类演示，也未实现自动 GPT API 链路。主控后续检查后才可决定发布。
