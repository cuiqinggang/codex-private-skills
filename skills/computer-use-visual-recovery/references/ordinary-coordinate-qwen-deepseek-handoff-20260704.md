## 复杂长题复制答案规则

复杂长题不能只看见回答。必须把答案复制回来，才算有意义：

```text
1. 提问前截图确认官网和输入框。
2. 粘贴复杂题并截图确认。
3. Enter 发送。
4. 等回答生成完成，截图确认答案落在下方。
5. 如果答案很长，滚动到可见复制按钮或答案区域。
6. 截图确认复制按钮 / 可复制区域。
7. 点击复制，或用普通人方式选中答案后 Ctrl+C。
8. 读取剪贴板或粘贴到本地证据文件，确认包含本轮唯一 marker。
9. 保存答案文本和截图路径。
```

## 归零规则

遇到以下情况不判断方法失败，只归零：

```text
标签页错了 -> 重新打开目标官网
页面被抢焦点 -> 重新激活 Chrome 并截图
输入框没焦点 -> 重新点击输入框并截图
输入框有残留 -> Ctrl+A / Backspace 清空并截图
旧会话干扰 -> 新对话并截图确认干净 composer
页面卡住 -> 刷新或重新打开官网并截图
边栏状态变了 -> 按新状态重新定坐标，不复用旧坐标
```

真正阻断只有：

```text

验证码
安全/权限/账号风险提示
服务不可用
网络断开
需要付费、授权、删除、发布等高风险确认
```
