# DeepSeek 普通人坐标截图法数据页

中文归属技能：**普通人坐标截图法**

用途：记录 DeepSeek 网页在不同可见状态下的轻量坐标数据。这里不建立单独大状态机，只保存经过截图验证的坐标、键盘等价动作、成功率、失败修正和证据路径。

## 通用操作法

```text
截图
识别当前页面状态
定位目标控件
记录当前状态下坐标
执行普通人动作
截图验收
成功则累计成功次数
失败则归一化状态并更新失败修正
```

## 明日验收计划

```text
1. 打开 DeepSeek 官网。
2. 截图确认登录和可输入状态。
3. 记录输入框坐标。
4. 粘贴简单题并截图确认。
5. Enter 或点击可见发送按钮。
6. 截图确认回答。
7. 简单题 10 轮。
8. 复杂短答 10 轮。
9. 写入成功率、失败修正、证据路径。
```

## PASS 标准

```text
简单题：10/10 截图看到正确回答。
复杂短答：10/10 截图看到唯一 marker。
成熟坐标：同一页面状态下坐标稳定；状态变化通过截图重新定位。
```
