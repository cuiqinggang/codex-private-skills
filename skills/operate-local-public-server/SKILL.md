# 本机服务器与文件分享 V1.0

版本：1.0，2026-10-29，Asia/Shanghai。独立封装已部署的 Copyparty 与 Cloudflare 能力；软件分支原为 V2.0，本技能首次发布为 V1.0。复用原服务、原目录和原两个计划任务。

## 默认替用户操作

把用户一句话转成实际操作，不要求用户自己拖文件、复制命令或登录本机后台。优先文件操作和成熟程序接口；只有用户要验收网页交互时才使用浏览器。分享默认保留原文件。

| 用户说法 | 实际执行 | 给用户的结果 |
|---|---|---|
| 把某个文件给别人下载 | 定位指定文件，复制到公开分享区，核验公网读取 | 文件下载链接和一句可转发的话 |
| 下载地址是什么 | 读取当前运行状态；指定文件时读取并核验该文件链接 | 当前有效地址 |
| 启动/关闭服务器 | 调用原 start/stop；已运行时不重启 | 实际状态，启动后返回当前地址 |
| 我要自己拖文件 | 核对原生目录联接和读写，必要时 repair-controls | 明确「放文件」入口；不把公网页面当上传页 |
| 部署、修复或恢复 | 读取 references/deployment.md，沿用既有程序与检查点 | 已验证部分和必要边界 |

## 当前本机与执行顺序

Windows 根目录：`C:\AI\Public-Server`。按当前 `gpt-windows-execution-bridge` 先读取规则、动态发现 A=Remote Desktop Commander 在线设备、执行无副作用探针；A 成功后全程用 A。不要沿用离线设备 ID，不切换 B/C 规避程序错误。同一实例只由一位执行者控制，普通连续步骤在本机批量执行。

1. 通过 A 检查 `public_server.py status` 及 `config.json` 的引擎、target。当前文件服务应为 `origin_engine=copyparty`、`target=http://[::1]:18780`。已运行则直接复用；用户要分享而服务停止时按授权启动原任务，勿重建部署。
2. 用户指定文件时在相关目录定位，核对唯一文件和明确公开范围。只有路径确实缺失或多项无法区分时才问一个必要问题。不把整个桌面、配置、私有卷或工作目录公开。
3. 确认本机具有与技能一致的 `share_file.py`；缺失时仅部署这个操作助手，不重装服务。用结构化参数或 Python argv 调用，避开多层 PowerShell 引号。中文脚本用 UTF-8；PowerShell 文件用 UTF-8 BOM。
4. 执行 `share_file.py --source <Windows绝对文件路径>`；需要独立文件名时附 `--name <文件名>`。助手使用标准文件复制/原子改名，原文件保留；同内容可复用。默认文件名遇到不同内容时自动加摘要后缀；明确指定的文件名发生冲突则拒绝覆盖，选择另一个合适的新名称再操作。出现已发布未验证状态时沿原路径核账，不换名重发。
5. 读取真实结果：小文件核对完整公网字节摘要，大文件核对长度与首尾 Range 样本，按返回的验证范围表述。只有 VERIFIED 才说“已分享并验证”。网址每次从当前状态读取，不复用历史域名。
6. 默认只返回下载链接和 `copy_text` 给用户。用户自己转发即可；没有明确收件人、渠道和发送授权，不调用邮件、聊天或社交工具代发。不要声称技能本身已通知他人。

```text
python C:\AI\Public-Server\public_server.py status
python C:\AI\Public-Server\public_server.py start
python C:\AI\Public-Server\public_server.py stop
python C:\AI\Public-Server\public_server.py repair-controls
python C:\AI\Public-Server\share_file.py --source "C:\用户指定的文件.pdf"
```

## 固定边界

- `shared` 为明确公开文件区，`public` 为网站展示区，`private` 是私有卷。密码/有效期分享沿用上游功能，先按部署文档核验；不要将私有文件复制成匿名公开文件。
- 本机管理走 `http://127.0.0.1:18780/download/`，免登录；公网访客只读。隧道必须走 IPv6 `::1`，绝不能指向具备自动管理权限的 IPv4 18780。禁止公开 metrics、18782 预检、MCP、SSH、系统管理或浏览器调试端口。
- 给别人下载的网页不能接收上传。本机文件操作、Windows 鼠标拖拽、网页鼠标拖拽、HTTP 上传分别描述，不互相替代验收。
- 不安装第二套服务、调度或浏览器，不更改系统代理、DNS、路由器、电源策略或无关任务。技能被调用不等于离线持续执行；现有服务由 Windows 任务计划运行，AI 代操作仍需连接在线。
- 关机、睡眠、断网时暂停；临时网址会变化。新增软件/穿透订阅为 0，电费、宽带及维护成本未计量；长期 SLA、整机重启、新电脑和独立手机异网访问未认证。

部署与恢复读 [部署配方](references/deployment.md)；历史证据读 [验收边界](references/acceptance.md)。需要查看原部署实现时直接读取附带的脚本，不现场重写同类上传、下载或账号系统。
