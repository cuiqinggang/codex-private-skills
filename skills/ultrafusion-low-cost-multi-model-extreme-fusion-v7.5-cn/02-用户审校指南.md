# 用户审校指南

## 1. 这个文件是干什么的

这份指南帮助你检查 V7.5 中文审校版是否忠实保留 V7.0，同时让你知道哪里能改、哪里不能随便改。

## 2. 哪些地方可以改

你可以改：

- 中文解释是否更贴近你的原始想法；
- 示例是否更好懂；
- 用户操作说明是否更清晰；
- 失败复盘里的中文名称、危害说明和修复建议；
- 审校指南和版本说明。

## 3. 哪些地方不能随便改

不要随便改：

- `COPY_START` / `COPY_END`；
- `Score_0` / `SCORE_FINAL` / `Gain`；
- `INVALID_CHAIN` / `EFFECTIVE_CHAIN`；
- V15 全量注入要求；
- A/B/C/D 层职责；
- C 层官方提示词要求；
- D 层 `FINAL_ANSWER FIRST`；
- 文件路径和模板文件名。

## 4. 看不懂英文状态码去哪里查

先查：

```text
00-中文总索引-文件名对照表.md
70-NOTES/V7.5中文失败复盘目录.md
```

## 5. 如何对照 V7.0

源目录是：

```text
C:\Users\A\.codex\skills\ultrafusion-low-cost-multi-model-extreme-fusion
```

新目录是：

```text
C:\Users\A\.codex\skills\ultrafusion-low-cost-multi-model-extreme-fusion-v7.5-cn
```

同名文件通常是一一对应关系。V7.5 中新增的中文说明文件会在总索引中标注。

## 6. 如何判断 B 层有没有退化

B 层必须产出新的完整增强答案。

如果 B 层只是在评论 A1/A2/A3 的优缺点，没有形成可直接阅读的增强版答案，就判定为：

```text
B_DEGRADATION_FAIL
```

## 7. 如何判断 C 层有没有简化

C 层必须使用官方 C prompt，并包含复检陌生稿规则、四维稠密融合、证据硬规则和逆向一致性检查。

如果 C 层只是把 B 层“总结一下”，就判定为：

```text
C_LAYER_SIMPLIFIED_PROMPT_USED
```

## 8. 如何判断 D 层有没有只评测不回答

D 层第一部分必须回答原问题，先给 `FINAL_ANSWER`。

如果 D 层只评价 UltraFusion 流程、只算分、只写验收报告，而没有先回答原问题，就判定为：

```text
D_META_EVALUATION_WITHOUT_FINAL_ANSWER
```

## 9. 如何判断 Gain 是否有效

看最终比较：

```text
Gain = SCORE_FINAL - Score_0
```

如果 `Gain < 2.0`，必须标记：

```text
INVALID_CHAIN
```

## 10. 如何把自己的原始中文版思想补进去

建议只补在中文说明、审校指南、失败复盘和版本说明中。

如果要改 V15、A/B/C/D 模板或 Gain 判定规则，先写入 `70-NOTES` 作为候选变更，再单独验收，不要直接改核心门禁。
