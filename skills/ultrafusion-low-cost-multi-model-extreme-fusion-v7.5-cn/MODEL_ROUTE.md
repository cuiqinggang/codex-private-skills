# UltraFusion Model Route vNext

## Core Principle

本技能包追求极限高质量与低成本，不追求模型数量越多越好。
核心流程优先使用官方网站、官方客户端、官方 Coding Plan、官方
Agent 产品。API 只作为自动化、批处理、备用路线，不作为极限答案
主路线。

## 正式核心三智能体

1. GPT 官网版
2. Kimi 官网会员版
3. GLM-5.2 / GLM Coding Plan

## GPT 官网版

职责：

- 总控
- 最终融合
- 最高质量判断
- 最终表达
- 最终验收

## Kimi 官网会员版

职责：

- 替代 DeepSeek 的复杂任务位
- Agent Swarm
- Deep Research
- 多智能体分群
- 多角色并行审查
- 大规模资料探索
- 复杂方案分支推演
- 极限答案增益测试

选择理由：

- Kimi 的核心差异性更强。
- 更适合极限答案。
- 更适合复杂任务。
- 更适合多角色、多分支、大规模探索。
- 比 Qwen 更能提供非重复能力。
- 比 DeepSeek 更适合正式使用，因为不需要拆成“快速联网 + 专家深思”两道流程。

## GLM-5.2 / GLM Coding Plan

职责：

- Coding Agent
- 技能包制作
- PPT
- 文档结构化生成
- 长程任务执行
- 工程化落地
- 自动化任务

接入路线：

- 不优先尝试 Codex 直连。
- 优先使用 Kilo / Claude Code 官方成熟接入。
- Codex 需要 GLM-5.2 结果时，通过文件、剪贴板、复制粘贴、坐标法取回。

## 备用模型

### Qwen / 通义千问

- 低成本综合联网备用。
- 文档、多模态、普通分析备用。
- 如果 Kimi 测试增分不足，则 Qwen 替代 Kimi 进入核心。

### DeepSeek

- 免费测试备用。
- 纯推理备用。
- 低成本反向审稿备用。
- 不作为正式核心。
- 原因是联网与深度思考割裂，正式使用流程太麻烦。

### MiniMax

- 音视频、创意、多模态备用。
- 不进入核心回答链。
