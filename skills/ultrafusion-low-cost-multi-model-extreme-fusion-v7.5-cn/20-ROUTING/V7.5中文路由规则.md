# V7.5 中文路由规则

## 路由标签

```text
UF_V7_5_CN_REVIEW
UF_V7_SEMI_AUTO_ABCD
```

中文解释：`UF_V7_5_CN_REVIEW` 表示中文审校版入口，`UF_V7_SEMI_AUTO_ABCD` 是保留的 V7.0 半自动 ABCD 执行路线。

## 两档路由

第一档：普通问题 -> GPT / ChatGPT 直答。

第二档：高价值或极限答案问题 -> 生成 GPT / DeepSeek / Qwen 半自动 ABCD 问题包。

## 升级前检查

- 是否真的需要多模型；
- 是否有足够时间执行复制粘贴；
- 是否需要审计记录；
- 是否愿意接受 `Gain < 2.0 -> INVALID_CHAIN` 的诚实失败。

## 不升级条件

如果普通答案已经足够好，或者用户只要快速结论，不启动 ABCD。
