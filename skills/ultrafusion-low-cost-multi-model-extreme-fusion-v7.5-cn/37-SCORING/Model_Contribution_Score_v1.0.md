# 模型贡献度评分 v1.0

## 独有贡献加分

| 贡献类型 | 加分范围 | 条件 |
|----------|----------|------|
| 发现其他模型遗漏的关键事实 | +5 到 +15 | 可核查，被采纳 |
| 提供有效反例 | +5 到 +15 | 逻辑有效，未被反驳 |
| 修复逻辑断点 | +5 到 +10 | 明确补全推理链 |
| 提供更好结构框架 | +3 到 +8 | 明显提升可读性 |
| 提供可执行路径 | +3 到 +8 | 直接可用 |
| 识别重要不确定性 | +3 到 +8 | 准确标注风险 |

## 贡献等级

| 得分 | 等级 |
|------|------|
| ≥15 | HERO — 本轮最有价值模型 |
| 5-14 | CONTRIBUTOR — 有实质贡献 |
| 0-4 | PARTICIPANT — 参与但无独有贡献 |
| <0 | DETRACTOR — 有损质量 |

## 记录方式

每个模型的贡献记录包含：
- 模型名
- 贡献项列表
- 总贡献分
- C_Fusion 中是否被采用
