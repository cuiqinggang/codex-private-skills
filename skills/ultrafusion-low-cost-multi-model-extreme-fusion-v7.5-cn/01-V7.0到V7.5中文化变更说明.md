# V7.0 到 V7.5 中文化变更说明

## 核心结论

V7.5 没有改变 V7.0 的核心逻辑。

本次变更只做三件事：

1. 中文化；
2. 解释化；
3. 可审校化。

## 没有改变的内容

- 没有删除任何关键门禁；
- 没有改变 ABCD 职责；
- 没有改变 `Gain = SCORE_FINAL - Score_0`；
- 没有改变 `Gain < 2.0 -> INVALID_CHAIN`；
- 没有删除 V15 全量注入要求；
- 没有把 B 层改成评论层；
- 没有把 C 层改成普通总结；
- 没有把 D 层改成只评测不回答。

## 保留英文的原因

英文文件名、状态码、协议字段和复制边界是机器识别入口。V7.5 保留这些英文，并在首次出现或索引处给中文解释，避免为了中文化破坏自动加载和验收。

## 与 V8 的边界

V7.5 不采用 V8.0 / V8.2 的极简压力链设计。V7.5 的核心仍然是 V7.0 半自动 ABCD 重型审计路线。
