# V7.5 中文失败复盘目录

本文件汇总 V7.5 中文审校版必须保留的失败模式。英文状态码保留，中文解释用于审校。

| 英文状态码 | 中文名称 | 发生原因 | 危害 | 检测方法 | 修复方法 |
|---|---|---|---|---|---|
| `V15_FULL_MISSING` | V15 全量缺失 | 问题包没有粘贴完整 V15 正文 | 层输出无效，质量门禁失效 | 搜索 V15 正文是否存在，检查是否只有占位符 | 重新装配该层问题包，注入完整 `10-SPEC/V15_FULL_WITH_GUARD_v1.0.md` |
| `C_LAYER_SIMPLIFIED_PROMPT_USED` | C 层简化提示词 | C 层使用普通总结或短提示词 | C 层失去官方融合能力 | 检查是否包含复检陌生稿、四维稠密融合、证据规则 | 改用 `C_LAYER_OFFICIAL_FUSION_PROMPT_v20260706.md` |
| `D_HARD_COMMAND_TRIGGERED_REFUSAL` | D 层硬命令触发拒答 | 提示词措辞过硬或像越权命令 | 外部模型拒绝执行 | 查看模型是否输出拒答或安全说明 | 使用温和执行包装器，避免“你必须服从”等硬措辞 |
| `D_META_EVALUATION_WITHOUT_FINAL_ANSWER` | D 层只评测不回答 | D 层把任务理解成评估 UltraFusion，而不是回答原问题 | 用户拿不到最终答案 | 看第一部分是否回答原始问题 | 使用 `FINAL_ANSWER FIRST` 包装器重新生成 |
| `D_LAYER_V15_FULL_MISSING` | D 层缺少 V15 | D 包只用了包装器或 D 模板，没有完整 V15 | 最终答案没有 V15 质量约束 | 检查 D 包是否含完整 V15 | 重新装配 D 包：wrapper + 原问题 + V15 + D prompt + Score_0 + C_Fusion |
| `FINAL_ANSWER_TOO_THIN` | 最终答案过薄 | D 层答案只有摘要或原则 | 产出不可执行，Gain 虚高 | 检查是否有可复制模板、运行 schema、隐私 SOP、30 天计划 | 要求 D 层补齐生产深度内容 |
| `B_DEGRADATION_FAIL` | B 层退化 | B 层只评论 A 稿，没有生成增强答案 | 后续 C/D 输入质量不足 | 看 B 输出是否为完整独立答案 | 重新生成 B 层，明确“不是评审，是融合增强” |
| `COPY_PASTE_BOUNDARY_ERROR` | 复制边界错误 | 用户复制了说明文字或漏复制问题包 | 外部模型收到污染输入 | 检查是否只有一个外层 `[COPY_START]` / `[COPY_END]` | 重新给出干净复制块 |
| `EXTERNAL_MODEL_REFUSAL` | 外部模型拒答 | 外部模型安全策略、上下文过长或措辞触发拒绝 | 某层输入缺失 | 查看返回是否拒答、空答或绕开问题 | 降低硬命令、拆分包、换模型或标记该模型无效 |
| `TOKEN_TRUNCATION_RISK` | 截断风险 | V15 + 多稿 + 模板过长 | 后半段丢失，输出无效 | 检查模型是否提示长度限制或缺结尾 | 分层压缩输入材料，但不能压缩 V15 核心正文 |
```

## 复盘入口

任何 V7.5 运行失败时，先定位失败状态码，再只修复受影响层。不要额外增加 E 层，也不要为了掩盖低 Gain 改判成功。
