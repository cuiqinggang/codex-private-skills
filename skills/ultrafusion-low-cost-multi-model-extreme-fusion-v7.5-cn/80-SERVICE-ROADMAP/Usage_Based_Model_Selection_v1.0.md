# 基于用途的模型自动选择 v1.0

## 设计目标

根据任务类型自动选择最优模型组合，而非固定 Core-3。

## 任务分类

| 类型 | 推荐模型组合 | 理由 |
|------|-------------|------|
| 高风险医疗 | GPT + DeepSeek + Gemini | Gemini 医疗知识强 |
| 技术深度推理 | GPT + DeepSeek + Kimi | Kimi 长上下文 |
| 中文语境 | GPT + DeepSeek + GLM | GLM 中文理解 |
| 快速事实检查 | GPT only (D-Lite) | 简单场景 |
| 创意/发散 | GPT + MiniMax + Qwen | 多样性优先 |

## 选择逻辑

1. 元评审判定任务类型
2. 查表匹配模型组合
3. 检查模型可用性
4. 自动激活
