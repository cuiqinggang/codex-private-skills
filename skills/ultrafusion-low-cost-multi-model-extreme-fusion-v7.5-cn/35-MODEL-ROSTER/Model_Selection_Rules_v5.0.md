# 模型选择规则 vNext-2026-07-01-night

## vNext Core-3 固定规则

正式核心三智能体为：

1. GPT 官网版
2. Kimi 官网会员版
3. GLM-5.2 / GLM Coding Plan

核心流程优先使用官方网站、官方客户端、官方 Coding Plan、官方
Agent 产品。API 只作为自动化、批处理或备用路线。

## Kimi 固定/替换决策

Kimi 只用于复杂任务、极限答案、多智能体审查、大规模资料探索类任务，
不用简单问题测试。

评分维度：

- 正确性 25
- 深度 20
- 覆盖完整度 20
- 关键遗漏发现 15
- 多样性/新角度 10
- 可执行性 10

决策阈值：

- 平均提升 >= 8 分：固定进入极限模式。
- 平均提升 4-7 分：只在特定复杂任务中启用。
- 平均提升 < 4 分：Kimi 不固定使用，退回 Qwen 作为正式替代位。

## DeepSeek 降级规则

DeepSeek 不再作为正式核心。保留用途：

- 免费测试
- 纯推理备用
- 低成本反向审稿备用

需要联网时，DeepSeek 只能作为备用拆分流程：

1. 快速模式先联网搜索事实、链接、价格、规则、当前信息。
2. 把搜索结果输入专家/深度思考模式。
3. 专家模式负责深度推理、反驳、漏洞检查。
4. 最后交给 GPT 融合。

## GLM-5.2 接入选择规则

主路线：

```text
Kilo / Claude Code -> GLM Coding Plan -> GLM-5.2
```

Codex 直连 GLM-5.2 不作为主路线。只有在找到公开成熟成功案例、完整
教程、可复制配置，并且不需要自行摸索协议时才尝试。

## v5.0 历史规则

## Core-3 固定规则

Core-3 是 UltraFusion 的固定生产阵容：
- GPT, DeepSeek, MiniMax 在每一轮都参与
- 不存在"选哪个、不选哪个"——三个都跑
- 仅当某模型不可用时触发替补逻辑

## 替补触发条件

当主力模型出现以下状态时触发替补：
- ERROR：接口返回错误
- RATE_LIMITED：限流
- AUTH_FAILED：鉴权失败
- EMPTY：连续2次返回空

## 替补优先级

1. Kimi K2 → 首位替补
2. Gemini 2.5 Pro → 复杂推理替补
3. GLM-4.5 → 中文任务替补
4. 若前3均不可用 → D_Final 标注"受限融合"

## 自动禁用规则

以下情况自动禁用某模型本轮：
- 连续3次返回 EMPTY
- 连续2次返回 REFUSED
- AUTH_FAILED（立即禁用）
- 输出安全过滤（立即禁用）
