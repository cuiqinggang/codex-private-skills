# Gate Status Template

Use this compact status block after every gate:

```text
Gate:
Status:
Inputs:
Outputs:
Contact sheet:
Videos:
Report:
Problems:
Next:
```

Allowed status words:

- `PASS`
- `ACCEPTED`
- `PASS_READY_FOR_VIDEO_TRANSITION_TEST`
- `PASS_READY_FOR_VIDEO_ASSEMBLY_TEST`
- `PASS_READY_FOR_SEGMENT_REVIEW`
- `PARTIAL_NEED_TARGETED_MIDFRAMES`
- `BLOCKED_DIMENSION_OR_ASPECT_ERROR`
- `BLOCKED_VIDEO_ASSEMBLY_ERROR`
