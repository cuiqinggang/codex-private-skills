## V1.0 模块
1. 全局总览：已派发/真实运行/完成/等待阻塞/真实失败，五项定义互不混淆。
2. 任务卡：TASK_ID、NODE_ID、负责人或执行器、阶段、最后心跳、证据链接、阻塞原因、下一动作。
3. 状态机：QUEUED、RUNNING、WAITING、BLOCKED、FAILED、VERIFYING、FROZEN、DONE；显示名称附中文。
4. 事件日志：任务派发、开始、心跳、证据、失败、重试、冻结的时间线；保留原始时间。
5. 数据新鲜度：最新更新时间、源类型、超时/失联告警；离线缓存明确标记，禁止冒充实时。
6. 故障台：故障计数独立标记，可与等待或失败重叠；在 UI 说明不能直接把五个计数相加。
7. 证据规则：DONE 必须有符合验收合同的真实执行及验证证据；仅有生成文件、日志或自述不能置为 DONE。
8. 数据适配：优先复用现有成熟 JSON/静态 HTML 与 GitHub 任务状态，按需补轻量同步，不引入 n8n。

## 优化顺序
