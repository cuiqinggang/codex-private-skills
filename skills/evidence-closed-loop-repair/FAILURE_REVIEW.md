# 失败复盘入口

出现以下任一情况时，在本文件追加一条记录，并立即停止发布：

- Required 未达到 100%；
- Forbidden 残留大于 0；
- 锁定文件哈希变化；
- 镜像或派生关系不成立；
- Bad fixture 意外通过；
- 最终包未在全新目录冷启动复核；
- 7z 未验证却被写成 PASS；
- 真实运行质量没有证据却被写成已完成。

每条复盘至少记录：日期、任务、失败 Gate、根因、受影响产物、修复动作、回归证据、下一次开工前检查项。
