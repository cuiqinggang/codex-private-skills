# Karpathy Coding Principles Skill Pack v0.1

这是爱马仕 + GPT Plus 超级大脑体系下的编程任务专用规则包。

## 核心口令

```text
先想清楚，少写代码，只改必要，验证通过。
```

## 四个原则

1. 编码前思考：不假设，不隐藏不确定性，必要时说明假设和权衡。
2. 简单优先：用最少代码解决问题，不做过度设计。
3. 精准修改：只改必要部分，不乱动无关代码。
4. 目标驱动执行：定义成功标准，循环验证直到达成。

## 与 gpt-plus-superbrain v0.2 的关系

本 Skill 是 `gpt-plus-superbrain v0.2` 的编程子规则。

使用顺序：

```text
先加载 gpt-plus-superbrain v0.2
再加载 karpathy-coding-principles v0.1
```
