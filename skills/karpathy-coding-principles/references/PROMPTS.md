# PROMPTS

## 1. 每次编程任务启动口令

```text
请先加载并遵守：
1. 《GPT Plus 网页作为爱马仕超级大脑的使用原则》；
2. 《Karpathy 编程原则 / karpathy-coding-principles》。

本任务是编程/代码/调试任务，必须遵守以下四条：
1. 编码前思考：不假设，不隐藏不确定性，必要时说明假设和权衡。
2. 简单优先：用最少代码解决问题，不做过度设计。
3. 精准修改：只改必要部分，不乱动无关代码。
4. 目标驱动执行：定义成功标准，循环验证直到达成。

请先回报：
KARPATHY_CODING_RULE_LOADED
然后开始执行任务。
```
