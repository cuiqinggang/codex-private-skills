# Product PM Planning Pack

## Purpose

Convert vague product ideas into structured execution material.

## Suitable Tasks

- PRD
- user persona
- user journey
- function list
- MVP definition
- stage roadmap
- dashboard module planning
- feature priority
- acceptance criteria
- task template mounting plan

## Required Structure

For every product planning task, produce:

1. Product goal
2. Target users
3. Core user scenarios
4. Main modules
5. Data / knowledge objects
6. User path
7. MVP boundary
8. Future expansion boundary
9. Acceptance checklist
10. Codex implementation handoff

## AI Company OS Special Rules

For AI Company OS / Obsidian Knowledge OS projects, always consider:

- 今日焦点
- Todo
- 活跃项目
- 知识库健康
- 技能索引
- 视觉证据
- 回传包
- GPT Gate Review
- 旧资产复用
- 阶段熔断点

## Output Requirement

The output must be practical enough for Codex to execute, not just a conceptual product document.
