# 交接给爱马仕

请把下面这个技能包保存到 Hermes 可复用技能库中。

技能包路径：
H:\Hermes_Skills\爱马仕大模型接入调试昨日重现技能包\SKILL.md

参考案例：
H:\Hermes_Skills\爱马仕大模型接入调试昨日重现技能包\references\七牛Claude4.7Opus接入Hermes成功案例.md

用途：
以后把第三方大模型接入 Hermes worker 时，先加载这个技能包。

必须按以下顺序执行：
1. API 预检。
2. WSL 代理排查。
3. Hermes profile clone。
4. provider 适配。
5. gateway 启动。
6. chat 标记验收。

本次最重要结论：
provider=openai 不可用。
provider=openrouter 会跑到 OpenRouter 官方 endpoint。
provider=deepseek 可以成功接七牛 Claude 4.7 Opus。
WSL 旧代理 192.168.128.1:17890 会导致超时。
判断成功不能只看 gateway running，必须看 chat 是否返回指定标记。
