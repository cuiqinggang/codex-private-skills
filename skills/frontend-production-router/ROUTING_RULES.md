# Routing Rules

| Input/intent | Route | Order |
|---|---|---|
| Live URL and exact authorized recreation | clone-existing-website | clone skill -> visual gate |
| Screenshot/mockup recreation | screenshot-to-page | clone skill -> visual gate |
| Written new-product brief | new-product-design | design router -> normal frontend build |
| Reference site, but not a copy | clone-and-originalize | clone analysis -> design router -> new implementation -> visual gate |
| High-fidelity first page plus future pages | clone-and-originalize | clone first page -> design router token normalization -> DESIGN.md -> extensions |
| Existing project is visually inconsistent | redesign-existing-project | design router -> guarded refactor -> visual gate |
| Review only | visual-quality-review | matched screenshots -> accessibility/consistency report |

Exact clone requires ownership or permission. Any original-product route strips brand assets and source copy. Missing or ambiguous evidence blocks similarity claims.
