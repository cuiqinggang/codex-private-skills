# Frontend Skills Relationship

- Existing clone skill (`indie-site-reference-factory`): recreates frontend pages from an authorized URL, screenshots, or existing page and supplies staged visual evidence.
- `ui-design-system-router`: creates project-level design rules, `DESIGN.md`, originality constraints, and long-term multi-page consistency.
- `frontend-production-router`: identifies task type, chooses call order, transfers artifacts, prevents cycles/duplicates, and executes final acceptance.

They are not substitutes: clone layer + design-system layer + orchestration/acceptance layer.
