# Skill Integration And Memory

Use when the user asks to preserve a workflow, add a method to a skill, or
convert a repeated video task into a reusable package.

## Integration Rules

- Preserve old skills.
- Add new references rather than overwriting older accepted records.
- Mark superseded approaches clearly.
- Record the accepted output path, source assets, excluded assets, music, codec,
  dimensions, duration, and verification checks.
- If the method belongs to an existing skill, update that skill's reference
  instead of only writing a new standalone note.

## Where To Store

- General video routing:
  `H:\AI\skills\video-production-and-editing-adaptive-skill`
- ComfyUI/Wan video generation:
  `H:\AI\skills\comfyui-aaki-v3-video-baseline`
- PPT/image showcase:
  `C:\Users\A\.codex\skills\ppt-showcase-video`
- AI free material promotion video/copy:
  `C:\Users\A\.codex\skills\ai-learning-material-pack`

## Record Format

Every saved method should include:

- date
- user-facing goal
- accepted output path
- source path(s)
- excluded path(s), if any
- audio/music choice
- visual style
- exact constraints from the user
- verification evidence
- what to avoid next time
