# 材料价值判断规则

## 高价值材料判定

材料满足以下任意 3 条，即判定为高价值材料：

1. 能减少 Codex 重复犯错。
2. 能提升复杂任务执行质量。
3. 能形成 SOP。
4. 能形成规则。
5. 能形成项目模板。
6. 能改善用户长期工作流。
7. 能让 Codex 下次少问、多做、做得更稳定。
8. 能转化为自动检查项。
9. 能补充用户已有 AI Company / Obsidian / Codex / ECC 系统。
10. 用户明确说“以后要用上”“不要落灰”“部署好”。

## 低价值材料判定

如果材料只是临时信息、娱乐内容、一次性观点、没有可执行步骤，或不能转化为规则/SOP/checklist/template/script，则只归档，不进入技能包。

## 本次视频价值判断

本次视频属于高价值材料。

理由：

1. 它直接讨论 Codex 如何避免重复犯错。
2. 它要求把满意结果写入 Workspace / AGENTS.md / SOP。
3. 它能转化为长期规则和开工前检查。
4. 它能提升用户后续 Codex 任务质量。
5. 用户明确要求“部署以后要能用上，不能落灰”。

结论：必须沉淀为长期技能包，并纳入 Codex 启动前复用检查机制。
