# Versioning

采用语义版本，并把阶段成熟度映射到版本：

- `v1.0.0`：母技能、方法、阶梯、P0 Contract 与 P0 工具正式建立；P0 尚未完成。
- patch：同一 P 阶段的新测量、新外部证据、T_PHY 修订、局部实验/修复或性能纪录提升，例如 `1.0.1`。
- minor：某一 P 阶段真实达到 99 且 FREEZE。P0 对应 `v1.1.0`，P1 对应 `v1.2.0`，依次类推。
- major：整个基础图像、视频或 H3 生产体系发生经过验证的重大代际变化时才考虑。

任何新版本必须同时保留：

- `previous stable`：上一个已验证稳定版本。
- `fallback`：发生回归时可直接恢复的版本与命令。
- `archive`：不可变更的历史合同、证据和哈希清单。

不得删除旧成熟版本。没有真实阶段证据时不得因文档、脚本或静态验证升级 minor。

## 2026-10-30 用户指定整数升级补充

V2.0.0为用户要求的视觉参考与质量规则整数升级。包版本与P阶段认证分开：新增人物魅力、关键动作及情绪状态检查和带资格的参考库，可升级技能包；不据此声称阶段99、性能提速或正式成片通过。旧版本历史与回退证据不删除；性能阶段晋级仍遵守上方真实证据规则。
