# Freeze and Reopen Rules

## 99 门禁

99 表示当前真实条件下已基本穷尽仍能产生显著、稳定、低风险时间收益的现实可行路径。它不等于达到 `T_PHY` 的 99%，也不保证超过外部方案。

冻结前必须证明：TASK 未变化；CURRENT、EXTERNAL FRONTIER、T_PHY/T_PHY_RANGE 均有可审计证据；显著候选已逐项实测；不存在未解释的可比巨大外部收益；冻结版本可复现与恢复。必须记录 `T_99` 和 `PHYSICAL_GAP`。

## FREEZE

冻结清单至少包含版本、合同哈希、代码/工作流哈希、环境、计时原始证据、输出验证、回退版本、未关闭物理差距和重新打开条件。冻结后只读保存，下一阶段从它派生。

## REOPEN

只有以下证据可重开：新算法/kernel/模型/缓存/硬件或成熟项目显示显著稳定收益；依赖或核心代码变化使冻结证据失效；发现合同、计时或有效性证据错误；安全/稳定性门禁变化。

重开必须保留旧冻结版为 previous stable，创建新实验分支与 fallback，不得原地覆盖。失败实验回滚到冻结哈希。
