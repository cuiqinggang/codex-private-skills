# First-Principles Rules

- 固定 TASK 下唯一优化指标是 `TIME`，正式计时为 `T_END_TO_END`。
- 质量、成功、安全和稳定性是 `RESULT_VALIDITY_GATE`，不是第二套综合评分。
- TASK 变化即 `TIME=INVALID_RESULT`。
- `T_PHY` 或 `T_PHY_RANGE` 是唯一终极参照；外部成熟方案是现实证据和路径库。
- 99 是当前现实条件下的阶段收敛，不是物理极限；冻结后仍保留 `PHYSICAL_GAP`。
- 存在真正可比且显著更快的外部证据时，原则上不得封 99。
- 每轮只改变一个局部假设，真实运行后 KEEP 或 ROLLBACK。
- 新能力使用 `ΔT_STAGE`；数量级退化优先调查 `PATH_ARCHITECTURE_ERROR`。
