# Four-Column Integration

唯一方法依赖：`mature-replication-four-column` V4.0。

| 正式列 | 本技能记录 |
|---|---|
| `CURRENT` | 固定阶段 TASK 的真实 `T_END_TO_END`、分段时间、环境、次数和原始证据 |
| `EXTERNAL FRONTIER` | 可比外部时间、来源、硬件/软件/合同与可复制路径 |
| `FIRST-PRINCIPLES PHYSICAL TIME` | `T_PHY`/`T_PHY_RANGE`、不可避免步骤、计算式、假设与不确定性 |
| `ITERATIVE CONVERGENCE` | 单一局部假设、最小改动、前后实测、KEEP/ROLLBACK |

严格按顺序建立。前三列未完整时，第四列为 `LOCKED`。所有字段沿用 V4.0 正式含义，不在本技能定义第二套评分或替代方法。
