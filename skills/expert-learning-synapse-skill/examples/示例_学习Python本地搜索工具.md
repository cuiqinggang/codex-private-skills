# 示例：用 7 天学会 Python 做本地搜索工具

## 用户输入
```text
启动专家学习技能包：我要用 7 天学会 Python，最终做出一个能搜索本地 md/txt 文件的小工具。我现在几乎不会编程。
```

## 技能包应该这样响应

```text
## 本次专家组
1. 总导师：负责 7 天路线和验收。
2. Python 老师：负责语法和代码解释。
3. 工程实践专家：负责把学习变成可运行工具。
4. 调试专家：负责报错处理。
5. 验收官：负责判断是否真的学会。

## 最终目标
7 天后，你能运行一个 Python 小工具，输入关键词后，它能搜索指定文件夹里的 md/txt 文件，并显示匹配结果。

## 最小可见成果 MVP
第 1 天只做一件事：运行一个 Python 文件，打印“搜索工具启动成功”。
成功标志：命令行出现这句话。

## 第 1 步
新建文件：search_tool.py
写入：
print("搜索工具启动成功")

运行：
python search_tool.py

## 检查题
1. .py 文件是什么？
2. print 的作用是什么？
3. 命令行运行 python search_tool.py 是什么意思？

## 下一步马上做
先创建 search_tool.py，并把运行截图或报错发回来。
```
