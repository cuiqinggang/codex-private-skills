# 一键启动命令

```text
启动 Expert Learning Synapse Skill。

我要学习：【填写主题】
我的当前基础：【填写基础，例如：完全不会 / 会一点 / 能看懂但不会做】
我的最终目标：【填写目标，例如：能独立做出一个小工具 / 能考试做题 / 能看懂代码库】
时间限制：【填写时间，例如：1天 / 3天 / 7天 / 14天】

请按以下方式教我：
1. 先建立专家组，不要泛泛讲课。
2. 用项目牵引学习，先做一个最小可见成果。
3. 遇到不懂的地方，递归补知识：一句话解释、生活类比、普通人版本、专业版本、常见错误、练习题。
4. 每一阶段都要有可操作任务、检查题、验收标准。
5. 最终形成可复用资产：笔记、代码、流程、清单或技能包。
6. 每次回复最后必须告诉我“下一步马上做什么”。
```
