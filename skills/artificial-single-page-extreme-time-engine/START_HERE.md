# 自动化单页面极限短时间引擎｜统一入口（候选方案，未完成生产验收）

**唯一外部入口**：读取本文件，即可定位方法与具体任务。权威位置为 GitHub 仓库 `cuiqinggang/codex-private-skills` 的 `main` 分支，本目录。不得先搜索本机 C 盘。读取成功不等于工具已获得现实执行权限。

## 启动与权威读取

1. 首先读取本目录 `ENGINE.md`（总纲），然后 `BRAIN.md`（执行大脑）。
2. 新任务：由大脑生成专属《当前任务目标与正反约束 第1版》及《当前任务冻结状态 第1版》，明确用户可见目标和 FINAL_VALID。
3. 接续任务：按 `TASK_ID` 解析**该任务**实际记录的合同路径与最新已持久化冻结路径；先读任务合同、再读冻结，不能把任一其他任务的 F002 当成全局最新；不存在状态就不得声称已经恢复。
4. 仅在需要页面交接时读取 `NEW_PAGE_TEMPLATE.md`，使用其最小恢复信封。需要查询同类成熟实现或具体业务技能包时，按实际必要性读取对应文件。
5. 所有文件名路径从同一仓库、同一经过核验的方法提交读取；动态任务状态可使用较新的独立提交，但必须验证路径确实存在。标注实际读取的版本和提交，不以 `CURRENT` 字样猜测新旧。
6. 方法文件仅在方法规则实际改变时递增整数版本；合同仅在目标与约束改变时递增；冻结每次正式状态改变递增。总纲正文只维护读取协议，**不嵌入某个任务的动态状态**。建议另建机器可读索引作为最小适配，不得把它变成自研调度器或状态机。
7. 工具不存在、权限不足、网络离线或状态不一致时，明确 BLOCKED/UNKNOWN，并使用可验证的本地离线备份；不能默默退到旧版。

## 两路线独立探索（选型未验收）

- **A｜双层页面**：主控 CEO 与最少必要的 Executor 独立页面，适于隔离重执行、复杂并行和独立恢复的候选；任务节点 Freeze 后由 CEO 汇总。
- **B｜单页面**：在当前 CEO 页面内完成一个预算内的自然执行节点；规划、成熟复用、故障局部修复、STOP_GATE、Freeze 和必要的 Reality 都保持在同一页。复杂度、上下文健康与完整时间决定是否换页。**排除“卡点解决就宣告整任务完成”**：除真实阻塞或 FINAL_VALID 外，自动向下一合法节点推进。
- **不新增 C 实现**：以后如有经过完整成本/恢复/VALID 证据证明融合净收益为正，再考虑路线合并；A、B 的实验版本、证据和冻结互相隔离，勿改写共同的正式方法历史。
- **单页节点边界**：允许一个有效、顺畅的串行链或无资源冲突的并行组；规划预算、上下文风险、依赖和副作用决定节点大小。完成、失败或 UNKNOWN 均须保存真实状态。无法修复时冻结并恢复交接；可以修复时继续直到既定 DONE_WHEN，不以解决单个卡点冒充完成。
- **比较指标**：同一任务、同一环境、同一 VALID 边界记录 `T_BASE_REAL`、`T_VIRTUAL_BEST`、`DELTA_T`、`GAIN_PERCENT`、`SPEEDUP`，包含模型调用、读取、派发、交接、恢复、等待、维护等真实成本；缺数据不得宣布 VIRTUAL_MATURE/FINAL_VALID。

## 执行器是替换件，不是方法权威

ChatGPT / Dot、Codex、n8n、Playwright MCP、Windows 双路执行桥均可在**获得实际工具权限**后执行获授权部分。Dot 适于对话型连续任务，Codex 适于代码和可验证终端工作，n8n 适于持久编排与事件触发。是否能自动读取私有 GitHub、访问本地设备、继续跨页运行和保存状态必须逐执行器验收；不能因工具名称宣称具备该能力。Windows 桥作为重要可选连接件，独立技能包继续维护，入口仅引用它，不复制实现。
