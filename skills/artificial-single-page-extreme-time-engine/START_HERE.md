# 《自动化A/B极限短时间引擎》｜唯一启动说明

**对用户只有一个入口**：把任务交给 GPT，说“使用自动化A/B极限短时间引擎完成”。真正的任务规划与工具执行始终由 GPT 主导；本文件负责**定位版本、恢复任务状态、选择页面形态、自动推进**，不是把其它技能包正文全部合并在一起。

权威来源：`cuiqinggang/codex-private-skills` 的 `main` 分支，目录 `skills/artificial-single-page-extreme-time-engine/`。
唯一标准：`T*=min(T_VALID)`。不得先在C盘寻找网络权威技能包。读不到网络时仅可明确声明离线使用已核验提交的备份；不能假装已同步最新版本。

## 统一入口最短可执行协议

1. **从网络读取本入口**，确定用户原始实质目标和必要权限；若是 GPT 一次答复即可有效完成的超简单任务，直接完成，不额外启动工作流或强制建立多个状态文件。
2. 用户明确指定“自动化B”则直接B、指定“自动化A”则直接A；只有未指定路线才按同一有效结果的总体时间与风险初选。A（双层）读取固定 `routes/A/ROUTE.md`；B（单层）读取固定 `routes/B/ROUTE.md`。B当前路线自身规定直接用本用户原ChatGPT浏览器的新聊天作接续，不启用A的专用浏览器或n8n默认编排。**版本号只以该 ROUTE 指向的实际版本文件和版本头为准**，不在本入口每次重复填写版本、Freeze号。每次任务启动/换页重新取当前网络指针；版本路径不存在或链不一致则停止并标记 VERSION_MISMATCH。
3. **按所选路线读取**：继承的引擎总纲 → 对应版本的执行大脑 → 本任务合同与冻结状态。续接任务先识别唯一 TASK_ID，使用 `tasks/<TASK_ID>/CURRENT.md` 路径定位本任务当前合同和最新已保存 Freeze，逐一核查实际文件、版本、方法提交/状态提交及下一未完成节点。新任务没有 CURRENT，不得伪造；由 GPT 在有写入权限的权威工作区新建合同V1、FreezeV1及任务 CURRENT；状态写入未成功则不能称已冻结/能自动跨页续接。
4. 由 GPT 选择合理自然节点，复用成熟方案，连续执行到 STOP_GATE/冻结条件；有可修复卡点先修再**继续原任务**，不得以局部修复充当最终成果。只有真正需要跨页交接时才读取所选路线的新页面模板；先保存状态，后新页按指针恢复。当前页面健康则继续，无须人为制造换页。
5. 仅在真实任务需要时调用现有成熟能力：n8n处理必要外部触发、持久等待/工作流；Dot为可核验的辅助入口候选；Codex承担按需代码工具；Playwright MCP与 Windows 双路执行桥调用已授权电脑/浏览器。它们默认**不是取代 GPT 的任务执行大脑**。没有必要就不用，禁止重造调度器、锁、浏览器控制服务或状态机。

## A/B 时间选型唯一合法比较

**只比较从同一个任务接收到取得同一个有效实质成果的完整耗时：`T_A_VALID` 对 `T_B_VALID`。**
A的派发/合并、B的重新开页/读取冻结/重新理解都只是各自完整时间的一部分，**不能拿两种局部成本直接比较**。同任务合同、输入、验收质量、设备条件，连同全部执行、返工、恢复、用户操作和维护摊销综合比较。没有实测/可复核虚拟时间则 `T*=UNKNOWN`，不能预先宣布谁快。

- 默认优先考虑低结构开销的 B，但中等和复杂任务也可用 B；A 在多独立执行节点、必要上下文隔离与跨分支协调时可成为更优候选。
- 从B换到A或反向选择，只能在合法冻结节点后发生，保持 TASK_ID 合同和事实连续，不能同时有两个当前任务写者。
- 任务最终依据原始合同 `FINAL_VALID` 验收；Freeze成功、工具启动、图片输出、局部报错修复都不代替原始目标。

## 版本与状态联动：唯一事实来源

本文件与标准 `SKILL.md` 是**固定外部入口**，无需跟着版本数字反复改。每个路线的稳定 `ROUTE.md` 是该路线的当前版本指针；方法发布先写齐新版文件并验证，然后**以一次 ROUTE 指针提交激活版本**，保证所有被指文件已在该提交可读。每个任务的 `CURRENT.md` 是其最新合同/Freeze指针，更新后才可可靠恢复；它与其它 TASK_ID 隔离。

因此“自动同步”表示**未来接单者自动追踪权威在线指针**，不意味着离线ZIP、已有会话或已装插件的缓存无需刷新，也不意味着无需保存新冻结就可自动恢复。首次授权和外部连接能力依工具真实条件。

## 现有重要依赖与验收边界

- 双层 A / 单层 B 的版本与实际文件由各自 ROUTE 读取，不能凭聊天记忆固定到旧版本。
- Windows 执行桥权威技能：`skills/extreme-time-automation-bridge/SKILL.md`（独立版本，不把代码搬入本技能包）。
- 浏览器共享 n8n 工程：`tasks/N8N_MCP_SHARED_20261009/`；原 F002 为该任务自身历史状态，不是其它任务默认状态。
- A/B对比长流程场景由该验证任务的合同及冻结状态指向当前场景证据文件，不能把示例文件名硬写成全局唯一任务。单次菜谱检索不足以检验长流程漂移。
- REUSE_GATE、连续虚拟成熟、STOP_GATE、Freeze→仅经授权一次Reality、已执行/未执行/UNKNOWN三态规则必须继承。没有真实时间证据或工具权限，坦承 IN_PROGRESS/BLOCKED，禁止假称自动续跑或已达 FINAL_VALID。
