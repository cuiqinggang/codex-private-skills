# 《极限短时间执行大脑 第8版》

版本：第8版  
升级来源：《极限短时间执行大脑 第7版》  
状态：CURRENT  
唯一标准：T*=min(T_VALID)

## 1. 先决定：做还是不做

比较成熟 BASELINE 与 T_FLOOR。优化空间不足或净收益不明显为正：

成熟方案 → 轻量精简 → 直接使用 → STOP

## 2. 值得优化时只做虚拟攻击循环

1 个 BASELINE → 1 个最大瓶颈 → ≤3 个成熟候选 → 1 个赢家 → 虚拟刷新整体 → 新最大瓶颈 → 继续

中间不做 Reality。

每轮只更新整条路径的预计时间、关键路径、兼容性、失败恢复和卡顿风险。

## 3. 什么时候才 Reality

只有虚拟层已经收敛：高收益瓶颈已处理、没有明显更优成熟替代、已接近 T_FLOOR，或继续攻击不值得，才：

Freeze → 一次正式 Reality → 验收

Reality 只认证最终整包。

## 4. Reality FAIL

回虚拟 → 搜成熟修复 → ≤3 个成熟候选 → 重新虚拟收敛 → 新 Freeze → 再 Reality

不是每个单点后测试。

## 5. 选点规则

每次只攻击当前整体关键路径上预计端到端收益最大的一个点。

局部选择服从整体 E[T_VALID]，同时考虑时间、可靠性、兼容性、失败恢复、卡顿风险和编排复杂度。

## 6. 禁止

- 禁止自研；
- 禁止从零研发；
- 禁止同时维护多个完整架构；
- 禁止中途逐点 Reality；
- 禁止为局部最优牺牲整体 T_VALID；
- 禁止为了理论小收益增加卡顿风险。

## 7. 核心

一条主路，一个瓶颈，三个候选，一个赢家，虚拟刷新，继续攻击，整体做熟，最后一次 Reality。

一句话：**Reality 放到最后；中间只刷新虚拟模型，不把测试插进未成熟方案。**
