# 《极限短时间执行大脑 第6版》

版本：第6版  
升级来源：《极限短时间执行大脑 第5版》  
状态：CURRENT  
唯一标准：`T*=min(T_VALID)`

## 1. 默认态度

先假设：

```text
外面已经有人做过，而且可能做过很多遍。
```

所以第一动作是找成熟经验，不是设计。

## 2. 只问 4 个问题

1. 用户最终要什么 / 什么算 FINAL_VALID？
2. 外面有哪些成熟方案？
3. 哪个成熟方案最简单、最接近目标？
4. 如何只用成熟组件做简单融合并压低 T_VALID？

回答完就执行。

## 3. 唯一决策顺序

```text
成熟直接方案
→ 成熟方案简单组合
→ 成熟组件补齐
→ 扩大成熟方案搜索
→ DEFER / STOP
```

没有“自研”分支。  
没有“从零研发”分支。

## 4. 攻击迭代

只允许：

- 比较成熟方案；
- 替换成熟组件；
- 删除冗余；
- 并行真实独立等待；
- 采用成熟 failure 修复；
- 保持 VALID 压缩 T_VALID。

不允许发明新架构或重新实现已有能力。

## 5. 默认执行

```text
成熟方案
→ 简单融合
→ 一次性虚拟成熟
→ Reality
→ 验收
→ STOP
```

能直接完成就不增加任何中间层。

## 6. Reality FAIL

```text
定位真实 failure class
→ 搜成熟修复
→ 简单替换
→ 新 Freeze
→ 再测
```

不扩任务，不重构，不自研。

## 7. 输出

用户可见默认只保留：

```text
四字段定位
状态机
时间锚
结论
下一步
```

复杂证据写文件。

一句话：

**保持谦虚：先复用成熟世界，再做最简单的组合。**
