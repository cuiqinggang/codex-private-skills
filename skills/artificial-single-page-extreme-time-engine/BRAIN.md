# 《极限短时间执行大脑 第10版》

版本：第10版  
升级来源：《极限短时间执行大脑 第9版》  
状态：CURRENT  
唯一标准：T*=min(T_VALID)

## 1. 每轮只算现实账

EXPECTED_GAIN = N_REALISTIC × 每次预计节省时间  
OPT_COST = 本轮优化成本 + 失败/卡顿/恢复成本  
NET_GAIN = EXPECTED_GAIN - OPT_COST

N_REALISTIC 只能取当前任务可预见的现实使用次数。

禁止把个人工具假设成百万次运行。  
以后真实使用规模扩大，以后再重算。

## 2. 正常决策

NET_GAIN 明显为正：继续。  
NET_GAIN 不为正或收益太小：停止。

“不做”可以是最优答案。

## 3. 低成本顺手优化

若某次优化：

- 虚拟成本极低；
- 不增加复杂度；
- 可立即回退；
- 不增加明显卡顿风险；

允许做一次轻量尝试，即使收益只有很小一点。

结果：
- 变好：保留；
- 无收益：停止；
- 变差/卡顿/复杂化：立即回退。

不允许为了小收益进入长修复链。

## 4. 每轮只攻击一个最大净收益点

当前完整方案  
→ 找最大 NET_GAIN 点  
→ ≤3 个成熟候选  
→ 选 1 个  
→ 虚拟替换  
→ 刷新完整数据  
→ 再算下一轮

不是找最大耗时点。

## 5. 中间不做 Reality

虚拟循环连续运行，直到下一轮不划算。

然后：

Freeze → 一次正式 Reality → 验收

## 6. Reality 后的最简单规则

- 更好：保留；
- 无明显收益：回退或保留原成熟 BASELINE；
- 失败：回退；
- 卡顿：回退。

先回到成熟状态，再决定是否还有值得做的成熟优化。

## 7. 禁止

- 禁止自研；
- 禁止从零研发；
- 禁止中途逐点 Reality；
- 禁止用假想超大运行规模放大收益；
- 禁止为了微小收益长期死磕；
- 禁止优化后变差却不回退。

一句话：

**只按当前现实使用规模算收益；便宜、可回退的小优化可以试一次，任何负收益立刻撤销。**
