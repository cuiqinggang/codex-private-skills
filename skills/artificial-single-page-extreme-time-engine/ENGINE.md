## 2. 用户端到端时间是最终时间

对任何用户实际使用的功能，必须先冻结：

USER_START = 用户为完成该任务必须做的第一个现实动作  
FINAL_VALID = 用户真正得到有效结果

T_USER_VALID = FINAL_VALID - USER_START

内部还可以记录：

T_SYSTEM_VALID = FINAL_VALID - SYSTEM_TAKEOVER

但 T_SYSTEM_VALID 只是诊断指标，不能替代用户方案的 T*。

若两个方案用户操作不同，打开网页、找入口、复制、粘贴、切窗口、点击、等待、确认等全部计入 T_USER_VALID。

只有在明确比较“系统接管后的后台性能”时，才允许单独比较 T_SYSTEM_VALID，并必须标明不是完整用户 T*。

## 3. 唯一主流程

成熟 BASELINE  
→ 算现实 NET_GAIN  
→ 选最大净收益点  
→ ≤3 个成熟候选  
→ 选 1 个  
→ 虚拟替换并刷新整体  
→ 再算下一轮  
→ 不划算即停止  
→ Freeze  
→ 1 次 Reality  
→ 验收

禁止中途逐点 Reality。

## 4. 虚拟循环强制执行门

进入 VIRTUAL_LOOP 后，未满足退出条件前，不允许停止在：
- “下一个优化点是……”
- “下一步建议……”
- “方案已经规划好……”

而必须自动继续：
选点 → 候选 → 虚拟替换 → 刷新整体 → 重算 NET_GAIN。

VIRTUAL_LOOP 只允许四种出口：

1. STOP_GATE：下一轮 NET_GAIN 不明显为正；
2. AUTH_GATE：需要用户授权的不可逆/高风险现实操作；
3. EXTERNAL_BLOCK：现实依赖不可用且无法继续虚拟成熟；
4. PAGE_HANDOFF：当前页面已明显过重/卡顿风险上升，需要最小冻结后换页继续同一 VIRTUAL_LOOP。

“完成一个优化点”不是合法出口。

## 5. Reality Delta

Freeze 后只做一次 Reality。

若 Reality 暴露偏差：
- 冻结已经通过的成熟事实；
- 只把真实失败/偏差送回 VIRTUAL_LOOP；
- 从失败点刷新后续完整方案；
- 再持续虚拟优化直到 STOP_GATE；
- 重新 Freeze；
- 再做一次整体验证。

禁止把 Reality 变成逐点试错工具。

## 6. 单页面边界

“人工单页面”含义不是“所有工作永远塞在一个页面”。

规则：
- 一个页面只服务一个明确任务/分支；
- 同一页面内允许多轮虚拟成熟与多个兼容优化；
- 不因完成一个微优化就机械换页；
- 页面开始变长、卡顿、恢复风险上升时，必须最小冻结并换新页面继续；
- 换页只是同一任务的状态接续，不是停止优化。

## 7. 唯一收益账

EXPECTED_GAIN = N_REALISTIC × 单次预计节省  
OPT_COST = 搜索 + 分析 + 融合 + 虚拟成熟 + 最终验证 + 失败/卡顿/恢复/维护成本  
NET_GAIN = EXPECTED_GAIN - OPT_COST

N_REALISTIC 只取当前可预见的真实使用次数。  
未来规模变化时再重算，不预支未来收益。

## 8. 低成本顺手优化

虚拟成本极低、可立即回退、不增加长期复杂度且不明显增加失败/卡顿风险时，允许轻量试一次。

变好→保留。  
无收益/变差/卡顿/复杂化→立即回退。  
不得为了微小收益进入长期修复链。

## 9. 每轮选择

不是找最大耗时点，而是找当前完整用户方案中预计 NET_GAIN 最大的点。

局部更快但整体更差，不换。  
系统更快但用户操作更慢，也不换。  
找不到更优成熟候选，保留原方案。

候选默认最多 3 个；只有继续搜索本身仍明显划算时才扩到 5。

## 10. 概率判断工具门

PROBABILITY_TOOL_DEFAULT = OFF

只有先证明完整调用后的 TOOL_GAIN 明显为正，才允许临时启用。

T_DIRECT = 不调用概率工具的端到端判断时间  
T_PROB = 准备 + 启动/连接 + 网络 + 判断 + 解析 + verifier + 失败/重试期望成本  
TOOL_GAIN = T_DIRECT - T_PROB

少量成熟候选时，默认确定性数据或当前智能体直接判断。

## 11. 停止与回退

下一轮 NET_GAIN 不为正，或收益已小到不值得投入：停止虚拟优化。

最终 Reality：
- 更好→保留；
- 无明显收益→回退成熟 BASELINE；
- FAIL→回到最近成熟冻结并按 Reality Delta 重新虚拟成熟；
- 明显卡顿/复杂化→立即回退。

## 12. 硬规则

禁止自研优先。  
禁止从零重建优先。  
禁止发明不必要的新架构。  
禁止中途逐点 Reality。  
禁止 VIRTUAL_LOOP 未到合法出口就停止。  
禁止只算机器时间而漏掉用户操作。  
禁止为局部最优牺牲完整 T_USER_VALID。  
禁止用假想规模放大收益。  
禁止为了“使用概率工具”而增加额外流程。

一句话：**从用户第一步到最终有效结果算总账；虚拟优化必须自动跑到停止门，Reality 只做整体验收。**
