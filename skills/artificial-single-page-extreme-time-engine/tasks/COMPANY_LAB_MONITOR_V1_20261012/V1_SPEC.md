## 版本边界
1. 监控台只读执行状态，不替代 GPT CEO 的派单、授权和验收决策。
2. Polsia V5 是业务系统版本；MONITOR V1.0.0 为独立监控版本。
3. 优先继承已有任务、日志、冻结文件及证据，禁止假造执行结果。
4. 允许最多六路并行的首屏布局，底层任务数可扩展，不耦合固定五路。
5. 离线/过期数据显示最后更新时间，禁止用缓存伪装在线实时状态。
6. 不修改 FlClash / Windows 代理 / 已登录专用浏览器，不引入不必要的 n8n。
7. 监控系统和执行系统故障隔离；只读展示失败不阻塞生产。

## V1.0 必备功能
- 总览：计划/运行/完成/阻塞/故障及时间戳，数值均来自同一状态数据源。
- 任务：TASK_ID、NODE_ID、执行方、当前状态、步骤进度、阻塞原因、下一动作。
- 证据：关联 GitHub Commit SHA、日志、Reality 测试、Freeze 文件；明确未核验/已核验。
- 状态：QUEUED/RUNNING/BLOCKED/FAILED/DONE/VERIFIED；DONE 不等于 VERIFIED。
- 时间：TASK_ACCEPTED、最近心跳、最后状态更新时间、有效完成耗时、人工等待时间。
- 恢复：刷新及跨页面接续后可恢复，不以浏览器内存充当权威存储。
- 安全：不在网页或任务日志泄露密钥、令牌、密码。
