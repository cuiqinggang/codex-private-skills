在我 38、39 岁的时候，当我真正开始构建 AI 产品时
我非常想打造能够自主运转的公司
这几乎不可能，因为梦想太大了
我觉得根本没有机会，因为

我当时辗转于巴黎、洛杉矶和旧金山之间，独自一人在做事
当我终于摆脱了手工打造产品的想法，转而使用 AI 时
我想：“好吧，现在我或许有一点机会了”
因为我真正想做的只是打造产品
不仅要打造它们，还要让它们自己思考

那时候，在旧金山，24 年、25 年的时候，他们已经有了 AI
于是，我整夜不睡，用 AI 写代码
大概 2 小时就能做出一个应用，
我想我大概做了七八个应用
我经常就在沙发上凑合着睡
因为我不想停下构建，这让我坚持了大约
一开始差不多有两年

我想打造一个平台，既有 1990 年代的氛围，也有 2000 年代的氛围，
以及 2010 年代的氛围，再加上一个属于未来的功能。
然后我说：“等一下，我懂 Agent SDK
我为什么不使用 Agent SDK 这个属于未来的功能呢？”
而我完全不知道该做什么，
但我知道我需要智能体，所以我让智能体循环运行，并接入了 MCP
然后这些都同步到了在生产环境中运行的真实产品上
我知道那可能会成为未来的一项功能
但我没想到它的影响会有这么大
