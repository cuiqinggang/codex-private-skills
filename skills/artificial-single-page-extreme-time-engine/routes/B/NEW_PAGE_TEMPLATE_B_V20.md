# 《B·新页面运行模板 第20版》

版本=B20｜继承 `NEW_PAGE_TEMPLATE_B_V19.md`，再继承根目录 `../../NEW_PAGE_TEMPLATE.md` 第18版。单层继承覆盖同任务创建额外Executor页面的旧语义，保留健康、Freeze和授权门。

## 一次自然节点及新页面接续
- 当前 GPT 页面合并CEO与Executor。可完成多步组成的一个自然产出；节点过程不因修复单个卡点而换页或结束。
- 节点到达 DONE_WHEN / 经证据确认 BLOCKED / UNKNOWN 后，先实际保存不可变节点证据和当前任务冻结状态；随后更新该 TASK_ID 独有 `tasks/<TASK_ID>/CURRENT.md`，并检查它确实指向有依据的合同、Freeze、版本和提交。
- **B收口门（比继承的“最多3次Freeze”更严格）**：一个 GPT 页面仅承担一个自然节点。节点内可以连续执行多步、处理卡点直到 DONE_WHEN；一旦节点Freeze且总任务未FINAL_VALID，原则上关闭该自然节点并换新的单层 GPT 页面承接下一节点；此时最多只有一个活动任务写者。总任务已FINAL_VALID则直接完成，无须多开页面。无法自动换页时输出唯一人工恢复信封并报告交接未完成，不得假装自动继续。
- 换页时一个旧页面写者先 Freeze/Persist，再由新页面从网络 `SKILL.md`/ `START_HERE.md` 与路线当前指针、任务 CURRENT 指针恢复，核对 TASK_ID、合同/冻结提交、下一未完成节点及唯一写者；新页确认接管前旧页不得被视为安全关闭。
- 当前可靠工具无法自动创建/接管/关闭GPT页面时，输出**唯一中文最短恢复信封**，禁止声称自动接管成功；用户不必把整个上下文复制过去。
- 新页面提示词仅应包括：任务ID、路线B、方法版本（从B ROUTE实际读取）、任务指针路径、冻结标签/状态提交、下一动作、权威网络仓库。B版本升级后自然通过B ROUTE读取最新版本，不应把版本号长期写死在通用入口。
- 任何状态缓存、历史网页、旧GitHub提交或离线备份均不能不经核实地冒充最新任务状态。根总纲的权限、安全、Reality once、STOP_GATE 保持不变。

## 不以换页时间为孤立目标
评价 A/B 时计入 B 重新建页、读取方法、理解未完成任务和直到得到同样 VALID 成果的全部时间；A亦计入派发/合并和重执行。只比较完整有效结束时间，不比较孤立局部成本。
