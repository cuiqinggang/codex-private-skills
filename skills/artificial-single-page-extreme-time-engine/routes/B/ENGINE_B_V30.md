## 一、统一入口才是人机接口
- 用户只需一次输入：「按自动化A/B极限短时间引擎完成【任务】」。载入网络仓库的稳定 `SKILL.md` → `START_HERE.md` → 当前 `routes/B/ROUTE.md`，由 GPT 继续按路径内部读取必要的总纲、大脑、任务合同与最新冻结；**一次用户输入，不代表程序只读取一个内部文件**。
- 版本**动态定位**：`START_HERE.md` 不抄写每次更新的版本号；本路线长期稳定的 `ROUTE.md` 是当前版本指针。先提交新版不可变方法文件并校验继承链，再在**一次受控的 ROUTE 指针提交**中激活新版本；使用者必须从该指针提交读到所有依赖。缺一或版本冲突即拒绝接单并标记 VERSION_MISMATCH，不得猜测旧版。
- 任务状态**按 TASK_ID 独立定位**：优先读取该任务 `tasks/<TASK_ID>/CURRENT.md` 作为最新合法合同/Freeze路径指针；指针必须对应真实持久化文件及可验证版本。指针缺失只根据已提供的可靠固定状态锚继续，否则 BLOCKED，不在其它任务或本机C盘猜测当前状态。任务冻结后更新该任务的指针，不能改其它任务的状态。
- 自动联动的准确含义：最新入口**每次重新读取**权威仓库固定路径，并沿路线当前指针、任务当前指针找到对应内容；这不是无需写入就会自己变化的缓存同步，更不是把全部动态任务状态塞进总纲。离线只能使用已校验本地快照，必须显示快照提交与过期风险。

## 二、B最短完整执行路径（GPT始终是执行者）
用户目标 → 恢复正确路线/任务状态 → GPT锁定 FINAL_VALID 与反约束 → 选一个合适的自然任务节点 → REUSE_GATE → 成熟BASELINE→≤3成熟候选→连续虚拟刷新整体→STOP_GATE → Freeze → 经授权唯一 Reality → 对账 → 若总任务未 FINAL_VALID，按真实能力自动交接下一单层 GPT 页面继续；不具备自动交接能力时输出唯一最短人工恢复信封，不伪称已继续。

- GPT 在同一活动页面规划、调用成熟工具、执行、分析、修复、核实，不额外派生GPT专用Executor。**B每页严格一个自然节点**，节点内可连续多步；节点完成或证实阻塞时先Freeze，任务未完才考虑新建下一 GPT 页面；旧页与新页不得同时作为当前任务写者。
- 一个节点可执行串行多步或独立并行组；节点大小由同一实质产出、上下文健康、操作依赖和故障可恢复边界决定，不固定步数，不因只是单层而降低 VALID。
- 每个卡点先用 GOOD/BAD 最早差异与已选成熟方案尝试修复；修复完成**返回原始任务合同**继续推进；只有节点真实达到 DONE_WHEN、真实不可恢复阻塞、未知外部副作用或触发已明确的人类授权门，才冻结阶段结果或停住。不能因为写好规划、启动程序、生成普通图、修掉一个报错就提前宣布整任务完成。
- 每次正式状态变化由本任务唯一写者保存不可变 Freeze 与状态指针后再考虑换页。若状态无法可靠保存，不得谎称完成交接；输出最小人工恢复信封。不得自动无限重试，尤其 UNKNOWN 外部副作用禁重发。
- n8n、Dot、Codex、MCP、Windows桥仅在其成熟能力对当前任务净收益为正/不可替代时使用：本页GPT能直接做就不额外经过n8n；需要代码工具才使用Codex；需要持久等待/外部触发才使用已验证n8n功能。严禁重造其通用调度、锁、状态机。

## 三、A/B唯一选型成绩
- A与B只比较**从同一任务接受时间到得到同一可核验 VALID 成果的完整耗时**（包含任务理解、方法载入、规划、工具启动、实际生产、返工、验收、Freeze、页面新建/重新理解、A派发/合并、恢复、操作及维护摊销）。
- 不以A派发合并时间 vs B上下文负担单独判输赢。B有时重新开GPT页仍更快；A有时可并行/隔离更快。先达VALID才比较时间，无真实相同边界证据不预判。
- `T_A_VALID`、`T_B_VALID` 若未知，`T*=UNKNOWN`；必须记录 `T_BASE_REAL`、`T_VIRTUAL_BEST`、差值/百分比及可复核来源，不能把理论推断写成已测时间。
- A仍为独立可选路线。当前B30只完善运行规约，**不等于VIRTUAL_MATURE=YES或FINAL_VALID=YES**。
