# 柴爱菊食管癌长期病例与营养通道决策技能

## 1. 目标

把患者历次检查、治疗、症状变化、营养方案、医生意见、费用与医保信息集中保存并持续更新，避免跨会话丢失、重复询问和信息混乱。

## 2. 固定工作原则

1. 保留患者真实姓名、年龄、住院号、病人ID、检查日期、医院、科室和医生等原始信息。
2. 原始报告、家属口述、医生口头意见、AI分析必须分层记录，禁止混写。
3. 报告原文优先；无法确认的内容标记“待核实”，不得自动补全。
4. 年龄、日期、诊断等出现冲突时同时保留，并写明来源。
5. 新资料加入后，必须更新：患者档案、时间轴、检查摘要、当前问题、决策记录和待办清单。
6. 医疗建议仅用于家属整理和就医沟通，不替代现场医生评估。

## 3. 当前核心问题

- 食管上段恶性病变造成明显狭窄，胃镜无法通过。
- 经口进食明显减少；当地住院输消炎药后可少量进食稀软食物，停药后进食明显减少。
- 当前优先目标为建立可靠营养通道、改善水分和营养摄入、减轻照护负担。
- 近期阶梯方案：先由本地有经验医生谨慎评估细鼻胃管/导丝或影像引导置管；若不能安全通过、耐受差、反复堵塞脱落或预计长期依赖，则转襄阳市中心医院南院区评估经皮胃造瘘/影像引导胃造瘘。
