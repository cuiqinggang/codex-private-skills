# 营养通道阶梯方案

## 当前共同目标

尽快、持续、安全地补充水分、热量、蛋白质和药物；减少长期静脉输液及反复住院，同时兼顾老人舒适度和家属照护能力。

## 方案A：本地鼻胃管/鼻肠管短期试用

### 适合定位

- 快速建立短期营养通道。
- 观察胃肠道对管饲营养的耐受。
- 为进一步胃造瘘评估争取时间和改善营养。

### 本病例特殊风险

患者食管上段距门齿约15cm处恶性狭窄，普通胃镜已不能通过，因此鼻胃管不一定能安全通过。放置时：

1. 必须由有经验的医护人员操作。
2. 事先明确告知胃镜不能通过及放疗史。
3. 优先考虑细软管、导丝辅助或影像引导。
4. 遇到明显阻力、疼痛、出血、剧烈咳嗽时立即停止，禁止反复盲插或强推。
5. 第一次喂养前必须可靠确认管尖在胃/肠内。

### 初期喂养

- 优先使用医生或营养科推荐的完整型肠内营养制剂。
- 不建议一开始用家庭饭菜打碎过滤后通过细管灌入，原因包括堵管、污染及营养不足。
- 若长期摄入很少，应先检查钾、磷、镁、血糖等，由小量、低速逐步增加，防范再喂养相关电解质紊乱。
- 每次喂养前核对外露长度；喂养时及之后保持上半身抬高；按医嘱前后冲管。

### 转换胃造瘘的触发条件

- 无法安全通过狭窄处。
- 鼻咽疼痛或老人不能耐受。
- 反复脱出、堵塞或需要重复置管。
- 反复呛咳、反流或疑似吸入。
- 每日无法达到目标水分和营养量。
- 预计需要长期管饲（通常超过数周）。

## 方案B：襄阳市中心医院腹壁穿刺胃造瘘

### 可能术式

根据医生口头描述，可能为影像引导下经皮胃造瘘或腹腔镜/镜下辅助胃造瘘。正式术式、执行科室及麻醉方式必须由医院确认。

### 优点

- 绕开上段食管狭窄，不需要强行从口腔通过肿瘤。
- 更适合长期营养。
- 面部不长期留管，舒适度和稳定性通常优于长期鼻胃管。
- 术后稳定后可回老河口进行日常换药、营养及常规维护。

### 术前重点

- 血常规、凝血功能、肝肾功能、电解质、感染指标。
- 体重、白蛋白/前白蛋白及整体营养风险。
- 是否使用抗凝或抗血小板药。
- 影像确认胃与腹壁之间无结肠、肝脏或其他不安全穿刺路径。
- 确认当前发热/感染是否需要先稳定。

### 主要风险

- 局部出血、感染、渗液、疼痛。
- 管道堵塞、脱出、移位。
- 胃壁固定不良、腹膜炎或误伤邻近器官（少见但严重）。
- 管饲后反流和误吸风险仍可能存在。

## 高性价比执行路径

1. 本地只做一次规范、可停止的安全置管尝试，不把反复强插当作方案。
2. 成功后先使用规范营养制剂，并设定1—2周的耐受和营养评估节点。
3. 明确需要长期营养时提前联系襄阳市中心医院，不必等到严重堵塞或并发症后才转。
4. 襄阳完成首次造瘘和早期观察；出院前获得书面管型、冲管、换药、换管周期及紧急处理说明。
5. 稳定后由老河口医院接续日常护理；首次计划换管或复杂问题优先回原置管医院。

## 必须立即停止喂养并就医的情况

- 新出现呼吸困难、持续呛咳、口唇发紫。
- 管子外露长度明显改变或完全脱出。
- 明显腹痛、腹部发硬、反复呕吐。
- 造口大量出血、漏液、红肿流脓并伴发热。
- 管道完全堵塞且规范冲管不能解决。


## 2026-08-16地点安排补充

- 患者目前仍能吃少量稀软食物，最近1个多月体重约95斤、基本稳定；可以先评估，不等于必须立即造瘘。
- 若未来需要胃造瘘，入口通常位于上腹壁，不是腰部。
- 因普通胃镜无法通过食管狭窄，需重点询问X线/CT引导下经皮胃造瘘或腹腔镜辅助方式，不能默认普通内镜PEG一定可行。
- 去武汉可以只评估发热和适合的营养通道；实际造瘘可根据技术与风险回襄阳市中心医院完成，稳定后回老河口护理。
- 胃造瘘只解决营养进入，不能直接治疗肿瘤、发热、肺感染或食管瘘。
