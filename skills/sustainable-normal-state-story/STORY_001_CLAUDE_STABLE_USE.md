# STORY-001｜Claude 长期正常使用故事｜v1.0

状态：SEED_STORY
用途：作为“可持续正常态故事法”的第一个现实强需求样例。

## 1. 现实需求

用户真正需要的不是“某一次重新能用”，而是：

> 在现实允许条件内，让 Claude 的有效使用长期保持在正常态，不因普通现实变化频繁中断，并在环境变化时仍有清楚、低维护的恢复路径。

## 2. 故事的第一性原理

Claude 是面向用户提供的公共商业服务，因此必然存在一组可长期维持的正常使用条件。

目标不是研究如何逼近平台内部未知阈值，也不是寻找规避限制的方法，而是：

```text
找到正常长期使用者共同满足的现实条件
→ 建立 NORMAL_ZONE
→ 把当前现实环境放入这个区间
→ 保持足够安全余量
```

## 3. 正常态候选维度

后续 Reality 中逐项确认，而不是先假定具体阈值：

- 服务可用性；
- 用户资格与账号状态；
- 身份/认证状态；
- 支付/订阅状态；
- 所在地区与服务条款的一致性；
- 网络链路与客户端状态；
- 使用量/额度；
- 正常设备与位置变化；
- 平台自身故障与恢复。

## 4. 攻击方式

用真实失败案例、服务中断、设备/网络/位置变化、支付异常、额度变化等去攻击 NORMAL_ZONE。

攻击目标不是“让系统规避平台判断”，而是确认：

> 普通、合法、现实的变化是否仍能保持正常使用；若不能，正常态还缺少什么条件或冗余。

## 5. v1.0 当前未完成

本故事目前只完成方法与目标定义，尚未完成现实资料收集、正常样本归纳和 Reality 验证。

下一版本应从：
1. 官方支持条件；
2. 长期正常使用样本；
3. 常见合法现实变化；
4. 已知中断类别；
中提取共同不变量，再构造第一版可验证 NORMAL_ZONE。
