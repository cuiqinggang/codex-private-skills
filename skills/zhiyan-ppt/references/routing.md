# 混合请求路由

仅在主模式无法由首条规则直接确定时读取。

| 冲突 | 主模式 | 附加要求 |
|---|---|---|
| 高级视觉 + 必须原生可改 | 正式可编辑 | 使用高级视觉语言，所有关键内容仍为原生对象 |
| 公开演讲 + 会后分发 | 演讲增强 | HTML 为现场主交付；另给可打印 PDF 仅在用户要求时生成 |
| 微信展示 + 后续还要改 | 正式可编辑 | 采用手机截图友好的强首屏与大字号；不自动改成 HTML |
| 三风格预览 + 最终 PPTX | 风格探索 | 只做三个代表页，用户选定后生成一套正式可编辑成稿 |
| 三风格预览 + 现场演讲 | 风格探索 | 只做三个代表页，选定后切换演讲增强生成一套成稿 |
| 逐字稿 + 原生 PPTX | 演讲增强 | 若用户明确要求 PPTX，则备注写入每页 Notes，不强制 HTML |

决策优先级：现场功能不可替代性 → 原生可编辑要求 → 首印象设计价值 → 默认正式可编辑。

不得因路由冲突自动生成两套完整版本。需要双格式时，先说明主交付与派生交付的关系。
