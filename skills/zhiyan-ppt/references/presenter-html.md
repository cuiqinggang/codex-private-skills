# 演讲增强模式

## 目标

在高级视觉的固定舞台基础上，提供可靠的现场演讲体验：演讲者视图、备注、计时、进度、跳页和逐字稿。

## 必备功能

- 主屏只显示当前幻灯片；演讲者窗口显示当前页、下一页、备注、已用时间和页码。
- 键盘至少支持：上一页、下一页、首页、末页、跳页、暂停/继续计时、开关备注。
- 核心导航与备注离线工作；刷新后从第 1 页或明确的 URL hash 恢复，不进入错误页。
- 逐字稿按页绑定，备注内容不进入观众画面或可见 DOM 区域。
- 打开演讲者窗口前处理弹窗拦截，失败时提供同页降级界面。
- 支持 `prefers-reduced-motion`，且计时与导航不依赖动画完成事件。

## 备注写法

每页备注包含：开场句、主要解释、证据限定、转场句、建议时长。逐字稿应口语化，可直接读，但不要把未知事实说成确定结论。

## 验收

逐项实测键盘、点击/触摸、跳页、刷新、计时、备注显示与双窗口同步。断网后再次打开并验证核心功能。
