# 同材六页横评基准

## 冻结输入

所有模式使用以下同一份六页中文输入，不增删事实，不改标题结论，不引入外部数据：

1. **封面：AI 助手进入团队工作流** — 副标题：从试用工具到可验证生产力。
2. **决策：先在高频、低风险任务中小范围部署** — 目标是验证节省时间、质量稳定性和采用率，再决定扩展。
3. **驱动：价值来自任务重构，不只来自模型能力** — 三个驱动：清晰输入、可复用流程、人工验收。
4. **证据框架：同时记录效率、质量与风险** — 效率看单次耗时；质量看返工率与验收通过率；风险看敏感数据、幻觉和权限边界。当前没有实测数值。
5. **实施：两周完成一个受控小试** — 第 1–2 天选任务与基线；第 3–10 天执行并记录；第 11–14 天复盘并决定保留、调整或停止。
6. **行动：指定负责人、样本和停止条件** — 未达到预设阈值就停止扩展；未知阈值由用户或项目负责人补充。

## 横评维度

| 维度 | 检查问题 |
|---|---|
| 准确性 | 是否保留“无实测数值”和未知阈值，没有编造数据 |
| 决策价值 | 是否让受众清楚知道先小试、如何衡量、何时停止 |
| 视觉层级 | 标题、证据、行动是否有明确优先级 |
| 可读性 | 远距离或目标视口是否能快速阅读 |
| 可编辑性 | 文本、图形、数据和备注如何修改 |
| 稳定性 | 打开、导航、字体、离线和跨设备表现 |
| 速度 | 生成、返修、导出和复用成本 |

## 输出规则

用同一评分表比较，不把格式差异伪装为内容能力差异。说明每种模式最适合的场景与代价；不给脱离用户目标的“绝对冠军”。
