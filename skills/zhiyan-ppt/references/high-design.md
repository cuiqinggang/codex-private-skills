# 高级视觉模式

## 目标

为微信展示、产品故事、个人故事和作品集案例制作单文件 HTML 演示。优先第一印象、叙事节奏和视觉完成度，同时保留源码可编辑性。

## 固定舞台

- 所有页面在 `1920×1080` 固定舞台内创作，整个舞台等比缩放适配视口。
- 禁止在手机端重新排版页面内容；允许留黑边或留白边。
- 幻灯片切换使用状态类控制 `visibility`、`opacity` 与 `pointer-events`；不要依赖可能被布局规则覆盖的 `display:none`。
- 支持键盘、点击/触摸导航和 `prefers-reduced-motion`。

## 视觉语言

1. 先定义一个可扩展的视觉命题：字体、主色、强调色、留白节奏、栅格、图形语汇和动效节奏。
2. 避免紫色渐变白底、同质化卡片墙、默认仪表盘和无语义装饰。
3. 连续页面不重复同一种构图；章节页、证据页、对比页、过程页和收束页形成节奏。
4. 动效服务于注意力顺序；一页一个主要动效时刻，禁止无目的漂浮。
5. 图片使用用户提供、明确授权或可追溯来源；不虚构产品截图或 Logo。

## 交付

交付单个离线可用 HTML；若必须引用本地资产，将其内嵌或放在清晰的同级资产目录。明确告知用户：HTML 源码可编辑，但不是原生 PowerPoint 文件。
