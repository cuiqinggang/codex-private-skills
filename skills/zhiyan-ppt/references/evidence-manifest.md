# 证据清单

演示开始时建立一个清单，并在叙事冻结与最终交付前更新同一份清单。

| ID | 页面 | 声明/数字 | 类型 | 来源或公式 | 日期/版本 | 限制 | 状态 |
|---|---:|---|---|---|---|---|---|
| E-001 |  |  | sourced_fact / calculation / inference / recommendation / assumption / unknown |  |  |  | verified / pending / excluded |

## 类型规则

- `sourced_fact`：可回到原文、数据表、访谈或用户材料。
- `calculation`：写清输入、公式、单位、分母和舍入。
- `inference`：由证据推导，必须写限定语。
- `recommendation`：行动建议，不伪装为事实。
- `assumption`：为推进工作采用的可撤销假设。
- `unknown`：材料中没有答案，公开显示缺口或请求补充。

一个声明若无法进入清单，就不能进入成稿。来源脚注应靠近证据；完整链接或文献表可集中在附录。
