# 成熟执行体整体能力增强 V1

版本V1；封存2026-10-29（北京时间）。组织方法沿用《AI 化组织》V4.2，不改写其冻结版本。

## 先恢复真实状态

1. 先读[最新DSH续接](references/dsh-continuation.md)及`assets/dsh-continuation.json`，再读[原V1检查点](references/checkpoint.md)、`assets/v1-checkpoint.json`和[成果数据](references/results.md)。DSH已实测并完成迟后接续，不重复旧起点。
2. 原生加载`ai-organization-v4-2`、`dsh-extreme-effective-time`；涉及Windows先加载当前`gpt-windows-execution-bridge`，动态发现A并做只读探针，成功后继续A。
3. 核对实际生产入口、回执和必要文件。封存时生产包装器仍是`1.3.1-scoped`；本轮通用默认入口候选未部署。原18条实验轨迹保留；最新DSH原预算NOT_VALID、迟后接续PASS，证据见最新续接。没有后台继续任务。
4. 继承已确认文件、源码、验收和失败记录。归档内`deploy.py`、`finish_reality.py`、`start_reality.py`是历史程序，禁止因加载技能自动运行。

## 保持真正目标

让同一个默认入口接收自然语言未见任务，自主发现成熟能力、正确选路、跨技能组合、适应追加需求，在故障后完成真实交付。不能用若干预写固定配方的速度代表整体执行体提升。

在固定质量、完整性、可靠性、成本和授权约束下，唯一目标为完整有效交付时间`T*=min(T_VALID)`。从收到可执行任务到独立验收交付计墙钟，含发现、接入、排队、工具、审核、失败、返修和恢复。未验收记NOT_VALID，未完整计时记NOT_MEASURED。SDK估算不是账单；局部最快不是全局极限。

## 成熟方法优先

- 优先复用已有完整执行入口、原生Skills、成熟专业工具、已验收业务流程和原恢复机制；目标运行时确实缺少等价能力时，才补最薄的兼容接入。
- 现成DSH入口已补一次库存组合、变化与ZIP恢复证据；按最新续接只处理实际缺口。准确调用及边界见[下一轮方法](references/next-method.md)，不要重建另一个平台或重复已验收业务。
- 沿用Pi官方Agent Skills按需加载；跨工具迁移沿用已有`absorb-deerflow-capabilities`的“行为映射→目标原生工具→实物验收”。复制说明不等于能力已吸收。
- 停止将逐项自制、逐项排错作为默认增长路线。不另造执行框架、检索引擎、调度器、锁、状态机或浏览器控制器。
- 不全库注入、不批量安装、不重搭环境；最多三条可行路线，包含成熟基线；净收益证据支持后才临时增加专业执行者。

## 连续执行和验收

1. 按[最新DSH续接](references/dsh-continuation.md)的唯一NEXT_ACTION开始；[下一轮方法](references/next-method.md)保留原调用合同。先核对现有素材，不重跑已验收业务。
2. 明确真实输入、全部成品、质量、成本和权限；完成输入→工具→产物→验收→故障→恢复的虚拟成熟，STOP_GATE→Freeze后做一次相关整体Reality。
3. 测同一默认入口的完整任务链；调用者不能预先指定具体业务配方。明确记录实际后台是Pi、DSH或其他执行器，不能隐瞒替换后台。
4. 选路须有真实调用；组合须有跨工具成品；变化在首次交付后追加；恢复须有真实异常与提交对账。文件数、成功码、自报PASS不算通过。
5. 优先用现成成熟验收器、原测试和成品读回，只补合同缺口。区分业务失败、接入失败、超时与验收误报；误报原件不改，迟来的重新接受不得套用旧耗时。
6. 普通故障最小修复并继续；UNKNOWN先对账，不盲重发。跨进程复用原生session-id及同一cwd；本地文件优先既有`run_resumable.py`，不新造监督系统。
7. 同合同质量、成功率、完整T_VALID和约定成本支持净收益后，才接入原默认入口并保留回退。候选、索引388项或一次新题通过，均不是完整超级智能体认证。

## 安全和保存

保留原Windows ACL workspace-write/read-only边界，不改C:\AI原项目、代理、凭据、安全设置或他人会话。复用原凭据机制，不复制、不输出密钥。发送、支付、发布、删除等真实账号操作仍依具体授权。

完整历史、源码和成品按[证据入口](references/evidence.md)恢复。保留失败、慢样本、旧版本与哈希。本技能保存知识和检查点，不表示生产已升级或后台会自动续跑。

普通任务交付实物和必要证据；复杂升级附TASK_ID、节点、已确认成果、未完成项、完整时间或NOT_MEASURED及唯一NEXT_ACTION。换页先封存，不让用户重新解释目标和成熟方法偏好。
