# 知识库条目：静态网站工厂

## 一句话定义

静态网站工厂是以 Astro/Vite 等构建工具，把设计或参考网页转成可由 CDN 直接分发的 HTML/CSS/JS，并用数据模板、SEO、外接表单和自动验收形成批量交付闭环。

## 路由关键词

静态网站、企业官网、落地页、作品集、博客、文档站、网站克隆、截图转前端、URL 转代码、Astro、Vite、Cloudflare Pages、Netlify、Vercel、批量建站、站群、SEO。

## 决策规则

- 展示型和内容型：优先静态；
- 登录、交易、实时状态为核心：转全栈或混合架构；
- 有参考站：调用克隆 Skill 后进入静态交付流程；
- 无参考站：调用设计 Skill 后进入静态交付流程；
- 批量页面：必须模板与 JSON/CSV 数据分离。

## 关联技能

- 网站设计；
- 网页克隆/URL 转代码；
- 截图转前端；
- SEO；
- 部署；
- 视觉回归测试。
