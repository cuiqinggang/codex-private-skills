# 与现有网站 Skills 的关系

| 能力 | 现有设计 Skill | 现有克隆 Skill | Static Site Factory |
|---|---:|---:|---:|
| 从零视觉设计 | 主责 | 辅助 | 路由调用 |
| 参考站结构提取 | 辅助 | 主责 | 合法性与验收 |
| URL/截图转组件 | 可选 | 主责 | 统一输入输出 |
| 数据驱动批量页面 | 通常较弱 | 通常较弱 | 主责 |
| 静态化判定 | 非主责 | 非主责 | 主责 |
| SEO、sitemap、canonical | 部分 | 部分 | 强制闭环 |
| 表单/客服外接 | 部分 | 部分 | 主责 |
| 构建与 CDN 部署 | 部分 | 部分 | 主责 |
| 三轮验收与收益数据 | 不一定 | 不一定 | 强制 |

## 合并策略

不建议把所有技能源码硬合并成一个巨型 Skill。建议采用：

- 保留原设计 Skill；
- 保留原克隆 Skill；
- 新增本 Skill 作为入口和编排器；
- 通过路由调用现有能力；
- 重复规则只在入口层定义一次；
- 原技能保持只读，后续通过独立 Worktree 做适配。
