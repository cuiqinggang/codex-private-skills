# Frontend Visual Taste Gate

## Purpose

Prevent AI-generated interfaces from looking generic, flat, noisy, or low-quality.

## User Visual Preference

The user prefers:
- horizontal layout when appropriate
- dark Obsidian-like dashboard
- elegant high-contrast UI
- clear hierarchy
- neon or soft luminous borders only when controlled
- clean cards
- readable Chinese typography
- visual evidence
- realistic and practical product UI
- less AI-slop
- less clutter
- no random decorative noise

Avoid:
- low-fidelity wireframe look
- childish gradients
- random icons
- fake SaaS template feel
- messy glow
- overdone glassmorphism
- unreadable small text
- copied external identity
- visual elements unrelated to user's own system

## Required Design Procedure

1. Identify interface purpose.
2. Identify primary user action.
3. Define visual hierarchy.
4. Define layout grid.
5. Define color and contrast rules.
6. Define component system.
7. Implement HTML/CSS/JS.
8. Produce screenshot or visual evidence if possible.
9. Compare against target image or reference structure.
10. Create polish checklist.

## Dashboard Acceptance Checklist

For AI Company Dashboard:

- Main title visible.
- Stage/status visible.
- Left navigation clear.
- Today focus visible.
- Todo visible.
- Active projects visible.
- Knowledge health visible.
- Skill / workflow entry visible.
- Cards aligned.
- Chinese text readable.
- No placeholder external company/project identity.
- No copied reference watermark or unrelated text.
