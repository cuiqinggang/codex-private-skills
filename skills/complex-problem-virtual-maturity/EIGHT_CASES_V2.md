# 八道超大型综合题：固定顺序与验收需求（第2版）
所有题目先选择历史已完成且结果可核查的真实载荷，必须控制答案隔离；若找不到满足条件的现实案例，标为待选，不虚构答案。
|序号|题目|必须覆盖|核心验收条件|具体案例状态|
|---|---|---|---|---|
|1|大型软件真实事故|多层依赖、回归、CI、回滚、发布风险、复验|独立证明 GOOD/BAD、FIRST_DELTA、最小修复、错误 RED/修复 GREEN|候选 Cargo #12064；已污染上下文，严格盲测需独立隔离|
|2|从零交付大型软件系统|需求澄清、成熟组件复用、架构、实现、集成、测试、打包与交付|用户主流程端到端有效，关键非功能要求可测，有恢复和回归证据|待选|
|3|大型自动化系统建设|多工具编排、多智能体、权限、状态机、跨页恢复、任务队列和重试|可重复运行、恰好一次副作用、失败恢复、状态一致|待选|
|4|大规模系统综合故障|网络、环境、并发、资源、数据与依赖交织|从根因链隔离第一差异，恢复服务，反复注入故障可恢复|待选|
|5|大型数据与决策项目|数据质量、冲突指标、不确定性、因果与资源权衡|能复核数据、比较反例、在盲化结果上解释和改善决策|待选|
|6|跨领域复杂工程项目|软硬件整合、供应链、性能、可靠性、预算约束|可验证的系统级交付与安全/成本/性能平衡|待选|
|7|大型多模态生产项目|图片、声音、视频、素材版权、时序同步、质量与可重复生产|端到端成品可审查，音画同步、角色一致及自动回归门明确|待选|
|8|多项目并行压力任务|2–3大型任务并行、资源租约、状态写者、页面关闭与错误隔离|并行下无状态污染、无资源抢写、故障独立恢复，净耗时可测|待选|

每题增加复杂度应来自真实依赖及可核查异常，禁止为了“超难”凭空编排难题。成功不意味着所有中小题覆盖，后续以新题迁移验证。
