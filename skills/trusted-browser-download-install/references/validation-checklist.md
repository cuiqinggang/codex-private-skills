# 可信浏览器下载安装校验清单

面向需要“像人一样从网页点击下载”的任务。

## 下载前

- 可信来源是否在任务允许清单中。
- 页面截图是否保存。
- 下载链接是否来自页面 DOM 中真实链接。
- 链接域名、路径、文件名是否符合预期。

## 下载中

- 浏览器必须是 headed/可见窗口。
- 下载目录固定。
- 如果出现 `.crdownload`，必须等待完成或记录停滞。
- 超时后不要把半成品当作安装包。

## 安装前

- 文件存在，大小合理。
- 文件不是 HTML。
- Windows 安装包有 MZ 头。
- SHA256 已记录。
- 能读取 Authenticode 签名时记录签名状态和证书信息。
- 出现 NSIS/corrupt/signature mismatch 时停止。

## 安装后

- 验证应用可执行文件路径。
- 验证版本。
- 验证协议、快捷方式或文件关联。
- 验证应用原生窗口截图。
- 用中文 HTML/JSON/Markdown 汇报证据与当前状态。
