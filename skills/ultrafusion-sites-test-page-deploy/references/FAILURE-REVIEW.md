# 失败复盘入口

## 已验证失败模式

1. 本地候选冒充部署完成：只有 Worktree 和本地测试时，必须使用本地状态词。
2. 结构重绘页冒充真实站点源码：缺少真实源码/Git/Sites 对应证据时停止，不另建独立页面。
3. 范围从最小移动膨胀为整站重构：用户收窄范围后，撤回未提交扩大改动；只前置操作区。
4. 建立第二套解析或计算逻辑：新交互必须调用原函数；解析兼容也只扩展同一个解析器。
5. Windows 换行导致提示词字节误判：分开检查正式 Git 内容、工作树换行和部署资产；禁止为修字节数改写正式提示词。
6. Sites 凭证请求返回 Invalid Appgen project id：同一次操作先调用 get_site，再把其原样 id 传给凭证工具。
7. 凭证被输出到 Playwright/终端日志：不回显包含 token 的运行代码；若已暴露，立即旋转并清理缓存/日志。
8. 本地证据被线上复验覆盖：使用 evidence/local 与 evidence/postdeploy 两个目录，并核对数量和时间戳。
9. Sites 私有部署瞬时参数错误：精确参数原样重试一次；持续失败则 MINIMAL_PATCH_BLOCKED。
10. 发布后只看部署状态、不打开原网址：必须从原根网址进入、检查首屏、执行线上流程并读取控制台。
