# 技能准备与实际使用关口

## 目录

1. 两种不同关口
2. 逐层接入
3. 使用证据
4. 失败返回
5. 技能冲突和缺失

## 1. 两种不同关口

### 技能准备关口

回答：必需技能是否存在、是否读取、是否适合、依赖是否可用。

准备证据：

- 技能名称和中文用途；
- 真实路径；
- 版本或内容校验值；
- 触发条件；
- 必读文件；
- 依赖工具；
- 输出合同；
- 风险和冲突；
- 将绑定的工作包。

### 技能实际使用关口

回答：负责工作包的真实智能体是否按照技能执行，并产生了该技能要求的证据。

只有技能名称出现在报告中不算实际使用。

## 2. 逐层接入

| 层 | 必须完成的动作 | 不通过的结果 |
|---:|---|---|
| 1 | 声明哪些能力是任务关键能力 | 关键能力不清，返回第1层 |
| 2 | 确认技能来源和版本可信 | 来源污染，返回第2层 |
| 3 | 选择并完整读取技能入口及其明确要求的必读资料，检查依赖和冲突 | 必需技能不可用，对应工作包阻塞 |
| 4 | 将技能绑定到具体工作包和验收项 | 未绑定，不得分派 |
| 5 | 将技能绑定到具体智能体，保存接收和读取证据 | 未分配或未读取，不得执行 |
| 6 | 工作包开始前复核实际使用条件 | 无使用证据，立即停止工作包 |
| 7 | 在开始、返回、阶段结束时触发技能检查 | 发现缺失，进入第10层 |
| 8 | 检查技能要求的命令、字段、产物或工具回执 | 不符合则检查失败 |
| 9 | 审计角色独立接受或拒绝技能使用声明 | 无独立接受则不能通过 |
| 10 | 返回第3、5或6层补准备、重分配或重做 | 三轮仍失败则阻塞 |
| 11 | 记录已用技能、版本、证据和未决问题 | 交接不完整不能关闭阶段 |
| 12 | 汇总前面已通过的使用关口 | 不能在本层第一次发现技能缺失 |

## 3. 不同技能的使用证据

### 说明型技能

例如流程规范和领域指南。

证据：

- 系统或智能体读取记录；
- 任务产物包含技能规定的关键结构；
- 禁止项没有被违反；
- 审计角色能把结果与技能标准逐项对应。

### 脚本型技能

证据：

- 实际命令；
- 参数；
- 开始和结束；
- 退出结果；
- 原始输出；
- 生成文件和校验值。

### 工具或插件型技能

证据：

- 真实工具调用回执；
- 调用者智能体；
- 输入范围；
- 返回结果；
- 错误和重试；
- 是否进入正式产物。

### 子智能体编排技能

证据：

- 真实智能体编号和父子关系；
- 独立上下文；
- 任务分派；
- 启动和回传；
- 主控接收；
- 独立产物。

逻辑隔离文件不是替代证据。

## 4. 失败返回

- 技能根本不存在：第3层，阻塞或寻找替代。
- 技能存在但未读取：第3层补读取。
- 技能未分配给智能体：第5层重分配。
- 智能体声称读取但无证据：第5层拒绝启动工作包。
- 产物不符合技能要求：第6层重做。
- 验证器不能检查技能效果：第8层补验证器。
- 审计不接受：第10层路由返修。

禁止把关键技能未使用写成“残余风险”后继续通过。

## 5. 技能冲突和缺失

出现多个技能时指定：

- 主技能；
- 支持技能；
- 优先规则；
- 冲突字段；
- 冲突解决理由；
- 每个技能只加载必要资料。

必需技能不可用时可以：

1. 使用证据充分的成熟替代技能；
2. 缩小工作包并明确能力限制；
3. 只完成准备和阻塞报告；
4. 请求用户安装、授权或提供资料。

不能假装技能已准备，也不能临时自创一个同名流程冒充成熟技能。
