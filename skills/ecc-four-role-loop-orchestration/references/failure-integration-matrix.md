# 历史错误与十二层融合矩阵

## 判断标准

一条防错规则只有同时进入主标准、任务模板、运行证据、确定性验证和最终验收，才算完成融合。

| 历史错误 | 主要根因 | 应进入的层 | 必需证据 | 阻断方式 |
|---|---|---|---|---|
| 十二层说明书冒充执行包 | 只有介绍，没有工作包 | 1、4、11、12 | 完整工作包和执行证据 | 没有本任务应用不得执行 |
| 制作任务包冒充真实任务 | 对象错误 | 1、6、9、12 | 任务本体产物 | 只生成方案不能正式通过 |
| 数小时任务几分钟通过 | 只信自述，没有覆盖复核 | 4、8、9、12 | 提前完成复核 | 不等待，复核失败则返修 |
| 强制最低时间后空等 | 时间替代目标 | 1、7、8、12 | 真实产物变化 | 生产任务取消最低时长 |
| 时间门存在但没有持续运行 | 只有禁止早退，没有运行驱动 | 4、6、7、10 | 每阶段真实工作 | 耐力任务无产物不得通过 |
| 心跳和时间总结冒充工作 | 证据只含时间 | 6、7、8、9 | 产物或有意义验证变化 | 连续无变化触发返修 |
| 单任务无限循环 | 无轮次、策略和停止条件 | 1、4、7、10 | 轮次和策略变化 | 默认三轮，连续无进展换策略或阻塞 |
| 相同失败重复相同修复 | 没有假设管理 | 4、10 | 本轮假设与上一轮差异 | 无策略变化拒绝下一轮 |
| 逻辑隔离冒充子智能体 | 文件证据可自造 | 1、5、8、9、12 | 系统启动和回传回执 | 正式任务无真实回执直接阻塞 |
| 主控主动禁止子智能体 | 错误理解上下文隔离 | 1、5、12 | 角色启动计划和回执 | 正式长任务不允许单智能体通过 |
| 多智能体写入冲突 | 没有独立空间和合并计划 | 4、5、7、8 | 工作区和文件范围 | 冲突范围冻结，重新拆包 |
| 执行者自我验收 | 权责混同 | 6、9、12 | 不同智能体编号 | 同一上下文审计无效 |
| 只靠模型自评分 | 缺少现实信号 | 8、9 | 测试、脚本、截图或人工关口 | 可用现实证据未运行则拒绝 |
| 验收器只检查文件存在 | 验证过浅 | 8、9 | 关键字段、行为和错误案例 | 结构通过不等于功能通过 |
| 验收器只看失败不看成功 | 信号不对称 | 8、9 | 成功和失败信号矩阵 | 缺一类信号则审计不完整 |
| 技能写进报告但未使用 | 准备与使用混同 | 3、4、5、6、8、9 | 读取、调用和产物符合证据 | 当前工作包立即阻断 |
| 模型或工具路由漂移 | 实际环境未锁定 | 1、3、7、8、9 | 工具和模型调用记录 | 未授权替代直接拒绝 |
| 只返回文件夹路径 | 缺少用户可审计摘要 | 11、12 | 证据摘要和索引 | 交接不完整不能关闭 |
| 英文状态用户看不懂 | 中文解释缺失 | 全层 | 同处中文解释 | 用户不可审计则拒绝关闭 |
| 时间到了但目标未完成 | 时间被当成目标 | 1、4、9、12 | 原目标对齐矩阵 | 输出部分完成或阻塞 |
| 延迟检查点伪装按时 | 恢复记录不诚实 | 2、7、8、9、11 | 原始开始时间和恢复日志 | 伪造时间致命失败 |
| 文件名称别名未声明 | 证据定位不稳定 | 2、8、11、12 | 文件对应表 | 无对应关系时不得静默接受 |
| 历史验收文件缺失却补造 | 追求结构通过 | 2、8、12 | 真实来源或缺口登记 | 禁止伪造旧证据 |
| 补丁只登记未进入模板 | 规则传播链断裂 | 1、3、4、8、12 | 五位置融合矩阵 | 只存在补丁不算完成 |
| 正式路径和历史盘混用 | 权威源不清 | 1、2、3、7 | 磁盘权威检查 | H/K日常路由直接拒绝 |
| 固定中文层名被改写 | 把十二层当成可自由概括的说明 | 全层 | 英文名、中文名、层号逐项记录 | 任一固定名不一致即拒绝 |
| 用十二层完整布尔值代替逐层执行 | 只有总结，没有十二层实例 | 1至12 | 标准模式逐层动态记录并绑定完整标准校验值；严格模式展开十六项 | 缺层、改名、调序、缺动态证据或允许跳过即拒绝 |
| 空工作包仍最终通过 | 只核对布尔关口 | 4、6、12 | 至少一个工作包、声明和产物 | 空工作包不能通过 |
| 最终验收只有结构化文件 | 用户不可审计 | 11、12 | final-acceptance.md和json双文件 | 缺一拒绝 |
| 用户要求没有进入完成台账 | 目标覆盖只在早完时检查 | 1、8、11、12 | 已声明要求与完成台账一一映射 | 未接受要求阻断通过 |
| 成熟技能或组件未比较就自研 | 复用关口缺失 | 3、4、8、9 | 路线比较、搜索状态和自研理由 | 适用时缺比较拒绝 |
| 角色配置冒充真实并行智能体 | 把视频角色表当系统回执 | 5、8、9、12 | 唯一上下文、空间、起止回执和贡献 | 没有系统回执即阻塞 |
| 资料推测进入正式结论 | 缺少来源置信度和下游限制 | 2、8、9、12 | 已核实／估计／推测登记 | 未获准估计或推测进入最终产物即拒绝 |
| 审计只核实内容不查泄密 | 没有交付前复检 | 9、12 | 元数据、密钥、内部路径、临时材料、附件、引用清单 | 交付安全未接受不能通过 |
| 第0轮缺失或轮次跳号 | 只检查最大轮次 | 6、10 | 从0连续的轮次台账 | 跳号或重复拒绝 |
| 返修第一轮重复原策略 | 只在第二次失败后换策略 | 10 | 每个返修轮策略变化 | 第1轮起未变化即拒绝 |
| 检查点只有一句进展文字 | 动作证据过浅 | 7、8、11 | 时间、层、包、差异、命令／测试／审计、证据编号 | 缺动作级证据拒绝 |
| 用空格、大小写或路径尾点伪装独立上下文 | 标识未归一化 | 5、8、9 | 归一化后的上下文、空间和回执 | 归一化后重复即拒绝 |
| 自建一个同名“平台日志”冒充系统回执 | 只检查文件和校验值 | 5、8、9、12 | 平台运行编号、父运行编号、事件状态、字段交叉核对和平台侧复核 | 结构不一致拒绝；无法平台侧核对则证据不足 |
| 用户要求只在完成台账出现，未进入执行 | 台账、工作包和声明没有交叉绑定 | 1、4、6、9、12 | 要求编号贯穿工作包、声明、产物和审计 | 任一关键要求无执行链即拒绝 |
| 技能使用只填`used=true` | 技能回执仍是执行者自述 | 3、5、6、8、9 | 独立工具追踪文件、读取事件、使用事件和真实调用者 | 无索引事件文件即拒绝 |
| 执行者在完成台账中接受自己 | 完成台账验收人未验角色 | 9、12 | 已登记的独立审计智能体编号 | 接受者不是审计角色即拒绝 |
| 第0轮接受后仍追加“继续返修” | 轮次状态未与工作包同步 | 9、10、12 | 连续轮次、决定枚举和最后决定 | 接受后追加轮次或通过包末轮未接受即拒绝 |
| 检查点复制编号、时间或不存在的工作包 | 检查点没有交叉引用 | 7、8、11 | 唯一编号、严格递增时间、合法层号、工作包和证据索引 | 任一引用无效即拒绝 |
| 生产任务声明耗时与智能体运行时间不符 | 时间只信最终自述 | 5、7、8、12 | 最早启动、最晚回传、检查点和声明耗时勾稽 | 超出容差即拒绝 |
| 模型或工具路线变化由模型自行写“已批准” | 授权证据是自由文本 | 1、3、7、8 | 进入证据索引的外部批准证据编号 | 只有自述文字即拒绝 |
| 推测来源把`used_in_final`改成假后仍被声明引用 | 来源登记未与执行声明绑定 | 2、6、8、9、12 | 每条声明的来源编号和置信度 | 声明引用推测即拒绝 |
| 密钥写进最终主文或产物副本 | 只扫描结构化键名 | 8、9、12 | 结构化字段、中文主文和产物副本联合扫描 | 命中未脱敏模式即拒绝 |
| 状态、技能或检查点证据编号没有进入索引 | 证据链只单向记录 | 6、7、8、11、12 | 所有被引用证据编号反向存在且校验值一致 | 缺索引或校验值不一致即拒绝 |

## 新版验证重点

确定性验证至少覆盖：

1. 十二层文件和关键字段；
2. 真实子智能体回执；
3. 执行与审计编号分离；
4. 独立空间和写入范围；
5. 必需技能实际使用；
6. 每轮变化和策略变化；
7. 返修上限；
8. 生产预算与耐力门槛分离；
9. 异常提前完成复核；
10. 目标对齐和未关闭阻塞；
11. 中文解释；
12. C盘权威和H/K禁止日常路由。

## 不能由脚本单独证明的内容

- 审计判断是否合理；
- 多智能体是否真正提高收益；
- 主观设计质量；
- 高风险业务决定；
- 用户是否接受范围变化。

这些需要独立审计角色、现实对比或人工关口。
