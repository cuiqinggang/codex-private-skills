## 二、从 \$20 Pro 升级到 \$100 Ultra 5x 的硬数据门禁

**原则**：先用现有 \$20 Pro 把 Antigravity + Claude 复核、\$10 API 赠金回执、Colab vs 本机 RTX 2080 Ti 计时全部打通，再在真实交付单中记录数据。**只有满足以下任一实测瓶颈，才批准切换至 `ULTRA_5X`**：

1. **交互/编程额度瓶颈**：连续 **2–3 张真实交付单** 在 Antigravity / Gemini 侧触发 Pro 额度封顶，并导致实际交付等待或被迫降级。
2. **云端 GPU 算力瓶颈**：单月 Colab 消耗逼近 **200 CU** 上限，且至少有 2 次同样本对照实测证明 Colab 的完整 `T_VALID_E2E`（含上传+排队+运行+下载+校验）稳定优于本机 RTX 2080 Ti（或本机显存/并发明确无法承接）。
3. **API / 部署刚性消耗瓶颈**：无人值守 Gemini API 定时/批量流程稳定运行，月消耗持续超过 **\$10 赠金上限**（或确有 Cloud Run 真实部署需求超过 Pro 额度）。
