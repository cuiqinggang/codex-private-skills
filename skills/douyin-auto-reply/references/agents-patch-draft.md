# AGENTS.md 补丁草案：可视坐标操作证据

当任务使用截图、网格、坐标点击或桌面可视操作时：

1. 每执行一个动作后必须重新截图。
2. 每张作为证据的截图必须用绝对路径 Markdown 图片直接嵌入当前对话。
3. 仅保存文件、仅内部查看、仅报告路径均不算验收。
4. 小按钮先 50px 粗定位，再用 20–25px 细网格；红色竖线、绿色横线、黄色目标圆圈/十字。
5. 用户看不到图片时停止后续动作，先修复图片展示。
6. 对外发送前检查重复内容、目标上下文和当下确认；发送后必须显示最终结果截图。

建议触发词：`一步一截图`、`一步一发图`、`网格坐标`、`细网格`、`普通人坐标截图法`、`负坐标`、`DPI 缩放`。
