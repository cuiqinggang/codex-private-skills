# Glossary ZH

| 术语 | 含义 |
|---|---|
| 一人 AI 公司 | 由一个人负责方向与审批，AI 承担大量研究、执行、复盘、运营工作的公司系统。 |
| Agent Company OS | 把多个 agent / harness 组织成公司式流程的操作系统或控制台。 |
| Route | 一条外部成功路线、技术路线、产品路线或可复用机制。 |
| Absorb | 不安装或少安装，提炼机制并写入本地规则/模板/技能包。 |
| Replay | 用 mock/read-only/demo 方式复现关键机制。 |
| WATCHLIST | 长期观察列表，用于持续进化。 |
| Blueprint | 可执行或可模拟的业务流程图/任务 DAG。 |
| CEO role seat | 公司级总控席位，负责全局理解和治理，不等于真人 CEO。 |
| Leader role seat | 单条业务线/蓝图负责人。 |
| Inbox | 审批和提案入口，防止聊天直接产生副作用。 |
| Run history | 每次运行的输入、输出、状态、审批、失败和复盘记录。 |
| HITL | Human in the loop，人类在关键节点检查、修改或批准。 |
| Durable execution | 任务失败或中断后可从 checkpoint 恢复。 |
| Credential status | 只显示凭据状态，不显示密钥明文。 |
| Supersede | 新路线明显优于旧路线，旧路线保留但标记被替代。 |
