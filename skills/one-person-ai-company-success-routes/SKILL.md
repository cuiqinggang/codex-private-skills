# One Person AI Company Success Routes

Use this skill to continuously discover, verify, replay, and absorb external routes for one-person AI companies and multi-agent company operating systems.

## Executable System Modules

- 海外本地商家网站获客与交付：CASE-013 routes to `one-person-local-business-website-system` for market selection, compliant lead research, 100-point scoring, concept demos, human-reviewed outreach drafts, proposals, fixed-scope delivery, three-round acceptance, and repeat sales.
- The parent skill selects and governs the route. The child skill executes the detailed workflow. Do not duplicate the child's full templates into this file.

## Hard Safety Rules

- Do not modify Hermes, OpenClaw/Xiaolongxia, New API 3011, Open WebUI 3000, ComfyUI, or ECC production configuration.
- Do not read, print, copy, or persist real API keys, tokens, passwords, cookies, or production secrets.
- Do not connect real sending channels or send WeChat, Feishu/Lark, Telegram, email, ads, payments, or customer messages.
- Do not blindly install projects. Prefer public docs, shallow clone, raw README, mock mode, static review, and local demos without credentials.
- Stop for Level 3 actions: destructive deletes, account/payment/security changes, secret exposure, unknown installers, or real external sends.

## Default Workflow

1. Load the latest `ROUTE-MATRIX.md`, `WATCHLIST.md`, `SOURCE-OF-TRUTH-MAP.md`, and `CHANGELOG.md`.
2. If the request matches an executable module, route to that child skill before using the general research workflow. CASE-013 uses `one-person-local-business-website-system`.
3. Classify each route as `ABSORB`, `REPLAY`, `WATCH`, `REJECT`, or `DEPRECATED`.
4. For a new candidate, fill `templates/NEW-ROUTE-INTAKE-TEMPLATE.md`.
5. If the route is worth deeper study, fill `templates/CASE-STUDY-TEMPLATE.md` and save under `references/CASE-XXX-Name.md` or a dated report.
6. Replay only in mock/read-only/demo mode. Never attach real production credentials.
7. Extract reusable mechanisms, not whole projects.
8. Map every useful mechanism to the current C-drive skills and AI Company OS. Treat H/K copies as backup/reference unless explicitly requested.
9. Update `ROUTE-MATRIX.md`, `CASES.md`, `WATCHLIST.md`, `SOURCE-OF-TRUTH-MAP.md`, and `CHANGELOG.md` after each run.
10. Write a periodic report under `reports/periodic-updates/` for light, weekly, monthly, or initial runs.
11. Run Knowledge Brain health/hot sync for explicit changed files after important updates; do not change production configuration.
