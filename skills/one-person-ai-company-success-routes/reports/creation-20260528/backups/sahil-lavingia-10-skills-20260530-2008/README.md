# One Person AI Company Success Routes

这是一个长期运行的“一人 AI 公司成功路线进化系统”，用于持续搜索、梳理、验证和吸收：一人 AI 公司、多 Agent 公司操作系统、Agent 协作公司、软件公司模拟、多 Agent 编排框架、可视化 AI 工作流、本地执行体、AgentOps/观察与安全等外部成功路线。

本技能包不是一次性报告。它必须持续更新，并把可验证、可复用、可本地化的机制合并回 `H:\AI\skills\one-person-ai-company-success-routes`，同时把关键索引同步到 `H:\AI\skills\ai-company-evolving-revenue-portfolio`。

先读 `PUBLISH-SUMMARY-20260528.md`。它是面向阅读和复用的成果导览：保存位置、核心文件、8 个案例、可吸收机制、持续更新方式、Polsia / AICompany Dashboard 建议和安全边界都在那里。

## 默认节奏

本技能包建议每 2 天运行一次轻量更新；每 7 天运行一次周复盘；每 30 天运行一次路线矩阵重评估。

## 核心原则

- 只吸收机制，不盲目安装项目。
- 先判断是否值得吸收，再决定是否 mock replay。
- 所有 replay 默认 mock/read-only/demo。
- 不改生产配置，不读密钥，不真实发送。
- 每个结论必须有来源、路径、截图或运行证据。
- 新路线要映射到 GPT Web、Codex、Hermes、OpenClaw、小龙虾、ComfyUI、ECC、H:\AI\skills、AICompany Dashboard。
- 如果发现更优路线，标记 supersede/upgrade，不删除旧案例。

## 快速使用

1. 读取 `ROUTE-MATRIX.md` 和 `WATCHLIST.md`。
2. 用 `templates/NEW-ROUTE-INTAKE-TEMPLATE.md` 录入新路线。
3. 对值得深入的路线写 case study。
4. 用 `ABSORPTION-RULES.md` 判断 ABSORB / REPLAY / WATCH / REJECT。
5. 用 `REPLAY-METHOD.md` 做安全 replay。
6. 更新 `CHANGELOG.md` 和周期报告。
