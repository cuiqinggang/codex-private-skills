# CASE-009：Ploy / Webflow 主动网站成熟复刻路线

## 定位
这是 `one-person-ai-company-success-routes` 下的成功路线案例，不是要求复制 Ploy/Webflow 源码，也不是声称已经完成生产复刻。

核心目标：站在 Webflow、Ploy、成熟 SaaS、开源生态、云基础设施和大模型能力的共同肩膀上，删除重复探索，把“成熟网站平台 + 主动式 AI 增长 Agent”重新组合成可验证的成熟产品。

## 一句话原则
**不要重造已经成熟的模块；只实现不可替代的差异化编排、产品体验和验证闭环。**

## 成熟路线
1. 收集现实成熟答案：Webflow、Ploy、云托管、Auth、数据库、Billing、Analytics、CRM、OAuth、Agent runtime、测试与可观测性。
2. 生成 `MATURE_CAPABILITY_GRAPH`，区分 REUSE / BUY / OSS / GENERATE / BUILD。
3. 用第一性原理极限短时间引擎 v3.1.2 生成 `VIRTUAL_MATURE_STATE`，先在虚拟空间收敛，而不是边写边猜。
4. 顶级推理模型只负责高价值决策；廉价模型承担大规模编码、测试、日志归类和候选修复；确定性程序承担 hash/diff/schema/test/统计。
5. 自动执行成熟命令包。
6. 真实证据闭环：Build → Test → Fail → Repair → Regression → Long-run → Freeze。
7. 只有真实证据通过后才允许 `MATURE`；Virtual Mature 不能替代 Real Mature。

`OBSERVE → THINK → ACT → MEASURE → LEARN`
