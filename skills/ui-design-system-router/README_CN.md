# UI Design System Router V1 RC1

离线 UI 设计系统路由技能：根据业务选择设计原型，生成项目专属 `DESIGN.md`，审查/重构现有 UI，并以原创化、商业安全、响应式和无障碍门禁验收。

快速调用：`python scripts/compose_design_md.py --product-type saas --audience enterprise --tone trustworthy --stack "Next.js,TypeScript,Tailwind" --output DESIGN.md`，随后运行 `python scripts/validate_design_md.py DESIGN.md`。

上游资料仅作为设计语言研究材料；禁止直接复制品牌资产和完整构图。正式运行不依赖网络。
