# 来源质量规则

| 等级 | 可接受来源 | 使用方式 |
|---|---|---|
| A | 官方产品页、创始人官网/博客/原帖、公开财务面板 | 可支持事实；收入仍标“自报/非审计” |
| B | 创始人直接访谈、Indie Hackers/HN 原帖、Product Hunt、权威媒体 | 可支持事实，注明采访时间 |
| C | 二手案例、新闻转载、社交转述 | 只能辅助；关键数字需二次验证 |
| D | 截图、营销号、无链接图片 | 只作检索线索 |

规则：时效性与来源等级是两个维度。旧 A 级来源不能证明当前状态；新 C 级来源也不能自动成为事实。产品自报客户数、收入和“排名第一”等营销数字均非审计事实。
