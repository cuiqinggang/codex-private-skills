# solo-founder-success-research

面向独立开发者与一人公司的证据优先研究技能包。方法层与案例层分离，可研究人物、产品、赛道、失败模式和多人差异，并持续更新案例库。

## 快速使用

- `研究 Pieter Levels 的独立开发经历`
- `分析 Photo AI 为什么成功`
- `对比 Marc Lou、Pieter Levels、Tony Dinh`
- `研究适合一人公司的 AI 工具赛道`

运行验收：`python scripts/run_acceptance_tests.py`。

注意：公开收入通常是创始人自报或媒体转述，不等于审计财务数据。
