# ABC 与全量证据闭环修复的量化对应

## 1. 统一思想

两套系统解决的是同一类问题：不能因为“已经生成了新版本”就宣布完成；只有正向必需项、负向禁止项、锁定内容、派生关系和独立验证全部成立，才能发布。

## 2. 答案任务的变更合同

每道题开始时，内部建立：

| 字段 | 含义 | 量化要求 |
|---|---|---:|
| Required | 用户必须得到的核心结论、变量、限制和输出 | 覆盖率100% |
| Forbidden | 关键事实错误、逻辑断裂、答非所问、伪造核验 | 数量0 |
| Locked | 已经成立、不得在后续丢失的正确内容 | 保留率100% |
| Derived | 事实→推理→结论；强点→融合稿；问题→补丁 | 关系闭合率100% |

## 3. 层级对应

| 全量证据闭环机制 | V9.5层 | 作用 |
|---|---|---|
| Change Contract | A开始前 | 锁定问题、质量口径和硬闸门 |
| Impact Graph | A | 扩大变量、路径、风险和依赖覆盖 |
| Freeze Original | A/B/C | 永久保留Raw、最强A和B原稿 |
| Source Repair | A | 修事实、前提和核心推理源头 |
| Rebuild and Sync | B | 将经验证强点重建为一致答案 |
| Independent Verifier | C | 不继承B自评，按陌生稿审核 |
| Bad Fixture Rejection | C测试 | 已知错误样本必须被拒绝或修复 |
| Evidence Matrix | 最终评测 | 每个增益与具体变化绑定 |
| Release Discipline | 全流程 | 无证据不得写PASS |

## 4. A层证据

```text
Raw真实存在；
材料性缺陷已定位；
修复与缺陷一一对应；
全维复评完成；
历史最佳保留；
极限探针完成。
```

缺少任一项，不能声称“极限有效压力已完整执行”。

## 5. B层证据

每个纳入强点必须有：

```text
来源模型；
最强A是否缺失；
独有性说明；
事实或逻辑验证；
提高的质量维度；
纳入后是否产生副作用。
```

只有“来源于另一个模型”不构成纳入理由。

## 6. C层证据

每个补丁必须有：

```text
原问题；
补丁范围；
修复证据；
其他维度复检；
接受或撤销决定。
```

没有材料性问题时，`C_Final = B_Final` 是正确结果，不是失败。

## 7. 证据等级

| 等级 | 内容 | 可声明状态 |
|---|---|---|
| E0 | 只有模型自称变好 | 不得发布 |
| E1 | 单层自评分和修改记录 | 方向性 |
| E2 | 单题匿名顺序平衡评测 | 单题结论 |
| E3 | 多题统计、C错误注入、真实时间成本 | 候选版本验收 |
| E4 | 长期真实使用与产品数据 | 稳定价值判断 |
