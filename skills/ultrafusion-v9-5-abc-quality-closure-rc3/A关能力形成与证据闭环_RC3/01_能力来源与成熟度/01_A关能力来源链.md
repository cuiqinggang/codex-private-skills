# A关能力来源链

## 1. 能力定义

能力名称：

> V15.1-A 极限有效压力能力

能力目标：

> 在固定预算内，找出答案最高价值缺陷，进行定向修复，通过复评、极限探针和历史最佳保留，使最终答案稳定不低于压力前答案，并确定最佳压力与最佳性价比位置。

## 2. 能力来源链

```text
原始问题与失败案例
        ↓
提出A关极限压力假设
        ↓
冻结量化测试合同
        ↓
建立十二道验收关口
        ↓
建立压力、质量、时间、成本计算
        ↓
建立A关测试网站
        ↓
十次模拟检测
        ↓
GPT真实烟雾测试
        ↓
三模型一致性测试
        ↓
多题正式实验
        ↓
校准评分波动和最小可识别分差
        ↓
确定有效最大压力和最佳性价比压力
        ↓
完整证据矩阵
        ↓
冻结能力、限制适用范围，或否决回退
```

## 3. 能力不是单个文件

正式能力由以下部分共同构成：

| 组成部分 | 功能 |
|---|---|
| V15.1-A正式提示词 | 执行极限压力 |
| 正式量化测试合同 | 规定什么叫有效 |
| 压力值计算 | 说明实际执行了多少压力 |
| 质量计算 | 说明答案提高或降低多少 |
| 固定时间最优计算 | 找到预算内最佳结果 |
| 十二道关口 | 阻止虚假完成和遗漏 |
| 图片证据矩阵 | 保存可复核证据 |
| 测试网站 | 固定执行、记录、计算和导出 |
| 模拟检测 | 验证测试工具逻辑 |
| 真实模型实验 | 验证实际质量 |
| 发布闸门 | 决定冻结、继续修订或回退 |
| 能力来源账本 | 保存能力形成历史 |

## 5. 强制原则

后续任何模型或执行器不得仅因为：

- 网站已经建好；
- 模拟测试通过；
- 提示词文字完整；
- 模型自己声称提高；

就宣布A关能力有效。

必须同时给出真实分数、真实时间、压力值、独立评审、图片证据和跨题统计。
