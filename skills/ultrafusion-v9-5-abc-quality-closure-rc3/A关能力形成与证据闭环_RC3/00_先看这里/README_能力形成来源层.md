- 所属技能包：UltraFusion V9.5.1｜ABC 极限质量闭环
- 增量候选版本：RC3
- 中文定位：A关能力形成来源层＋量化测试层＋全量证据闭环层

- 正式V15.1-A提示词：保持只读，禁止重写、优化或重新生成

## 二、为什么必须加入技能包

A关能力不是仅由一份提示词产生。真正可复用、可证明、可持续改进的能力来源于：

1. 问题与能力假设；
2. 正式量化测试合同；
3. 压力、质量、时间和成本计算；
4. 十二道核心验收关口；
5. 测试网站和数据记录工具；
6. 十次模拟验证；
7. 真实单模型测试；
8. 三模型一致性测试；
9. 多题统计与评分波动校准；
10. 最佳压力和最佳性价比确定；
11. 证据矩阵；
12. 最终冻结、回退或否决。

如果只保留最终提示词，而不保存上述过程，后续就无法回答：

- 这项能力从哪里来；
- 为什么相信它有效；
- 在什么任务中有效；
- 最佳压力是多少；
- 什么时候不该使用；
- 哪些数据支持发布；
- 下一版本该根据什么修正。

因此，本增量包必须作为 UltraFusion V9.5.1 的“能力来源与验证记忆”加入新候选版本。

## 四、集成原则

此包是增量模块，不是覆盖包。

正确做法：

原RC2只读
→ 新建独立工作副本或Git工作树
→ 复制RC2形成RC3候选
→ 仅新增本增量目录和运行规则
→ 验证核心提示词校验值不变
→ 运行本包自检
→ 再进行真实测试

禁止直接覆盖原RC2。
