# HTML 最小运行页规范与 RC3 现状

## 1. 正式定位

HTML 页面是 UltraFusion V9.5.1 A关能力来源与验证执行器的一部分，不是技能包外部的临时工具。RC3候选已把页面、量化合同、十二道关口、模拟证据、图片证据矩阵和发布闸门纳入 `A关能力形成与证据闭环_RC3/`。

## 2. 当前实现边界

- 本地/私有站点运行；
- 无模型API、无账号、无数据库、无后台；
- 正式A提示词来自哈希锁定的只读静态镜像；
- 网站只负责输入装配、记录、计算、异常阻断、保存和导出；
- 网站不得重写、优化或补全正式提示词；
- 哈希不一致时必须阻止复制和测试输入装配。

## 3. 页面顺序

1. 显示能力来源、当前成熟度和下一关口；
2. 核验正式源路径、字符数、字节数和SHA-256；
3. 粘贴原始问题一次；
4. 装配并复制V15.1-A输入；
5. 粘贴模型完整回复并自动提取A_Raw、A_Final和压力记录；
6. 记录Q0、QR、Q1、Q2、QF；
7. 计算实际最大压力、有效最大压力、最佳性价比压力和固定时间最佳版本；
8. 执行十二道关口与十二项证据矩阵；
9. 记录独立匿名评审和人工复核；
10. 输出发布状态与下一关口并导出证据包。

## 4. 依赖失效

- 修改原始问题：当前装配输入和下游结果全部失效；
- 修改模型完整回复：自动拆分、评分与发布结论失效；
- 修改任何评分、时间或硬闸门：性价比和发布结论失效；
- 正式提示词哈希变化：当前测试立即阻塞，禁止静默沿用。

## 5. 必备检测

```text
正式源SHA-256核验；
空输入阻断；
正式BEGIN/END标记检查；
命令包回显检测；
结果区块缺失检测；
0—100压力计算；
五维质量与边际收益计算；
本地保存和恢复；
证据完整率；
发布状态门禁；
导出TXT、Markdown或JSON证据。
```
