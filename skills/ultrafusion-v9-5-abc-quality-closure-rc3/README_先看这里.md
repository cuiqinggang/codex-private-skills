## Codex部署原则

Codex在RC3候选中只负责：

```text
解压；
运行自测试；
复制技能目录；
复制桌面执行母版；
报告哈希和测试结果。
把用户提供的RC3增量精确加入独立候选副本；
把正式A提示词以逐字节只读镜像接入技能内网站并发布私有站点。
```

Codex不得：

```text
重新生成或改写提示词；
把一个A提示词改成三个版本；
修改核心提示词或让网站静默改写正式源；
加入模型API、账号、数据库或后台；
修改旧版；
merge或push。
```


## 本版本边界

- HTML A关能力验证执行器已作为技能内部能力来源层接入；
- 没有连接 GPT、Qwen 或 DeepSeek API；
- 没有声称真实答案质量已通过；
- 没有取代后续多题实验；
- 没有生成英文版。

## 正确使用方式

从 `桌面执行版模板/1号文件夹_稳定运行母版_V9.5.1` 复制出新的 2号测试副本。母版内已经包含 A_Initial、统一A、B、C和最终评测提示词；1号母版不得直接使用。

涉及 V15.1-A 或 A关验证时，必须先读取能力来源账本，显示 `L3｜模拟验证通过`，执行十二道关口，并按发布闸门输出 `REVISE / LIMIT / ROLLBACK / REJECT / FREEZE` 的中文状态。当前下一关口为 L4 GPT三题真实烟雾测试。
