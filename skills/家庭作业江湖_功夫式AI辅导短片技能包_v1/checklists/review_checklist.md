# 复盘与验收检查表

## 1. 剧本层

- [ ] 不是工具介绍，而是一个故事
- [ ] 故事能打动人
- [ ] 家长痛点明确
- [ ] 孩子委屈真实
- [ ] AI 出手有反转
- [ ] 最后有情绪释放

## 2. 分镜层

- [ ] 0-3 秒左右双画面清楚
- [ ] 3-11 秒解决问题占最大篇幅
- [ ] 11-14 秒反差表达清楚
- [ ] 14-15 秒尾卡不拖
- [ ] 每一秒都有任务
- [ ] 没有无意义空镜头

## 3. 人物层

- [ ] 妈妈真实、美观、体面
- [ ] 妈妈前半段焦虑，后半段舒展
- [ ] 小男孩天真可爱
- [ ] 小男孩委屈但不卖惨
- [ ] 没有假脸、塑料脸、畸形脸
- [ ] 没有卡通化

## 4. 画面层

- [ ] 前半段压暗
- [ ] 后半段放亮
- [ ] 有乌云散开感
- [ ] 不是 PPT
- [ ] 不是普通广告
- [ ] 不是幼稚动画

## 5. AI 价值层

- [ ] 展示拍题
- [ ] 展示 AI 秒看懂
- [ ] 展示拆思路
- [ ] 展示给家长讲法
- [ ] 展示查错因
- [ ] 展示语数英覆盖
- [ ] 没有夸张成“魔法万能”

## 6. 字幕层

- [ ] 字幕短
- [ ] 字幕大
- [ ] 手机一眼能看懂
- [ ] 不像课件
- [ ] 不堆长句

## 7. 声音层

- [ ] 0-3 秒有压迫感
- [ ] 3 秒 AI 出手有声音转折
- [ ] 3-11 秒卡片音效干净
- [ ] 11-14 秒音乐转暖
- [ ] 14-15 秒落版音稳

## 8. 尾卡层

- [ ] contact_version 只出现号码
- [ ] 不写“电话：”
- [ ] 不写姓名
- [ ] 不写冒号
- [ ] 字体不是正楷
- [ ] 字体不是普通办公字体
- [ ] 号码像电影片名落版
- [ ] 清楚可读

## 9. 技术层

- [ ] HyperFrames/Remotion 工程存在
- [ ] 不依赖剪映
- [ ] MP4 可导出
- [ ] public_version.mp4 存在
- [ ] contact_version.mp4 存在
- [ ] 电话号码可配置
- [ ] 源码可继续修改

## 10. 总判定

只有所有核心项通过，才算 PASS。

核心项包括：

- 剧本能打动人
- 前 3 秒抓人
- 解决问题占最大篇幅
- 人物真实美观
- 尾卡号码片名式落版
- 不像 PPT/广告/动画
