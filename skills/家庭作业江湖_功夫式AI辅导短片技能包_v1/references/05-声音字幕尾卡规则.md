# 05｜声音、字幕、尾卡规则

## 1. 音乐总原则

声音要服务情绪，不要喧宾夺主。

整体声音曲线：

```text
低沉压迫
→ 拍题出手
→ 快速拆解
→ 音乐转暖
→ 号码落版
```

---

## 2. 阶段声音

### 0-3 秒

- 低沉
- 压迫
- 风雨欲来
- 不能像鬼片
- 不能吓人

### 3 秒

- 拍题声
- 轻微“出手”音
- 节奏突然变快

### 3-11 秒

- AI 卡片出现时有轻微科技音
- 音效干净、短、快
- 不要廉价电子音

### 11-14 秒

- 音乐转暖
- 压迫感消失
- 像乌云散开

### 14-15 秒

- 号码落定时一个有气场的收尾音
- 简洁
- 稳

---

## 3. 字幕规则

字幕必须：

- 大
- 短
- 狠
- 手机一眼能看清
- 不像课件
- 不堆长句

推荐字幕：

```text
辅导班一报几千，
作业还是没人讲？

拍一下题

AI 秒看懂

一步步拆思路

告诉家长怎么讲

错在哪里也能查

语文：阅读题怎么答
数学：步骤怎么讲
英语：句子怎么分析

少吼孩子，
少花冤枉钱。
```

---

## 4. 尾卡号码规则

最后只出现号码。

正确：

```text
138 0000 0000
```

错误：

```text
电话：138 0000 0000
联系电话：138 0000 0000
姓名：XXX｜电话：138 0000 0000
免费交流 AI 辅导方法｜电话：138 0000 0000
```

---

## 5. 尾卡气质

号码是电影落版，不是广告说明。

关键词：

```text
片名式 / 高手名号式 / 优雅弧线 / 江湖感 / 厚重 / 清楚 / 简洁
```

禁止：

- 正楷
- 宋体
- 普通办公黑体
- 传单感
- 名片感
- 直接平板弹出
