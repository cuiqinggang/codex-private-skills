# 中文个性签名设计与教学

## 核心原则

把“字形正确”和“真人能重复写出”设为硬门。把“好看”设为评分项，不把 AI 生成的一张漂亮图直接当成成品。

`可交付签名 = 字形正确 × 可重复书写 × 场景适配 × 艺术识别度 × 教学完整度`

任何一个硬门失败，退回局部重画，不用装饰掩盖错误。未经真人三写验证的方案只能称为“视觉候选”，不能称为“已验证成品”。

## 选择任务路径

- 新设计：执行完整流程，默认提供六种不同骨架。
- 修改现有图：先锁定正确姓名和错误位置，再局部返修，不整体重生成。
- 数字化真人签名：保留本人笔迹，清理背景、平滑线条并导出透明文件。
- 评审方案：逐字验形，再做真人三写测试和量化评分。
- 制作教学级交付：补齐下笔顺序、抬笔点、节奏、真人视频、练习纸、应用示例和验收记录。
- 通过微信免费服务受理：由父技能 `$wechat-ai-service-evolution` 接收需求，再调用本技能；只登记匿名运营数据。

## 完整流程

### 1. 收集最小必要信息

读取 `references/intake-and-brief.md`。至少取得准确姓名、简繁体、使用场景、期望气质、惯用手、常用笔和现有签名照片。遇到异体字、生僻字或用户强调过的笔画，要求标准字图或亲笔正楷样本；不得自行猜字。

### 2. 冻结字形

读取 `references/character-integrity.md`，为每个字建立验字卡：标准结构、允许连写、禁止丢失的识别笔画、历史错误风险。先做黑白骨架，不加光效、纹理和夸张飘带。

用户指出的笔画约束优先于风格偏好。例如在特定“崔”字案例中，用户要求“隹”部保持四道横向笔意；出现第五道即判错，不进入美化阶段。该约束只绑定这个已确认案例，不能未经核对机械套用到其他异体或书写体系。

### 3. 设计六个有实质差异的候选

默认提供商务签、连笔签、潇洒签、一笔或少抬笔签、艺术签、结构强化签。不要只换字体、颜色或背景。需要可爱签或英文签时替换一个候选。每个方案标注：

- 主骨架和视觉重心；
- 连线与抬笔位置；
- 最长笔锋的作用；
- 预计书写难度与耗时区间；
- 最容易写错的部位；
- 适用场景。

读取 `references/style-and-scoring.md`。

### 4. 先验字，再审美

把每个候选与标准姓名逐字对照，放大检查增笔、少笔、粘连导致的错字、简繁混用和字符替换。AI 图像工具只能提供笔势灵感；涉及准确汉字时，优先使用真实书写、矢量路径或可编辑线稿重建。

字形没有通过时只改错误部位，保留其余已确认结构，避免整体重生成让正确部分再次漂移。

### 5. 做真人三写测试

读取 `references/handwriting-test.md`。让设计者或用户用日常使用的笔、在实际签名尺寸下连续写三次。记录每次耗时、抬笔数、骨架一致性、辨识度和卡顿点。三次都保持同一骨架才通过；否则减少绕线、压缩长收笔或拆开高风险连接。

不能实际完成三写时，必须在交付中写明“尚未通过真人三写验证”，并给出待测表，不得虚构测试数据。

### 6. 量化评分与定稿

先检查硬门，再按 `references/style-and-scoring.md` 的 100 分表评分。总分不能覆盖硬门失败。默认选 1 个主方案和 1 个备选，不把六张未经筛选的图全部甩给用户。

### 7. 制作教学材料

读取 `references/teaching-delivery.md`。至少包括：定稿图、分段下笔顺序、抬笔点、节奏说明、三写记录和练习纸。需要练习纸时运行：

```powershell
python scripts/build_practice_sheet.py --name "准确姓名" --variant-label "方案名称" --signature-image "定稿透明图.png" --output "签名练习纸.svg"
```

需要视频时提供真实书写演示或明确的拍摄脚本；不得把纯动画冒充真人书写。

### 8. 交付前验证

按 `references/delivery-checklist.md` 建立 `delivery.json`，然后运行：

```powershell
python scripts/validate_signature_delivery.py --delivery-dir "交付目录"
```

检查通过只说明文件、字段和三写证据齐全，不替代人工验字和用户本人试写。

### 9. 记录真实证据并进化

父服务中的服务 ID 为 `teachable-chinese-signature-design`。只记录成功状态、耗时、满意度和可复用性，不记录姓名、签名原图、身份证件或聊天内容。少于 3 个独立成功案例时保持“候选”；示例图、模拟测试和重复文件不算真实成功案例。

## 资料使用边界

六张用户资料已收入 `assets/reference-examples/`，来源、尺寸、哈希、用途和重复关系见 `manifest.json`，逐图判断见 `references/source-image-review.md`。

- 签名图片用于研究骨架、收笔、结构密度与教学风险，不自动视为字形正确或可重复书写。
- 宣传海报只用于研究微信竖版信息层级，不证明价格、免费范围、成交或服务效果。
- 私人姓名和笔迹未经权利人明确许可，不得公开展示、做广告或作为公共模板。

## 安全边界

读取 `references/safety-and-claims.md`。只为本人姓名或获得授权的姓名设计；不协助伪造他人签名、冒充身份、规避核验或制作欺骗性文件。本技能不提供签名法律效力意见，也不处理数字证书或密码学签名。
