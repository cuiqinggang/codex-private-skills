# 真人三写测试

## 测试条件

- 使用者：最终使用人优先；否则由设计者先做预测。
- 工具：使用者日常中性笔或签字笔。
- 尺寸：使用者平时实际签名大小。
- 环境：普通纸张，不临摹透明底图，不暂停描线。

## 通过条件

1. 三次都保持同一主骨架。
2. 没有新增或丢失关键识别笔画。
3. 没有一次因长飘带、回锋或绕线而卡死。
4. 三次在实际尺寸下都能被本人正确认出。
5. 速度适合目标场景；首次学习可慢，但不能依赖逐线描摹。

## 失败后的处理

- 抬笔过多：合并低风险连接，不能合并关键部件。
- 末笔失控：缩短收笔，保留方向而非长度。
- 三次形状漂移：减少回环或把复杂连接拆开。
- 字形错漏：返回验字卡，局部重画后重新三写。
- 无法进行真人测试：状态写“未测”，保留待测表，不填虚构数字。
