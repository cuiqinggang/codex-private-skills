# 字形完整性与局部返修

## 验字卡

```text
字符：
标准来源：用户正楷 / 可靠字典 / 已确认文本
左右或上下结构：
必须保留的识别笔画：
允许合并的连接：
禁止新增的装饰笔画：
高风险粘连处：
用户特别约束：
核验人和日期：
```

## 硬性检查顺序

1. 姓名字符数量和顺序是否一致。
2. 简繁体和异体是否混用。
3. 每个部件是否存在，关键笔画是否丢失。
4. 连线是否制造出额外部件或额外横、点等错觉。
5. 装饰尾线是否穿过主体，破坏识别。
6. 缩小到真实签名尺寸后还能否辨认。

## “崔”字案例约束

在本次用户明确指出的案例里，“崔”的“隹”部要保持四道横向笔意，出现第五道即失败。执行时用放大图逐条标注，不能把长收笔、回锋或装饰线误算成新的横画。

这是一条针对已确认案例的验收约束，不替代规范字形来源，也不能自动推广到未确认的异体字或书法体系。

## 局部返修

- 错一个部位，只修改该部位和与其直接相连的入笔、出笔。
- 已确认的人名顺序、主骨架、字距和收笔全部锁定。
- 修后重复完整验字，不只看被改区域。
- AI 整图重生成会引入漂移，除非全部方案被否定，否则禁止作为首选返修方式。
