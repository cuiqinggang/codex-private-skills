# 自动路由策略

- P1 强触发：明确寻找、推荐、比较、替换免费/公共 API 或无 Key 接口。
- P2 场景触发：开发任务明确缺少天气、地图、汇率、新闻、图片、音乐、电影、测试数据、地理编码、文件处理或机器学习等外部数据源。
- P3 建议触发：可能有帮助但非必要，只提示一次。
- P0 禁止触发：已指定唯一 API 且只需写/修代码；本地或离线数据足够；第三方服务增加明显隐私、合规或稳定性风险；请求绕过付费、认证、限速或访问控制；普通概念问题；预计节省不足 5 分钟。

必须结合语义判断，不因“接口”二字偶然出现而触发。自动调用仅限本地检索与官方文档复核；不得未经授权调用第三方 API。
