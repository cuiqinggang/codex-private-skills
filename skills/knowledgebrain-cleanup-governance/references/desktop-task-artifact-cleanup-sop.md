# Desktop Task Artifact Cleanup SOP

## Scope

${REDACTED_SECRET}

## Default classification

- `COLD_ARCHIVE_TASK_ARTIFACT`: task-named `.png` and `.py` files such as `step*`, `check*`, `verify*`, `grid*`, `click*`, `shot*`, `s1.py`, or a task-specific prefix.
- `KEEP_USER_SOURCE`: unrelated `.jpg/.jpeg`, source media, documents, archives, installers, shortcuts, and ambiguous files.
- `KEEP_ACTIVE`: directories, active repositories, launchers, runtime assets, and files referenced by shortcuts.
- `HUMAN_REVIEW_REQUIRED`: anything not provably generated by the finished task.

## Required gates

1. Read the previous Desktop cleanup report when available.
2. Inventory top-level Desktop metadata; do not recursively scan unrelated directories.
3. Check that durable scripts, final evidence, and lessons already exist in the relevant skill/project.
4. Generate the manifest before execution.
5. Review candidate count, extensions, bytes, time window, and name pattern.
6. Execute only `PLANNED` rows from that manifest.
7. Verify source missing and target present for every moved row.
8. Keep rollback commands in the manifest and write a final report.

## Safety defaults

- No permanent deletion.
- No automatic directory moves.
- No automatic JPG/JPEG moves because these are often user source images.
- No automatic ZIP, MP4, Markdown, JSON, executable, shortcut, or project-root moves.
- Recent files are movable only when the user explicitly says the just-finished task is complete and wants its clutter cleared.
- If a final evidence file is needed by a skill, copy it into that skill's acceptance/evidence folder before archiving the Desktop copy.

## Standard command

```powershell
# Plan first
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\desktop_task_artifact_cleanup.ps1 `
  -Since '2026-07-10T12:00:00' `
  -RunLabel 'desktop-cleanup-20260710-douyin' `
  -ManifestPath '<outputs>\desktop-cleanup-plan.csv'

# Execute only the reviewed manifest
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\desktop_task_artifact_cleanup.ps1 `
  -Execute -ManifestPath '<outputs>\desktop-cleanup-plan.csv'
```

## Acceptance

- Candidate count equals moved count plus documented skips/errors.
- Every `MOVED` row has `source missing = true` and `target present = true`.
- Protected files remain on Desktop.
- Final status is `PASS_CLEANED` or `PASS_CLEANED_WITH_SKIPS`.
