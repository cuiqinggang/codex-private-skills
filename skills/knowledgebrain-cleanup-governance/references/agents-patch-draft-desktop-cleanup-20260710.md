# AGENTS.md Patch Draft - Desktop Task Cleanup

When a finished task leaves many screenshots, step/check-number files, grids, crops, or one-off scripts on the Windows Desktop:

1. Route to `knowledgebrain-cleanup-governance`.
2. Read the last Desktop cleanup report and inventory Desktop top-level metadata.
3. Confirm durable scripts and final evidence already exist in the relevant skill/project.
4. Generate a manifest before moving anything.
5. Default to moving only task-named `.png` and `.py` files into a cold archive; preserve JPG/JPEG source images, directories, shortcuts, installers, archives, documents, media, and ambiguous files.
6. Execute only reviewed manifest rows, verify source/target state, and retain rollback commands.
7. Update the skill recent-use log, Obsidian skill note, and Knowledge Brain hot index.

This is a draft for future global adoption; it is not an automatic overwrite of the user's global AGENTS.md.
