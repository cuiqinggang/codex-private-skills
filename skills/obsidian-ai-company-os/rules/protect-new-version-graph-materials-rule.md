# Protect New Version Graph Materials Rule

## Purpose

Protect new-version graph, knowledge graph, graph motion, 满天星, and Obsidian-native deployment materials during legacy package purification.

## Hard Rules

- Do not classify new-version graph evolution materials as old failed assets.
- Do not place graph / knowledge_graph / 满天星 / graph_motion / visual-evidence / video-reference / native / plugin materials into DELETE-CANDIDATES.
- If uncertain, place the material into UNCERTAIN-HIGH-RISK or NEW_VERSION_KEEP_OR_REFERENCE, never DELETE-CANDIDATES.
- Judge by whether the material serves the new Obsidian-native route, not by whether it lives under assets.

## Large File Rule

Large PNG / JPG / contact sheet files may stay out of the C-drive core, but they must be preserved in H-drive protection archives or source package paths and indexed.
