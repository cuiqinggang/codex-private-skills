# Hermes SuperTool V2.2.1 双模型执行链

开工先读 [当前状态与回执](references/CURRENT.md)。Hermes v0.22.7 使用唯一正式执行模型 `deepseek/deepseek-v4.1-flash-20261017`，沿用已有 OpenRouter 配置、正式 CLI 和原生接续。GPT 负责定目标、独立审核及决策。需要 GPT 的审核、图片理解、视频理解或绘图时，由 Hermes 经获准的智能浏览器入口向指定已登录的 ChatGPT 网页派单，等待完成，读回并交付结果。

- Windows 严格按 V13.0.6 的 D→A→B→C，本次 D 为 Windows D 20261105-01。重连只验证本次新编号。保留已通过的节点，写入结果未知时先只读对账。
- 使用《三人行》第5版与《轻量状态持久化 V3》。完成当前对话能闭合的步骤；只有确实需要独立宿主时，向现有 n8n 交付一次并记录执行 ID。
- 常规辅助任务继承正式会话模型。委派走同一 1017 路线。审核以外部测试、业务产物、模型回执和会话 ID 为准。
- 网关恢复先核对进程、HTTP、WebSocket，再验证真实对话。跨 CLI 进程续跑、网关重启和整机重启分别记证据。
- GPT 网页服务验收覆盖 Hermes 发单、完成判定、原会话读回、结果校验和交付。用唯一任务标记核对一次提交。提交结果未知时，沿原任务和原会话只读对账。人工操作只作为网页能力诊断。平台阻止自动控制时登记阻塞，待指定网页的自动化入口获准后再实测。
- V2.1.0 的 7/10 为旧合同历史。四个旧 Profile 已归档，旧模型直连、Dashboard 角色切换、额外 Open WebUI 对话和 Hermes 内部跨模型委派退出当前合同。原 V2.0、V2.1 证据按需查阅。
