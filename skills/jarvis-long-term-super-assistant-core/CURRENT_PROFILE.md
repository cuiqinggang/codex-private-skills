## 当前三个核心

```text
1. MEMORY
2. RELIABLE_AUTOMATION
3. EXTREME_TIME_CONVERGENCE
```

### MEMORY
目标是：
- 个人长期记忆；
- 项目长期状态；
- 经验 / 教训；
- 已验证技能与现实证据；
- 世界上已经解决问题的可检索外部记忆。

当前结论：这是 JARVIS 与普通一次性执行 Agent 产生长期差异的核心之一，尚需继续形成最小现实实现。

### RELIABLE_AUTOMATION
已有 Codex / n8n / ECC 长流程等现实经验可复用。
当前不重新造自动化引擎；重点是把现有成熟能力组合成可持续、可恢复、可验证的任务运行方式。

### EXTREME_TIME_CONVERGENCE
继续以 v5.6.5 为母方法：
`T*=min(T_VALID)`。
