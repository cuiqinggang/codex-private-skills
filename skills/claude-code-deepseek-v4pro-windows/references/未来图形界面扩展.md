# 未来图形界面扩展

本技能当前只验证了 Windows 原生 Claude Code CLI 到 DeepSeek V4 Pro 的链路。

未来如果要加入 Claude Code 图形界面安装、桌面版配置、IDE 扩展、浏览器登录态或 GUI 验证，必须新增一轮独立实测，不能直接把未验证经验写成已通过流程。

## 新增 GUI 流程时的要求

1. 明确 GUI 产品名称、官方安装来源和版本。
2. 区分 CLI 环境变量和 GUI 配置存储位置。
3. 不修改 Codex 桌面版配置，除非用户明确要求。
4. 不复用或泄露 DeepSeek API Key。
5. 使用桌面可见性流程验证界面状态：
   - 优先可访问性快照。
   - 需要布局证据时截图。
   - 操作后重新观察确认。
6. 每一步继续使用 Gxx gate 格式：
   - purpose
   - execution location
   - exact command 或 GUI 操作
   - success criteria
   - failure criteria
   - failure recovery
   - continue or stop
7. 把 GUI 实测报告保存到 `references/`，再更新 `SKILL.md`。

## 暂定新增 gate

- G09：确认 GUI 官方来源。
- G10：检查是否已有 GUI 安装。
- G11：安装或确认 GUI。
- G12：配置 DeepSeek API。
- G13：GUI 最小 prompt 验证。
- G14：GUI 项目目录或工作区验证。
- G15：更新本技能包并重新验证。
