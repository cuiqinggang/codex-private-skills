# 素材清单 v1.3

## 关键人物

### 妈妈

- 年轻漂亮；
- 生活化；
- 体面干净；
- 被学习和辅导费逼到破防；
- 不能像刻板凶妈妈，也不能像文艺片里过度克制的妈妈。

### 孩子

- 小男孩；
- 委屈、想学但不会；
- 后段不是突然狂喜，而是“终于听懂了”的轻松。

## 关键道具

### 辅导费账单

必须像真实收据/付款凭证。

必须一眼可见：

- 辅导费
- 3000 / ¥3000
- 已支付 / 收费凭证 / 课程费用

辅助细节：

- 某某教育
- 课时包
- 课程名称
- 订单号后四位
- 付款时间
- 支付方式

禁止：

- 白纸写“辅导费3000”
- 明显假道具
- 过度干净的模板纸

### 作业本

- 有红叉；
- 有擦改痕迹；
- 有孩子卡住的题；
- 能承载 AI “题眼、思路、错因”三招。

### 手机

- 是 AI 出手载体；
- 3 秒左右压到题上，动作像高手落掌。
