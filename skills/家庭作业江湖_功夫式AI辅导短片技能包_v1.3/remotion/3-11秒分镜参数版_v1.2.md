# 3-11 秒 Remotion 分镜参数版 v1.2

## 0. 技术基准

- 画幅：1080×1920
- 帧率：30fps
- 总片长：15s
- 本文件覆盖：3.0s-11.0s
- 视觉风格：真实家庭作业桌面 + 墨迹功夫点穴 + 克制 AI 界面
- 主色情绪：3-6s 冷暗压迫；6-9s 墨迹高光；9-11s 暖光回归
- 镜头语言：不是软件演示，是高手出招

---

## 1. Remotion 层级规范

每个镜头建议使用以下层级：

1. `BG_LiveDesk`：真实作业桌 / 暗光 / 雨夜窗影
2. `HomeworkPaper`：作业纸主体
3. `PhoneFrame`：手机或拍题框
4. `InkScanLayer`：墨迹扫描线 / 字符吸入
5. `AcupointLayer`：红色墨点 / 题眼圈注
6. `PathLayer`：已知 → 要问 → 方法 石阶路径
7. `ExplanationLayer`：一句人话讲解
8. `ErrorLayer`：错因点穴
9. `SubjectFlashLayer`：语文 / 数学 / 英语闪影
10. `SubtitleLayer`：短字幕
11. `SoundCueMarkers`：音效节点，不渲染，仅用于同步

---

## 2. 3-11 秒总结构

> 一拍 → 看清题 → 点题眼 → 拆成路 → 讲人话 → 点错因 → 三科闪影 → 孩子听懂

## 4. 字幕安全区

- 字幕主位置：底部居中，y=1510，宽度不超过 860px。
- 避开平台 UI：底部至少留 230px 安全距离。
- 单屏字幕不超过 11 个汉字，特殊句子最多 14 个汉字。
- 字幕不能像讲课课件；需要像电影短句。

---

## 5. 字体建议

### 字幕
- 使用有力量但不办公的黑体/标题体。
- 可选：站酷酷黑、思源黑体 Heavy、阿里巴巴普惠体 Heavy。
- 避免：宋体、仿宋、楷体、微软雅黑常规字重。

### 题眼/错因
- 可用手写感批注字体，但必须清楚。
- 不能太卡通。

## 7. 失败判定

只要出现以下任一情况，本段失败：

1. 看起来像软件功能介绍。
2. 画面像 PPT。
3. 观众记不住“一拍开路”。
4. AI 只是在给答案，没有讲路径。
5. 家长痛点没有被解决。
6. 语文数学英语平均铺开导致主线松散。
7. 特效比问题解决本身更抢眼。
