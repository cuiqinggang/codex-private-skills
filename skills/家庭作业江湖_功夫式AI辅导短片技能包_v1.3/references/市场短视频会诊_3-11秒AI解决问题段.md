# 市场短视频会诊：3-11 秒 AI 解决问题段

## 1. 会诊结论

3-11 秒不能做“功能菜单”，而要做“方法有效的瞬间证明”。

短视频中段最怕平均展示：
- 识题
- 批改
- 语文
- 数学
- 英语
- 讲解
- 错题本

这样会变成 PPT 或软件说明。观众会觉得“信息很多，但没有记忆点”。

本项目必须压成一个可记忆动作：

> 一拍开路。

---

## 2. 成熟短视频钩子复用

### 成熟结构 A：痛点压迫 → 一个动作 → 立刻看到变化
复用方式：
- 妈妈崩溃、孩子抹泪是痛点压迫。
- 手机“啪”一下拍题是动作。
- 题眼、路径、错因出现是变化。

### 成熟结构 B：不要解释能力，直接展示结果
复用方式：
- 不说“AI 支持智能识别”。
- 直接让关键字被圈出。
- 不说“AI 能生成思路”。
- 直接让乱线变成“已知 → 要问 → 方法”。

### 成熟结构 C：一个主证明 + 两个辅助闪影
复用方式：
- 主证明：数学应用题完整拆一遍。
- 辅助闪影：语文和英语只出现快速证据，不抢主线。

---

## 3. 本项目不采用的广告套路

| 广告套路 | 为什么不用 |
|---|---|
| 三栏功能展示 | 像 PPT，不像电影 |
| 蓝色科技 HUD | 太常见，缺少家庭作业江湖气质 |
| 机器人老师形象 | 容易幼稚，也削弱真实可信度 |
| 大段口播 | 15 秒无法承载 |
| 直接出答案 | 容易被理解成替孩子写作业 |
| “提分快”口号 | 太像培训广告，缺少艺术性 |

---

## 4. 最终创意压缩

### 观众看到的
手机拍题，AI 点出题眼，乱题变成路径，错因被点出来。

### 观众记住的
AI 能把乱题理成孩子听得懂的路。

### 观众相信的
它不是花架子，因为它展示的是“题眼、路径、错因”，不是空喊口号。

---

## 5. 导演原则

1. 只保留能证明“有用”的画面。
2. 只保留孩子和家长真实需要的结果。
3. 每个视觉元素都要服务“乱题成路”。
4. 不能让视觉炫技抢走“讲清楚”的核心。
