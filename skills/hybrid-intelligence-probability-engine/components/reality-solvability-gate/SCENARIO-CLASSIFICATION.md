# 现实可解性示例

分类看“任务目标 + 已有成熟解决路径”，不看题目听起来是否高科技。

| 任务例子 | 分类 | 原因 |
|---|---|---|
| 读取一万份文件并按规则提取/汇总 | 成熟组合解 | 文件解析、检索、并行、汇总、验证都有成熟方案 |
| 根据预算、距离、偏好选择餐厅 | 成熟组合解 | 属于成熟检索 + 多条件决策 |
| 第一次接触某个成熟软件部署 | 成熟直接/组合解 | 对我们陌生不等于现实未知 |
| 用已有航天器平台设计常规卫星任务 | 成熟组合解 | 可由成熟工程子系统与验证流程组合 |
| 未探索洞穴的测绘 | 成熟探索任务 | 地形状态未知，但测绘/定位/安全探测方法成熟 |
| 未知深海区域调查 | 成熟探索任务 | 环境未知，但声呐/采样/导航/建图流程成熟 |
| 解释核聚变原理 | 成熟直接解 | 已有成熟理论知识 |
| 设计基于成熟托卡马克路线的实验计划 | 成熟组合/探索任务 | 方法体系存在，实验结果仍需测量 |
| 要求证明一个当前仍未解决的数学猜想 | 前沿未知候选 | 完成证据检索后若确无成熟证明路径，属于前沿研究 |
| 要求发明超出现有验证物理的新推进原理 | 前沿未知候选 | 无成熟直接/组合/探索闭环时才成立 |
| “帮我做得最好”但不给目标、约束、验收标准 | 信息不完整 | 不是未知，只是规格不足 |

注意：
同一个领域可以同时包含成熟任务和前沿未知任务。
“核聚变”“航天”“数学”“洞穴”这些名词本身不能决定分类。
