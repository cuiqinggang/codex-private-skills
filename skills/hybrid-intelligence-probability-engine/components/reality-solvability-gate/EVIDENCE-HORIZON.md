# 成熟方案证据范围 v0.1.0

“世界上没有解”无法由一次普通搜索绝对证明。

因此引擎禁止使用绝对表述：
`世界上不存在解决方案`。

只允许使用：

**在当前冻结证据范围内没有发现成熟闭环解。**

## H=1 的最低条件

只有以下检索层全部完成，才允许：
`evidence_search_complete=true`

1. 本地 Reality Foundation / 历史 Reality Delta；
2. 共同技能库与已有成熟任务族；
3. 已知成熟软件、算法、标准、工程组件；
4. 与任务直接相关的权威公开文档/论文/标准/供应商资料；
5. 可组合成熟部件的闭包搜索；
6. 若关键未知是环境状态，则检查是否存在成熟探索/测量协议；
7. 候选方案均完成输入/输出/依赖/验证合同审查。

如果这些没有做完：

`SOLUTION_SEARCH_REQUIRED`

而不是：

`FRONTIER_UNKNOWN`。

## 时间戳

前沿未知判断必须带：
- evidence horizon version；
- 检索日期；
- 检索范围摘要。

新证据出现后允许重新分类。
