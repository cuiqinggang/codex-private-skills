# 混合智能概率引擎 v0.3.2

## 核心目标

现实世界已经有成熟解决方案的任务，不重新发明。

现实世界可以由成熟方案组合闭环的任务，不标成未知。

未知环境但已有成熟探索/测量协议的任务，不标成未知。

只有真正缺少成熟直接解、成熟组合解和成熟探索协议的前沿任务，才进入前沿研究模式。

在所有有效硬门通过后，仍以：

`T* = min(T_VALID_E2E)`

作为执行方案竞争的唯一时间目标。

## 未注册任务族

“未注册”只表示当前没有冻结快路径模板。

第一次遇到但现实已解决的任务：

→ 查成熟方案；
→ 组合成熟部件；
→ 高智能模型只承担必要的方案编译/残余推理；
→ 编译时间计入完整 T_VALID；
→ 完成 Verifier。

若该任务族重复出现且验证稳定：
→ 回“虚”冻结为新的确定性快路径；
→ 后续不再支付在线组合/编译时间。

- 无未解决科学依赖；
