`未注册/未知任务族 → 直接 Full-GPT`

```text
未注册任务族
→ 现实可解性判定
→ 成熟直接解 / 成熟组合解 / 成熟探索任务
→ 成熟方案组合编译
→ 正向拆解

```

```text
规格完整
+ 成熟方案证据检索完成
+ 物理/逻辑允许
+ 无成熟直接解
+ 无成熟组合闭环
+ 无成熟探索协议
```

才允许：
`前沿未知`。

## 关键解释

- 对我们陌生 ≠ 现实未知；
- 没有注册快路径 ≠ 现实未知；
- 没完成搜索 ≠ 现实未知；
- 环境状态未知 ≠ 方法未知；
- 没有单一现成方案 ≠ 无法由成熟方案组合；
- 真正未知只保留给当前证据范围内没有成熟闭环路径的前沿问题。

## 下一步对新任务的实际处理

新任务第一次进入：
1. 先查成熟直接解；
2. 再做成熟组件闭包搜索；
3. 若关键未知是环境状态，查成熟探索/测量协议；
4. 找到闭环后组合执行；
5. 再按 CODE/JEV/GPT 做正向拆解；
6. 所有在线检索/组合/编译时间都计入本次 T_VALID；
7. 重复稳定任务族再冻结快路径。

这使引擎优先“站在成熟方案肩膀上”，而不是把陌生任务一律交给 Full-GPT。
