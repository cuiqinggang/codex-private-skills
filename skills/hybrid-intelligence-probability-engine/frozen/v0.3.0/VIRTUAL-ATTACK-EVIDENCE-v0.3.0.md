# 混合智能概率引擎 v0.3.0 — 虚拟攻击与淘汰证据

## 已发现并修复的问题

1. **历史 JEV 收益误当本轮收益**：已纠正。JEV v0.4.0 的 560.9819 ms 只作为历史现实锚点。
2. **旧 48 节点预先带路由标签**：已纠正。完整时间从原始任务开始，正向编译时间进入 Hybrid T_VALID。
3. **正则 residual 可被代码机械完成**：已删除，改为 8 个自然语言 SQL 构造任务，由 SQLite 独立验证。
4. **每次先用 GPT 在线拆解会产生串行高延迟税**：已淘汰；已认证任务族改为冻结确定性编译器。
5. **先用 JEV 做全局 router 也增加串行屏障**：已淘汰；JEV 直接承担已识别 Choice 节点并与 GPT residual 并行。
6. **Full-GPT/Hybrid 双跑竞速破坏成本门**：已淘汰，只做认证 A/B，不做生产双跑。
7. **JEV v0.5.0 过度压缩语义合同**：历史现实 0/30，明确禁止复用该语义删减路线。
8. **JEV v0.5.1 虽保持语义但没有现实提速**：历史现实 30/30 有效、min=956.2431 ms，未打败 v0.4.0 560.9819 ms；当前核心继续 v0.4.0。
9. **成本基线最初漏掉 Full-GPT 必须承担的 32 个 JEV 等价决策问题**：已重新按 Reality runner 公平 payload 计算；旧 2.624x 成本代理作废。

## 正向拆解攻击

- 10 个形式硬条件：2^10=1024 种组合，1024/1024 PASS；
- 128 个已认证任务族边界案例：128/128 PASS；
- 192 个结构/schema 变异攻击：192/192 PASS；
- 不能证明安全进入 JEV 的情况全部 fail-closed 到 GPT。

## SQL residual 攻击

- 8 个不同关系型查询结构；
- 64 个合法/非法 SQL 验证/失败注入：64/64 PASS；
- 只允许单个 SELECT/WITH；
- 拒绝 DELETE/INSERT/UPDATE/DROP/ALTER/ATTACH/PRAGMA/CREATE/VACUUM/REPLACE 以及多语句。

## 当前不能由虚阶段证明

- GPT 真实 30/30 SQL 生成；
- JEV 本轮真实延迟；
- OpenRouter provider/网络抖动；
- 真正 usage.cost；
- 同会话交替 A/B 的完整真实 T_VALID。

这些被明确留给 Reality，不使用 mock 冒充 PASS。
