# 系统进化执行策略

## 初始阶段

默认 `Approval` 模式。每两小时自动生成报告、提醒和待执行方案，但不修改生产系统。

## 自动阶段

用户明确授权后可改为 `Auto` 模式。`Auto` 仍只允许：

- 生成报告和日志。
- 更新 output 目录内状态。
- 同步 `H:\AI_System_Evolution` 下的副本。
- 生成 Codex/Hermes 验证任务。
- 执行不会修改生产配置的本地验证脚本。
- 处理公开视频/RSS 视频来源。
- 在用户已明确下达视频情报任务后，只读浏览已登录视频账号的关注流并保存证据。

## 视频来源任务级授权

用户已经明确要求把抖音、YouTube、TikTok、Bilibili 等视频来源纳入系统进化后，视为任务级授权。只读浏览、截图、记录标题/作者/链接/公开热度、字幕转写和摘要不需要逐条等待批准。

停止条件：

- 点赞、关注、评论、私信、收藏、发布或修改账号。
- 绕过验证码、账号安全提示或平台限制。
- 长期后台刷流。
- 付费墙、隐私内容或非公开内容。

## 永远需要批准

- 修改 Hermes 主配置。
- 修改 Codex 全局 AGENTS.md。
- 修改 Open WebUI 配置。
- 安装长期服务。
- 创建或修改非本 skill 的 Windows 定时任务。
- 改动 H 盘正式 skill。
- 使用付费 API、账号密钥、Cookie 或 Token。
