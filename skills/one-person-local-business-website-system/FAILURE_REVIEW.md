# Failure Review

## 已知失败模式

| 失败模式 | 防复犯门禁 |
|---|---|
| 把采集数量当业务成果 | 以合格率、回复率、成交率、毛利和续费率验收 |
| 给所有线索做完整网站 | 70 分以上才研究；单条演示限 30—60 分钟 |
| AI 自动群发或无审核外联 | 只生成草稿；逐条人工事实核验和批准；不代发 |
| 用无来源事实写文案 | 商家研究卡的每个事实绑定来源和采集日期 |
| 使用公开但未授权的图片 | 仅用授权素材、正规图库或占位视觉 |
| 演示冒充正式官网 | 标注非官方概念演示、noindex、关闭支付和真实表单 |
| 保证排名、流量或收入 | 只承诺具体交付物、测试标准和合理优化过程 |
| 范围失控与无限修改 | 提案明确不包含项、轮次、变更报价和付款节点 |
| 只验漂亮截图 | 必做功能、跨设备视觉/内容、真实用户任务三轮验收 |
