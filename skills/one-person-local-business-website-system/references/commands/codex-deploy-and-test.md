# Codex 任务：部署“一人公司海外本地商家网站获客与交付系统”

你要在 C 盘日常工作区建立可运行版本，不要写入 K 盘，除非最终备份。

## 目标

把本技能包实现为一个本地中文工作台，支持：

1. 创建目标市场项目；
2. 导入/手工录入 CSV 线索；
3. 自动计算 100 分线索评分；
4. 生成商家研究卡；
5. 管理来源证据；
6. 生成但不自动发送个性化外联草稿；
7. 管理 4 次以内跟进；
8. 生成演示站需求书、提案和交付清单；
9. 记录三轮测试截图；
10. 输出项目报告和 ZIP。

## 安全硬规则

- 不实现未经允许的 Google Maps 抓取绕过。
- 不自动群发邮件或私信。
- 所有外联必须经过人工点击批准。
- 不使用私人联系人数据。
- 演示页面默认 noindex，并显示“非官方概念演示”。
- 不伪造评价、案例或商业结果。

## 实现要求

- 中文 UI；
- 本地优先；
- SQLite 或 JSON 数据库；
- 可导入/导出 CSV；
- 评分规则可配置；
- 线索去重；
- 来源和时间戳；
- 模板变量校验；
- 审核状态机：草稿→待审核→批准→已发送（只记录，不代发）；
- 完整日志、错误处理、备份和恢复。

## 三轮实测

### 测试 1：功能
建立 20 条模拟线索，验证导入、评分、筛选、研究卡、模板、导出。

### 测试 2：质量
随机抽取 5 条，确认所有事实来自证据，不出现幻觉、错商家、错城市、错链接。

### 测试 3：真实工作流
用一个公开行业目录中的 3 家商家做“仅研究、不联系”的演练，完成从线索到概念需求书全流程，保存截图。

## 最终交付

- 源码
- 启动脚本
- 中文说明
- 测试报告
- 截图证据
- 风险清单
- 回滚说明
- 将全部成果打包成桌面唯一递增三位编号 ZIP
