# Executable Lesson Extraction

## Core Rule

不要把“AI 建站”当作产品；把“识别高意向本地商家 → 诊断数字化损失 → 低成本展示改善 → 固定范围真实交付”做成服务系统。

## Reusable Lessons

- 用单一国家、行业、城市和结果约束首轮验证。
- 线索先评分再投入演示成本；70 分以下不进入深度制作。
- AI 辅助研究和写稿，人负责事实、版权、商业判断和外联批准。
- 概念演示用于降低信任成本，不是未授权正式官网。
- 客户购买的是电话、导航、预约、询价和可信度，不是技术栈。
- 成交后用范围、付款节点、修改轮次和权属控制风险。
- 交付必须通过真实任务验收，不能只看截图。
- 用维护、内容、本地 SEO/AEO 和自动化延伸复购，但不承诺排名或收入。
