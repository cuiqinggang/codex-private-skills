# Rule Patch - CASE-013 Executable System

## Trigger

当任务包含海外本地商家网站、Google Maps 获客、样站外联、本地服务商建站、Lab 305 或 CASE-013 时：

1. 先由 `one-person-ai-company-success-routes` 选择 CASE-013。
2. 再加载 `one-person-local-business-website-system` 执行细节。
3. 开工前先读合规边界、SOP、评分和失败复盘。
4. 研究与模板阶段不需要账号、密钥或真实发送。
5. 所有外联只生成草稿；未经用户明确授权，不发送任何外部消息。
6. 正式网站完成前不得以 PASS 交付；必须保留三轮验收证据。

## Acceptance

- 父技能可路由到子技能。
- 子技能 frontmatter 有明确触发词。
- 线索、研究、外联、提案、验收和合规资源均可定位。
- 原始 ZIP 哈希可复核。
- Knowledge Brain 与 Obsidian 有长期入口。
