# 未来 HTML 最小运行页规范｜本版本只冻结逻辑，不实现

## 1. 页面目标

本地、无服务器、无账号、无API。只把当前手工复制粘贴流程放到固定位置，自动继承数据、计时、检查空输入并导出答案包。

## 2. 页面顺序

1. 粘贴原始问题。
2. 复制 A_Initial 提示词到新的 GPT 会话；粘贴 A_Initial 回页面并封存。
3. 复制同一个 A 层统一极限提示词，依次粘贴到 GPT、Qwen、DeepSeek。
4. 分别粘贴三个模型的完整 A 回复；页面自动提取 Raw、Final 和压力记录。
5. 页面自动生成 B 层完整提示词；复制到新的 GPT 会话。
6. 粘贴 B 层完整回复；页面自动提取 B_Final 和强点记录。
7. 页面自动生成 C 层完整提示词；复制到新的 GPT 会话。
8. 粘贴 C 层完整回复；页面突出展示并提取 C_Final。
9. 页面自动生成匿名最终评测输入包；复制到新的 GPT 会话。
10. 粘贴最终评测报告，导出完整答案与证据包。

## 3. 一次输入、自动继承

```text
原始问题自动进入A_Initial、A、B、C和最终评测；
三份A_Final自动进入B；
B_Final自动进入C；
全部答案和运行数据自动进入最终评测；
任何数据不得要求用户重复粘贴。
```

## 4. 依赖失效

- 修改原始问题：A_Initial、A、B、C、评测全部失效；
- 修改A_Initial：仅最终评测失效；
- 修改任意A：B、C、评测失效；
- 修改B：C、评测失效；
- 修改C：评测失效。

页面必须明确提示“下游结果已过期”，不得静默沿用。

## 5. 人工剪贴板动作基线

无API最小页面预计：

```text
页面复制提示词：5次；
提示词粘贴到模型：7次；
从模型复制结果：7次；
结果粘贴回页面：8次；
合计：27次剪贴板动作。
```

## 6. 必备检测

```text
空输入阻断；
开始/结束标记检查；
命令包回显检测；
结果区块缺失检测；
自动计时；
复制/粘贴/返工计数；
本地保存和恢复；
导出TXT、Markdown、JSON和ZIP答案包。
```

```text
不接API；
不做多用户；

不自动调用模型；
不把测试页面扩展成复杂工程。
```
