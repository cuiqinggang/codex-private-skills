# Distillation Runbook

1. Treat installed editors as references and optional tools, not dependencies.
2. Start from a user-facing feature, not from a tool name.
3. Decide whether the feature needs GUI judgment.
4. If not, implement with FFmpeg, Whisper, Auto-Editor, PySceneDetect, Python,
   PowerShell, or Remotion.
5. Save scripts only after they run on sample assets.
6. For every rendered result, verify streams and generate a preview/contact
   sheet before claiming PASS.
7. Update `FEATURE-MAP.md` when a new editor feature is tested.
8. Preserve legal boundaries: no cracked packages, paid template copying, or
   proprietary asset extraction.

## Good Distillation Targets

- automatic subtitles
- subtitle burn-in
- silence removal
- rough cut
- clip trim/join
- social vertical export
- audio mix/fades
- cover extraction
- contact sheet and QA
- batch platform package generation

## Poor Distillation Targets

- manual taste decisions
- proprietary effect packs
- paid stock templates
- account-gated AI effects
- anti-watermark or payment bypass
- anything requiring private platform actions
