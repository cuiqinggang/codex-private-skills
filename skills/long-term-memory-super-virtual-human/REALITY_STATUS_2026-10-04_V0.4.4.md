## v0.4.4 的正式变化

页面生命周期不再由“压缩几次再换页”或多套 supervisor 分别管理，而统一进入一套外部连续性控制链：

```text
页面增长 / 阶段结束 / 历史断连 / UI异常 / 无进展 / 活跃turn卡死
→ 统一观察与只读 probe
→ 若后台仍推进：继续等待原结果
→ 若确认停滞或到预防阈值且存在安全 checkpoint
→ 必要时停止旧 turn
→ checkpoint
→ 真正 New chat
→ 最小 handoff
→ exactly-once
→ ACK
→ 新会话接管
```

同页总结只用于形成可接续状态，不被视为真正释放上下文。
