# 长期记忆超级虚拟人｜恢复阶梯 v0.1

```text
L0 当前会话正常执行
↓
L1 最小重试
↓
L2 Checkpoint + 新页面恢复
↓
L3 工具主路切备路
↓
L4 换成熟等价执行器
↓
L5 GPT 不可用 → 独立强备份
↓
BLOCKED：持久化状态并等待依赖恢复
```

## Checkpoint 最小内容

- TASK_ID；
- 当前任务合同版本；
- 最终现实目标；
- 已完成；
- 未完成；
- 当前状态；
- 失败路径与根因；
- 当前工具/连接状态；
- 下一步唯一动作；
- 关键文件、Commit、Run ID、Artifact ID；
- FLOW_START 与当前时间轴状态。

恢复不是重新规划一个新项目，而是从最近可信状态继续原任务。
