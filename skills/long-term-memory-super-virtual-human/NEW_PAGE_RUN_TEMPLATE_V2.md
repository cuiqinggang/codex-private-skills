# 《新页面运行模板 第2版》

版本：2.0  
状态：CURRENT / 当前版

## 启动顺序
执行《人工单页面极限短时间引擎 当前版》。

依次读取：
1.《极限短时间执行大脑 当前版》
2.《当前任务目标与正反约束 当前版》
3.《当前任务冻结状态 第N版》
4.《新页面运行模板 当前版》

## 单页执行
- 先基于冻结状态刷新当前节点判断，不重复已冻结工作。
- 每个 CEO 页只完成一个自然逻辑节点，或为完成该节点不可分割的必要并行节点组。
- Reality 必须从合法 READY_STATE 开始，测试器只观察，不代替正式任务。
- 唯一优化标准：T*=min(T_VALID)；先满足 VALID，再比较时间。
- Reality 完成后，无论 PASS 或 FAIL，都必须把本页事实、证据、时间、失败边界、下一唯一节点冻结为《当前任务冻结状态 第N+1版》。

## NEXT_PAGE_PROMPT
- 冻结完成后，必须生成唯一 NEXT_PAGE_PROMPT。
- NEXT_PAGE_PROMPT 必须足以让下一 CEO 页无需依赖本页隐含上下文即可继续：包含读取顺序、任务、冻结事实、本页唯一目标、硬约束、验收标准和页面结束条件。
- 不得同时生成多个互相竞争的下一页提示词。

## 强制页面结束门禁
**生成 NEXT_PAGE_PROMPT 文件不等于交付完成。最终回复必须原样完整输出唯一 NEXT_PAGE_PROMPT，使用户无需打开任何文件即可直接复制进入下一 CEO 页。未输出正文则 CEO_PAGE_COMPLETE=NO。**

只有同时满足以下两项，当前 CEO 页才允许结束：
1. NEXT_PAGE_PROMPT 已持久化并完成回读核验；
2. 最终回复已原样完整输出同一份唯一 NEXT_PAGE_PROMPT 正文。

其余未修改规则继续继承《新页面运行模板 第1版》。
