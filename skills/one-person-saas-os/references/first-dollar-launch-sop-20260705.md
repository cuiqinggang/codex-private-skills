# First Dollar Launch SOP

## Goal

Turn a tiny AI-built SaaS into the first paid overseas order with minimum infrastructure and maximum learning.

## Workflow

### 1. Capture Demand From Existing Attention

Look for places where users are already asking "how do I do this?" or showing friction:

- Comments under viral posts.
- X/Twitter search results.
- Product Hunt, Reddit, Discord, GitHub issues, YouTube comments.
- Competitor pages with downloads, likes, comments, or reposts.

Record:

| Signal | Evidence | Link | Count/Heat | User Pain |
|---|---|---|---:|---|
| Comment asks how to make X |  |  |  |  |

### 2. Validate Topic Heat Before Building

Search the product keyword and adjacent trend terms on X/Twitter, Reddit, Product Hunt, Hacker News, YouTube, and Google.

Minimum evidence:

- At least 5 recent posts or discussions.
- At least 1 competitor/example already getting attention.
- At least 1 clear user pain that the product simplifies.

### 3. Build The Smallest Paid Wedge

Reduce the user's workflow to one obvious promise:

`Input -> transformation -> output`

Example absorbed from the case:

`one photo -> personalized desktop pet -> downloadable result`

Use the best available model for the core output if quality determines conversion. Cheaper models are only acceptable when quality remains good enough.

### 4. Prepare Payment Approval Surface Before Applying

Before Paddle, Creem, Stripe, or any merchant-of-record/payment application:

- Product page is live.
- Service description is clear.
- Pricing or payment expectation is clear.
- Privacy policy exists.
- Terms of service exists.
- Refund/cancellation policy exists.
- Contact method exists.
- Delivery/access method is clear.
- No placeholder pages.

Applying too early can cause rejection and extra review.

### 5. Choose Payment Route

Preferred practical options for overseas-first tiny SaaS:

| Route | When To Use | Notes |
|---|---|---|
| Paddle | Want merchant-of-record handling for tax/VAT and digital products | Can reject weak/unfinished sites. Prepare policies first. |
| Creem | Indie digital-product/SaaS experiments | Check availability, fees, and category fit before relying on it. |
| Stripe | You have a supported jurisdiction route, bank/payout route, and clean website | Requires KYC and accurate business information. Add in v2 after v1 is stable. |

### 6. Launch Where Attention Already Exists

Do not rely only on posting from your own empty account.

X/Twitter first-dollar tactic:

1. Search competitor/trend keyword.
2. Find posts where people are showing the same object/result.
3. Reply with a useful, specific comment.
4. Show your generated result as proof.
5. Mention that users can make the same thing with one input.
6. Link only when natural and platform-safe.
7. Repeat 8-10 high-context comments in one day.
8. Track views, clicks, signups, and payments.

### 7. Ride A Related Live Trend

If direct product keywords are not enough, connect the product to a current public topic.

Template:

`[hot person/event/object] + [your product transformation] + [short vivid line] + [link/demo if allowed]`

Rule: the trend must genuinely fit the product output. Avoid spam and unrelated hijacking.

### 8. Measure First-Dollar Loop

Track:

| Date | Platform | Post/comment URL | Angle | Views | Clicks | Signups | Orders | Lesson |
|---|---|---|---|---:|---:|---:|---:|---|
|  |  |  |  |  |  |  |  |  |

### 9. Decide Whether To Continue

After first orders:

- If orders come with low effort, improve product and repeat distribution.
- If traffic comes but no payment, fix offer/pricing/output quality.
- If no traffic, improve topic selection and distribution angle.
- If account/payment review blocks, fix website trust surface and compliance route.

## Hard Lessons

- Product judgment beats raw coding speed.
- Topic heat matters before feature depth.
- The best model is worth it when output quality is the product.
- Payment rails should be applied after website readiness, not before.
- First traffic often comes from comments under existing attention, not your own cold post.
