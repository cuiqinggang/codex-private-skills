# 微信 AI 免费服务发现与进化

从真实微信需求出发，建立持续生长的免费服务系统。直接服务对象以中年微信联系人为主，也允许他们带来与子女、父母、工作、店铺、车辆和家庭生活有关的需求。

## 固定方向

- 以免费做出有用结果和发现真实需求为目标，不以收入为目标。
- 接受普通微信文字、语音、截图、照片或文件作为输入。
- 远程交付一个完整的小结果，默认不引入上门服务。
- 用日常中文说明结果，不向服务对象推销模型、提示词、智能体或工作流。
- 可以准备微信文案，但必须由用户检查并手动发送；绝不自动群发。
- 与本服务无关的极限答案流程不得混入。
- 保持较宽的候选服务池；只有真实使用证据足够，才提升服务等级或主动推广。
- 面向老河口等普通小城市时，向居民和商户展示完整服务结果，不展示几十个“生成器”或模型功能。后台可以保留细分能力，前台必须合并成少量清楚入口。

## 核心闭环

### 一、理解一个真实需求

提取：

- 直接请求者和真正受益者；
- 已经具备的原始材料；
- 对方想拿到的可用结果；
- 是否可以远程交付；
- 是否涉及隐私或高风险问题。

最多只问一个会阻塞执行的简短问题。其他情况下，采用可撤销的合理假设并立即开始。

### 二、匹配或评估服务

读取 `references/service-priority.md`，再搜索 `references/seed-services.json` 或已初始化的服务登记表。

- 已有接近服务时，复用其输出形式与检查清单。
- 新需求先评分，再决定是否加入候选池。
- 对要求诊断、法律定论、冒充、欺骗、作弊、违规内容或不必要敏感数据的请求，拒绝或缩小到安全范围。

同时满足下列条件时优先提供：能免费交付完整小结果；结果有直观实际价值；AI 明显降低难度或时间；同一流程能重复服务多人；仅凭微信材料即可完成，无须上门。

### 三、制作最小但完整的结果

能制作可用成品时，不要只给建议。例如：

- 直接修好一张照片，而不是只讲照片修复原理；
- 把学校通知整理成待办，而不是只讲如何规划；
- 完成一张可用海报，而不是只列设计技巧；
- 把语音整理成干净文字，而不是只教转写方法。

根据实际文件或成品类型调用对应内置技能。保留原件，并明确区分“基于事实的修复”和“AI 推测式重建”。

需要把设计图、网页截图或图片稿复刻成可分享网页时，读取 `references/static-showcase-webpage.md`。必须制作真实 HTML/CSS/组件结构，不能把整张设计图作为网页背景或唯一图片。只要求观看时，不添加虚假点击功能；电脑和手机默认使用同一个响应式网址。

处理趣味照片或家庭回忆再创作时，读取 `references/photo-memory-fun-remix.md`。需要复刻“老油条”案例时，同时读取 `references/oil-stick-case-study.md` 和 `references/oil-stick-prompt-pack.md`。

需要从已筛选的家庭、婚礼、儿童、趣味人物、头像、节日或小商家模板中选择方向时，先读取 `references/wechat-curated-image-template-library.md`，再从 `references/wechat-curated-image-template-prompt-pack.md` 取得对应编号的输入要求、身份或商品锁定、完整首轮提示词、局部返修提示词和交付检查。首轮只做一张小样，每轮只改变一个主要变量；中文文字默认留空，确认后单独排版。“示例审查通过”只允许限量试做，达到 3 个彼此独立的真实成功案例后才能称为“可用”。不得把 `0/3` 写成已经验证。

需要从新的外部提示词 JSON 寻找候选时，先运行 `scripts/curate_image_prompt_candidates.py` 做字段白名单、提示注入、凭据/命令、用途和重复检查。脚本输出只是一份隔离候选报告，不得自动改写模板库、提示词包或服务登记表；人工审查来源页和示例图后，仍须用自有或获授权素材试做。

寻找新模板或照片服务方向时，读取 `references/photo-template-resource-radar.md`；需要先看真实成品、优秀案例及可复用原理时，再读取 `references/photo-inspiration-gallery.md`。只有得到所有者明确同意，才能使用技能内案例素材；不得把私人肖像当作公开示例。

### 四、交付前检查

核对：

- 成品确实回答了请求；
- 姓名、日期、数字和画面文字没有被凭空编造；
- 文件能正常打开，并适合通过微信传递；
- 没有不必要地重复私人输入；
- 不确定之处已用一句短话说明；
- 公开发布的 AI 生成媒体保留平台或法规要求的标识；
- 声称的像素尺寸经过成品文件验证；没有达到实际 8K 像素时，只能称“8K 质感”或“高清”，不能称“8K”；
- 多轮修改后，人像身份、可见中文文字、手部和已锁定模板区域没有漂移。
- 网页交付不是一张整页截图；标题、导航、卡片和说明文字都是独立网页元素；
- 对照设计稿逐项检查图标、文字、图片、数量、间距和覆盖关系，避免相似图标冒充、按钮重复叠加或生成式漂移；
- “部署成功”“公开访问”“无须登录”和“目标地区无代理可达”分别验证，不能互相替代；
- 面向国内微信联系人时，由真实手机关闭代理后通过本地 4G/5G 或常用 Wi-Fi 打开；未通过前不得声称“别人直接能看”。

### 五、简单交付

只返回完成的成品、一句话说明做了什么，以及确实有价值时的一个可选改进。需求发现阶段不要加入销售话术。

### 六、记录匿名证据

在用户同意的位置使用 `scripts/service_registry.py`。初始化一次后，只记录服务 ID、结果状态、耗时、满意度和可复用性。绝不保存姓名、电话、账号、原始健康信息、身份证件、私人聊天或原始肖像。

```powershell
python scripts/service_registry.py init --state-dir <state-dir>
python scripts/service_registry.py list --state-dir <state-dir> --top 20
python scripts/service_registry.py record --state-dir <state-dir> --service-id old-photo-repair --status success --minutes 7 --satisfaction 5 --reusable yes
python scripts/service_registry.py report --state-dir <state-dir>
```

有价值的新需求若没有匹配项，使用 `service_registry.py add` 加为候选服务。诚实评分，不得为了推广抬高分数。

### 七、从真实案例进化

- 候选：仅有想法，或成功案例少于 3 个。
- 可用：至少 3 个成功案例，且没有实质性安全问题。
- 优先：至少 8 个成功案例，平均满意度不低于 4/5，平均完成时间不超过 15 分钟。
- 暂停：完成 4 个以上案例后，至少一半部分成功/失败，或反复出现安全与隐私问题。

升级为“可用”后，新建或完善简洁操作参考；升级为“优先”后，再改进自动化和推广示例。不要因为每个个案都重写整个技能。脚本可继续使用稳定机器状态值，面向人的说明统一使用上述中文等级。

## 老河口本地服务入口层

当请求涉及老河口、本地居民、本地小店、农产品、土特产、采摘园、农家乐或县域微信服务时，先读取 `references/laohekou-local-service-strategy.md` 和 `references/local-service-bundle-delivery.md`，再读取 `assets/local-service-portfolio/service-entrances.json` 选择入口。

前台只提供四个入口：

1. 家庭影像修复与纪念；
2. 小店微信宣传素材；
3. 农特产品电商视觉与文案；
4. 趣味照片与微信头像（免费引流）。

这四个是面向人的服务入口，不是四个新的底层技能包，也不替代 `references/seed-services.json` 中的细分能力。收到需求后，从入口映射到已有服务 ID，组合交付一个完整结果。不要把菜单生成器、头像生成器、海报生成器、包装生成器分别宣传为独立业务。

本地数据只用于说明小试方向，不能代替真实需求证据。首轮复查为 7 个真实案例或 2026-08-31，以先到者为准；至少覆盖 3 个家庭影像、3 家小店和 1 个农特产品经营者。每例记录对方是否实际使用、是否愿意转介绍、是否再次提出需求。没有真实记录时不得宣称“当地最受欢迎”“复购高”或“已经能持续收入”。

## 图片与家庭回忆专线

在 3 个彼此独立的成功案例完成验证前，把 `photo-memory-fun-remix` 保持为候选服务。始终分开保存：未改动私人原图、可复用视觉模板、每次衍生版本及其取舍状态。

每轮只改变一个主要变量：先清理或重建合法模板，再选择人物材质化或自然身份处理，然后收紧脸部几何，再调整画布构图，最后才加入“小世界”等高级空间效果。后续提示词锁定已经认可的区域。服务登记表只记录匿名运营指标，不保存或复制原始肖像。

寻找外部模板时，不把网上能看见等同于可复制或可商用。记录平台链接、模板名、作者、日期、免费/付费状态、授权说明和一张自有测试记录；只有许可明确或用户拥有合法使用权时，才把第三方素材纳入服务资产。不得去除作者、版权或平台要求保留的水印。

## 中文姓名艺术签名分支

用户要求个性签名、商务签、连笔签、潇洒签、一笔签、验字、纠正增笔少笔、笔顺教学、真人书写视频、透明图或练习纸时，读取 `references/signature-design-branch.md`，并调用独立技能 `$design-teachable-chinese-signatures`。

这个分支把“字形正确”和“真人三次都能重复写出”作为硬门。AI 生成图只能作为视觉候选；未完成逐字验形与真人三写时，不得称为教学级成品。不得帮助模仿、伪造他人真实签名，也不得宣称法律效力。

## 通过微信推广

准备群消息或朋友圈内容时，读取 `references/wechat-promotion.md`。一次只推广一个具体结果。只有得到明确许可，才展示真实前后对比。可以使用：“把照片或语音发来，我免费帮你做成能直接使用的结果。”
