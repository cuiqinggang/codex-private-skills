# 微信 AI 服务优质模板完整提示词包

更新日期：2026-07-21

用途：把 `wechat-curated-image-template-library.md` 中的 28 个方向变成可以直接试做、返修和验收的中文提示词。所有模板都必须先使用自有或明确授权的图片；方括号中的内容要替换成当前任务的真实信息。

## 使用方法

1. 先读取对应模板的“输入照片要求”，不合格时先修图或请用户补图。
2. 把“第一轮生成提示词”整体交给图片工具，不要只复制其中一句。
3. 第一轮只做一张小样；身份或商品漂移时，改用同一模板的“身份漂移后的返修提示词”。
4. 中文文字默认留空并在生成后单独排版；必须与物体一体生成时，逐字核对。
5. “实际测试状态”必须依据真实案例更新。没有完成 3 个独立成功案例前，不得称为“可用”。

## 公共占位符

- `【身份源图】`：决定五官、脸型、年龄、发型和神态的原始照片。
- `【商品源图】`：决定商品包装、标签、颜色、比例和结构的原始照片。
- `【当前结果图】`：上一轮生成、等待局部返修的图片。
- `【模板主题】`：职业、节日、材质、场景等本轮主题。
- `【文字内容】`：用户逐字确认的姓名、日期、祝福语、价格或店名。
- `【输出比例】`：默认按微信用途选择 1:1、3:4、4:5 或 16:9。

## WX-01 老照片事实修复

**输入照片要求**：提供原始扫描或清晰翻拍图，尽量不要使用聊天软件反复压缩后的截图；说明是否只修损、是否允许上色。若人物面部已经完全缺失，先告知只能推测重建。

**身份锁定**：锁定人物数量、脸型长宽比、眼距、鼻口距离、发际线、表情、姿势、衣服轮廓、背景结构和照片年代。身份源只能是原照片，不得参考陌生人的“漂亮脸”。

**场景和构图**：保持原构图、裁切、人物站位、镜头方向和景深；只恢复受损区域，不把旧照片改成现代影楼照。

**材质、灯光和相机**：保留原胶片或相纸质感；恢复合理灰阶、颗粒和局部对比度。上色时使用克制、符合年代的自然颜色，不使用现代高饱和滤镜。

**允许改变的区域**：划痕、折痕、污点、霉斑、噪点、轻微失焦、缺角和褪色区域；只有用户同意时才上色。

**严禁改变的区域**：人物身份、人数、表情、服装款式、肢体、背景建筑、家具、文字、徽章和历史性细节。

**负面约束**：不要年轻化、磨皮、换脸、放大眼睛、改变发型、生成现代服装、重构背景、增加人物、制造错误手指或把推测细节说成事实。

**中文文字处理**：原图有文字时尽量保留原像素；无法识别的字不要猜。需要重排时先让用户提供准确文字，再单独排版。

**第一轮生成提示词**：

```text
以【身份源图】为唯一事实依据，进行保守的老照片修复。保持原始人物数量、面部结构、年龄、表情、姿势、衣服轮廓、背景、裁切和年代感完全不变。只去除可见划痕、折痕、污点、霉斑、压缩噪点和轻微模糊，保留自然皮肤纹理与原相纸颗粒；对缺损区域只做最小、连续、符合周围像素的补全。不要年轻化、不要换脸、不要现代化服装或背景、不要新增任何物体。若本轮允许上色，则采用低饱和、符合年代的自然颜色；无法确定的颜色保持中性。输出与原图相同比例的高清修复小样。
```

**身份漂移后的返修提示词**：

```text
以【当前结果图】为主画布，以【身份源图】为唯一身份和历史事实依据。只修正发生漂移的【具体区域】，恢复原图中的头部长宽比、眼距、鼻口距离、发际线、皱纹、表情和服装轮廓；其他已经修好的区域全部锁定，不重绘、不美化、不改变颜色。删除上一版擅自增加的现代元素或虚构细节，保留原构图和年代质感。
```

**交付检查**：并排放大检查人数、五官、服装、手部、背景和文字；分别标明“事实修复”和“AI推测补全”；核对实际像素，不把普通高清称为8K。

**实际测试状态**：示例审查通过；真实案例 `0/3`；等级：候选。

**交付检查**：逐人数清人数，逐脸对照身份源，检查手部、长幼身高、眼镜、灰阶和站位；未经许可不公开全家福。

## WX-07 婚纱/纪念日多场景小样

**输入照片要求**：同框夫妻照优先；至少能看清两人的正面或轻侧脸。用户选择2～4个场景、服装方向和是否保留当前年龄。

**身份锁定**：所有分格使用同一对夫妻，锁定脸型、年龄、发型、肤色、身高差和体型；不得每格换脸。

**场景和构图**：2×2或横向多格，每格一个明确场景，人物大小和视觉节奏统一；分格之间边界干净。

**材质、灯光和相机**：每格可有不同环境光，但肤色和身份一致；使用真实婚礼摄影质感，不做过度仙侠化。
