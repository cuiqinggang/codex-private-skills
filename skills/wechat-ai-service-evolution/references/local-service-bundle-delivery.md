# 老河口本地组合服务交付标准

## 一、共同收件表

只收完成当前结果所需资料：

```text
服务入口：家庭影像 / 小店宣传 / 农特产品 / 趣味引流
对方想拿到的完整结果：
已有原始材料：
必须准确的信息：姓名 / 店名 / 电话 / 地址 / 日期 / 价格 / 规格
发布渠道：微信聊天 / 朋友圈 / 视频号 / 抖音 / 打印
截止时间：
隐私、肖像或素材授权：
不允许改变的内容：
```

姓名、电话、地址、二维码、私人照片和未公开经营资料只在当前交付中使用，不写入匿名服务登记表。

## 二、共同制作顺序

1. 冻结事实字段和原件，不先美化。
2. 检查照片清晰度、裁切空间、人物身份或商品真实性。
3. 从 `assets/local-service-portfolio/service-entrances.json` 选择已有能力，不临时新建技能。
4. 先完成一个最小可用主成品，再补同套衍生尺寸。
5. 逐字核对可见中文、数字、日期、价格、电话、地址、规格和二维码。
6. 用真实目标渠道打开；微信图片检查缩略图可读性，二维码用另一台设备实扫。
7. 只由用户或客户人工发布，不自动群发。

平台规格可能变化，制作时查看当前平台要求并验证最终文件，不在长期规则中把某个像素值写成永远不变。

## 三、家庭影像交付

最小结果：一张修复或纪念图、原图对照、一句说明哪些是事实修复、哪些是 AI 推测。

完整组合可含：高清保存版、微信预览版、打印参考版、纪念文字、相册或短视频。交付前检查人物身份、手部、服装时代感、面部年龄、背景逻辑和新增文字。

已故亲人合影需记录家属已同意。不得默认生成说话、唱歌、招手等易误解动态；如用户明确要求纪念动态，也要标明为 AI 再创作。

## 四、小店宣传交付

最小结果：一张可以直接发朋友圈的主宣传图。

完整组合可含：主海报、朋友圈图、视频号/短视频封面、菜单或价格表、营业信息卡和二维码版。交付前让商家逐项确认：

- 店名、电话、地址、营业时间；
- 商品或套餐内容、原价、现价、活动日期和限制条件；
- 二维码确实指向商家认可的页面；
- 菜品和商品图没有把份量、颜色或内容夸张到误导消费者；
- 门头效果图明确标注“效果参考”，不冒充已经施工。

## 五、农特产品电商交付

最小结果：一张真实主图、一张卖点图和一段基于事实的商品介绍。

完整组合可含：白底图、场景图、卖点图、包装/标签效果图、朋友圈图、短视频封面、规格说明和注意事项。必须由经营者提供并确认：品名、产地、规格、净含量、配料、储存方式、保质信息、价格、资质和可使用标志。

AI 场景图必须保留商品外形、数量、包装和颜色，不得把普通农产品变成不存在的品种或包装。健康、治疗、减肥、儿童适用、有机、绿色、地理标志等声明没有证据时不得写入。

## 六、趣味引流交付

最小结果：一张本人或已授权肖像的趣味图或微信头像。必须避免恶意丑化、敏感身份误导、未经授权的名人合成和明确品牌风格冒充。趣味体验成功不等于其他三个正式入口成功。

## 七、真实使用验收

每例完成后只记录匿名指标：

```text
入口ID：
结果：成功 / 部分成功 / 失败
耗时分钟：
对方实际使用：是 / 否 / 未知
愿意转介绍：是 / 否 / 未问
30天内再次提出需求：是 / 否 / 观察中
满意度1-5：
最主要返工原因：
是否可复用：是 / 否
```

首轮7例复查时计算：实际使用率、转介绍意愿率、再次需求率、平均耗时和事实错误率。没有观察期数据时统一写“尚无实测”。

## 八、停止或调整条件

- 家庭影像反复出现身份漂移、家属不同意或情绪伤害：暂停相关高风险形式。
- 小店素材完成后多数不发布且没有再次需求：缩小为单张免费试做，不继续扩充模板。
- 农产品资料无法取得真实规格、标签或资质：只做不含这些声明的安全版本。
- 7例中实际使用不足一半，或事实错误/隐私问题达到2例：停止扩张，复盘后决定合并、调整或移除。
