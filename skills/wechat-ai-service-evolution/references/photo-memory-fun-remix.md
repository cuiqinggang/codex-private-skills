# 趣味照片与家庭回忆再创作流程

## 一、收件门禁

1. 确认照片所有者或肖像本人已同意处理；儿童照片由监护人确认。
2. 确认用途是私人分享、家庭纪念还是公开发布；公开发布需要单独许可和必要 AI 标识。
3. 保留未改动原图，工作副本与交付成品分开保存。
4. 优先使用本地或当前可信生成环境；外部网站的隐私、留存、社区公开和删除规则必须当天复核。
5. 不把证件、病历、亲密影像、未公开家庭照或无关人员照片上传到规则不清楚的平台。

## 二、选择路线

- 基础修复：去划痕、去模糊、纠偏色、清晰整理；事实修复与推测重建分开说明。
- 身份保持再创作：先锁定脸型、五官、发际线、年龄和神态，再改变服装、背景或材质。
- 食物与人物：载体先真实，人物只在用户选择的层级材质化。
- 家庭小世界：洞口有厚度、遮挡和纵深，内部场景保持独立色彩和完整空间。
- 收藏品人物：先确认是分享用视觉效果，还是真正制造用深度图/网格；没有制造验证时只交付效果图。
- 家庭纪念：历史细节由家属确认；AI 扩展场景不得冒充真实历史照片。

需要“老油条”路线时读取 `oil-stick-case-study.md` 和 `oil-stick-prompt-pack.md`；选新方向时读取模板雷达和灵感画廊。

## 三、单变量迭代

1. 建立合法干净模板，不直接搬运无权使用的原作品。
2. 选择自然人像、半材质、全材质或小世界模式。
3. 第一轮只解决主体与身份。
4. 第二轮只校准脸部几何、年龄和神态。
5. 第三轮只修接触边缘、遮挡、阴影和色温。
6. 最后再处理构图、中文文字、画布尺寸和高级空间效果。
7. 每轮保存上一版作为回退点，并在后续提示词开头写明锁定区域。

## 四、质量检查

- 人物仍一眼像本人，人数和家庭关系正确。
- 中文文字逐字正确，手部、耳朵和边缘没有明显畸变。
- 外部载体材质没有污染自然人脸或内部小世界。
- 小世界具有前景遮挡、中景、远景和一致透视，不像镜子或相框。
- 文件可打开，像素尺寸经过读取验证，微信预览清楚。
- 不确定的历史、颜色或缺失细节标为推测。
- 公开发布时保留必要 AI 标识、作者署名和平台要求水印。

## 五、交付与保留

交付成品、一句变化说明和必要限制。用户确认后，只登记匿名服务指标。私人原图和临时工作文件按约定保留或清理；没有单独许可，不进入模板库、画廊、演示或宣传材料。

## 六、服务升级

`photo-memory-fun-remix` 在 3 个彼此独立的真实成功案例前保持候选。达到 3 个成功案例后完善操作参考；达到 8 个成功案例且满意度和耗时达标后，才优化自动化和公开推广示例。
