## 一、使用方法

这些提示词用于图片编辑工具，不是从零生成的普通文字画图。整套说明和可执行指令均使用中文。品牌名、文件名、尺寸、编号和程序参数按原样保留，不代表英文版。

只处理用户自有或明确获授权的图片。不得删除作者、版权或平台要求保留的水印；不得把第三方截图清理后冒充自有模板。P01 仅适用于用户拥有完整处理权的自有截图或内部界面截取；否则应从自有素材重新制作干净模板。

每次明确提供：

- `主模板`：决定构图、手、油条、文字和背景；
- `身份源`：决定人物五官、头型、发型和神态；
- `场景源`：决定小世界中的完整环境；
- `已认可成品`：上一轮已认可、下一轮必须锁定的图片。

不要一次运行全部提示词。按案例选择一条路线，每轮只解决一个主要问题。所有相对素材路径均以 `assets/photo-memory-fun-remix/oil-stick/` 为根。


### 中文文字锁定

```text
中文文字必须与输入完全一致。保持字数、顺序、位置和含义不变。不得增加文字、漏掉笔画、替换汉字或出现错别字。
```

```text

```

## 十一、P09 真正纵深小世界

输入：无标题模板和完整场景源图。

若原场景触发输出安全拦截：说明被拦截的具体元素；在得到允许或按规则可直接调整时，只修改服装或裁切策略，不改变人物身份、动作、场景层级和世界结构；不得绕过图片工具安全检查。

```text
已认可的来源脸部纵向更长、横向更窄。恢复精确长宽比，不得加宽脸颊或缩短下半脸。
```

### 眼睛被美化放大

```text
恢复来源人物较窄、略有不对称的眼裂。不得放大、变圆、过度提亮或强行对称。
```

### 下眼睑太浓

```text
下眼轮廓保持柔和圆润，但阴影要更淡。不得制造深色眼袋或加深眼窝。
```

### 人脸被环境染黄

```text
去除人脸中心和自然发色上的金黄偏色。只允许最外层轮廓接受轻微暖色反光。
```

### 小世界像镜子

```text
删除所有玻璃、反射和图片平面线索。加深隧道，把人物移到洞口后方更远处，让地面作为透视平面继续延伸，并明确分开前景、人物、中景和远处建筑。
```

### 只删字却改了头像

```text
拒绝所有脸部重新生成。恢复上一版已经认可的精确头部、脸、头发、眼睛、鼻子、嘴和表情。本轮只允许删除标题并改变画布边界。
```

### 低光照片被修成另一张脸

```text
撤销重新美化和五官重塑。恢复身份源中精确的头部长宽比、眼裂、鼻口距离、笑意和年龄。只修复曝光、偏色、轻度模糊和眼神光，不改变人物身份。
```

### 全金色版本仍像贴上去的照片

```text
保持已经认可的五官几何不变，把头发、脸、颈部和衣领统一转换为连续的细腻金黄油条浅浮雕材质。只加强材质连续性、接触阴影和遮挡，不重新设计人物。
```
