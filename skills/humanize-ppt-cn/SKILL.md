# 中文 PPT 内容人化

先保真，再提炼，最后视觉化。不得为了顺口而编造数据、客户、引用、案例或因果。

## 工作流

1. 建立来源清单，标记事实、推断和建议；不确定内容写明“待核验”。
2. 用一句话写出整场演示的主张，再写受众、行动目标和核心冲突。
3. 组织为：钩子 → 问题 → 框架 → 证据/案例 → 结论 → 行动。
4. 每页只保留一个可复述的结论；标题必须表达结论，不用“背景/现状/方案”等空分类名。
5. 每页正文最多 6 个信息单元；段落过长时拆页，不缩小字号硬塞。
6. 把抽象词转换为流程、对比、时间线、矩阵、因果图或具体例子；能画图就不只写文字。
7. 为每页输出：标题、核心句、视觉对象、来源/限定语、演讲备注。
8. 交给视觉工具前复核事实、重复、密度、中文自然度和行动闭环。

## 输出契约

```text
页码 / 页面角色
结论标题：
核心内容：
视觉对象：
来源或限定：
演讲备注：
```

## 硬门禁

- 不编造数字、引语、品牌、客户或测试结果。
- 不用“赋能、抓手、闭环、全方位、智能化”等词替代具体意思。
- 不连续三页使用相同版式或同一种信息结构。
- 找不到真实数据时使用定性表达，并明确限制。
- 输出进入动态演示前，调用 `ast-attention-architect` 标注注意力状态。

验收、失败复盘和使用记录规则见 `references/OPERATIONS.md`。
