# 07_BRAND_REWRITE_AND_INDEPENDENT_SITE

默认把参考站改造成一个虚构但可商业化的独立站，不保留原站身份。

默认测试品牌：
- Brand Name：NovaLanding
- Product Type：AI 独立站生成服务
- Audience：一人公司、AI 工具创业者、数字产品卖家
- Tone：清爽、可信、专业、现代
- CTA：Start Building / Get Demo / Join Waitlist

必须替换 Logo、Brand name、原文案、原图、客户案例、法律文本、联系方式。

输出：outputs/brand/BRAND_REWRITE_REPORT.md

## 输出要求
- 所有结论必须中文可读。
- 关键证据必须落盘。
- 没有真实 URL、截图、build 和 QA，不得标记 PASS。
