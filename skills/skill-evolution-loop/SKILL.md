# Skill Evolution Loop

## Purpose

Turn successful or failed work into reusable procedural memory.

## Core Principle

Any task can be handled in two ways:

- If AI has done it successfully before, convert it into a mature reusable lifetime skill.
- If AI has not done it before, copy or reconstruct a mature external skill route, run it, verify it, and then turn the verified process into a local skill.

## When to Use

Use after:
- a successful recovery
- a completed dashboard stage
- a solved Codex problem
- a repeated workflow
- a failure that revealed a hard rule
- a useful video/tutorial/process
- a GPT Gate Review acceptance

## Required Outputs

1. SKILL.md draft
2. SOP.md
3. FAILURE-HISTORY.md if relevant
4. ACCEPTANCE-CHECKLIST.md
5. TRIGGER-RULES.md
6. DO-NOT-TRIGGER.md
7. EXAMPLES.md
8. MANIFEST.md

## Skill Quality Rules

A good skill must include:

- clear trigger conditions
- clear non-trigger conditions
- exact workflow
- hard boundaries
- evidence requirements
- output format
- failure handling
- examples

## Anti-Bloat Rule

Do not create a giant skill.
If the skill exceeds a reasonable scope, split it into:
- orchestrator skill
- subskill
- reference file
- script
- checklist
