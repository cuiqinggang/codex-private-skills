# Hermes GPT Plus Superbrain Skill Pack v0.2

这是给爱马仕数字助手使用的第二版技能包。

## v0.2 新增重点

首次测试发现：如果任务开头不明确加载 GPT 使用原则，爱马仕容易把 GPT 页面当成普通问答工具，或者退回复杂机器协议思路。

所以 v0.2 增加最高优先级要求：

> 每次任务必须显式加载《GPT Plus 网页作为爱马仕超级大脑的使用原则》，并要求本任务全程按该规则执行。

## 核心目的

- ChatGPT Plus 网页作为爱马仕超级大脑
- 爱马仕负责本地执行和结果反馈
- GPT 负责分析、编程、判断、改方案
- 像普通人使用 ChatGPT 一样自然使用
- 不强迫 GPT 输出复杂机器协议

## 文件

- `SKILL.md`：完整技能包
- `PROMPTS.md`：可复制启动口令与编程任务模板
- `VERSION.md`：版本记录
