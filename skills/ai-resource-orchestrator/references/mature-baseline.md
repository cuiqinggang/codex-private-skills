# 2.0 Core 成熟基线

## 冻结来源

| 项目 | 冻结内容 |
|---|---|
| 原目标 | 按任务类型、成本、质量和风险选择执行资源 |
| 来源版本 | `ai-resource-orchestrator 1.0.1` |
| 原正式入口 | `$ai-resource-orchestrator`；专用Profile交互式启动 |
| 已通过能力 | 精确输出、四档路由、Codex子代理、Reasonix官方入口、Playwright真实网页、Reasonix失败回退Codex |
| 已通过安全能力 | workspace-write安全目录、默认配置未改、受保护范围回读 |
| 未知边界 | L1至L6完整运行、长期稳定性、首轮成功率、精确费用、自动学习和持续健康监控 |
| 禁止改动 | 代理、FlClash、账户、密钥、Provider、Reasonix配置、Playwright实现、默认全局配置 |

## R6缺口归因

| 当前成熟能力 | 实际缺口 | 缺口原因 | 复用的成熟解决方案 |
|---|---|---|---|
| 1.0.1直接交互会话曾完成六项验收 | R6的P0-02子进程自报`never/read-only`并出现网络10013；L1至L6未执行 | `EXTERNAL_FAILURE`与`UNVERIFIED`：测试宿主、参数传递和网络权限未被分离证明；不能归因为业务路由失败 | 分离交互与非交互入口；网络用例单独设门；从新证据根复测原失败对象 |
| 正式技能、Profile、Reasonix和Playwright哈希未变 | 早期尝试日志被复用路径覆盖 | `MISSING`：取证辅助器缺少不可变attempt路径 | 复用追加式证据做法，为每次尝试保存独立参数和日志 |

## 2.0范围裁决

保留：四档路由、单一主执行路径、Codex、按需子代理、Reasonix官方入口、按需Playwright、一级回退、人工确认。

移出运行核心：安装发现生命周期、Knowledge Brain写入、发布封袋、大型综合QA、未经验证的精确计费、自动学习和持续健康监控。

“移出运行核心”不是删除历史能力；相关证据继续保留在1.0归档和2.0发布验收材料中。
