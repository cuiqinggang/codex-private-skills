## Important Observations

1. Windows native Hermes 0.14 already has a built-in Telegram adapter. No old WSL/OpenClaw gateway is required.
2. The adapter uses long polling when `TELEGRAM_WEBHOOK_URL` is not set.
3. Hermes clears stale webhooks before polling.
4. `TELEGRAM_ALLOWED_USERS` is required on this machine; without allowlists Hermes logs a warning and denies unauthorized users.
5. `TELEGRAM_PROXY` was needed because direct Telegram/httpx attempts timed out repeatedly.
6. FlClash/Core was listening on `127.0.0.1:7890`, and the proxy path successfully reached Telegram.
7. `hermes gateway install` failed to create a Scheduled Task because Windows returned localized access denied text: `拒绝访问`.
8. Hermes 0.14 did not fall back automatically because its fallback detection did not match that Chinese localized error string.
9. The internal Startup-folder fallback worked and was verified by manually invoking the generated Startup entry.

### First Telegram Gateway Restart

`hermes gateway restart` timed out after about 124 seconds. Diagnostics showed it still launched a gateway process with:

```text
telegram connect timed out after 30s
Primary api.telegram.org connection failed
Fallback IP ... failed
Gateway running with 1 platform(s)
Starting reconnection watcher for telegram
```

Root cause: Telegram network path from Python/httpx was unreliable without explicit proxy settings.

Future improvement: Hermes could detect local system proxy or produce a clearer next action when Telegram direct/fallback IPs fail.

### PowerShell to Python Environment Handoff

The first attempt to persist Telegram config failed with:

```text
KeyError: 'TG_TOKEN'
```

Root cause: a PowerShell local variable was not exported to Python as an environment variable.

Correct pattern:

```powershell
$env:TG_TOKEN = "<token>"
$env:TG_CHAT_ID = "6164003953"
```

Future improvement: wrap this in a tested setup script that accepts parameters and never echoes secrets.

## Recovery Preference

Use this order next time:

1. Run `scripts/check-hermes-telegram.ps1`.
2. Fix proxy or env first; do not reinstall Hermes.
3. Restart gateway with the existing launcher.
4. Reinstall Startup fallback only if `status --deep` says the login item is missing.
5. Only pursue admin Scheduled Task creation if the user specifically wants it.
6. Consider token rotation if the bot token was exposed outside trusted local files.
