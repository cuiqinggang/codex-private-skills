# R1 Failure Pattern Catalog

## FP01 Generic Magic Animation

Symptom: output has red circles or stones but does not match the source desk, motion, or lighting.

Fix: return to L04/L05 and extract source-specific positions and timing.

## FP02 Missing Modern Desktop Layer

Symptom: magic scene replaces the mundane workspace.

Fix: restore desk, cables, candles, stickers, PC tower, and real surface perspective.

## FP03 Full Source Copy

Symptom: output is the original target clip or all source frames re-encoded.

Fix: fail the gate. Rebuild with sparse guides and procedural layers.

## FP04 Phase Drift

Symptom: ring, glow, or center body appears too early or too late.

Fix: add key event anchors and rerun L09 comparison.

## FP05 Sound Ignored

Symptom: visual similarity exists but sound timing/mood is absent.

Fix: extract audio, map events, rebuild or mix an aligned sound bed.

## FP06 False PASS

Symptom: report says PASS without comparison metrics, verification JSON, or score thresholds.

Fix: run L10 verification and only accept if final acceptance supports the status code.
