# R1 Mother-Plate Replica Extension

This extension records the R1 mother-plate driven replica workflow.

## Scope

- Use the original reference video as the only truth source.
- Lock a 3-6 second target segment.
- Extract frames, audio, event timeline, replica spec, and score matrix.
- Build a high-similarity replica with documented anti-copy boundaries.
- Verify with side-by-side keyframes, deterministic media checks, and final acceptance.

## Not Scope

- Not a free inspired animation.
- Not a full 23-second reconstruction.
- Not a pixel-level source file copy.
- Not a ComfyUI/Wan workflow.
- Not a replacement for human review when source rights or usage constraints matter.

## R1 Result Pattern

The first R1 pass used sparse keyframe plate guidance plus procedural overlays. It did not reassemble the full source frame sequence. This is suitable for high-similarity validation when the task permits keyframes/screenshots as mother-plate evidence.
