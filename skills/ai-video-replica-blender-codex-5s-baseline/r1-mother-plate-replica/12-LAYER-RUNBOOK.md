# R1 12-Layer Runbook

## L01 Task Contract

Lock the task as replica, not creation. Write standards and forbidden scope.

## L02 Master Source Lock

Freeze the original video as the only truth source. Record metadata and hash.

## L03 Target Segment Lock

Choose the 3-6 second target segment and write the selection rationale.

## L04 Multimodal Breakdown

Extract frames every 0.1s or 0.2s, extract audio, create frame index and audio event map.

## L05 Replica Spec

Convert evidence into composition, element, motion, audio, and contrast specs.

## L06 Rebuild Plan

Define modern desktop, magic geometry, center body, glow, motion, sound, and composite layers.

## L07 Visual Rebuild

Build only from the locked spec. Do not substitute a new design.

## L08 Motion And Audio Rebuild

Rebuild timing, glow, ring/body motion, camera movement, and sound mood.

## L09 Same-Frame Comparison

Generate first composite, side-by-side frames, contact sheet, and comparison report.

## L10 Verification Plane

Run deterministic checks and compare against score thresholds.

## L11 Repair Loop

Record every failed point, fix only that point, and rerun the corresponding gate.

## L12 Final Acceptance

Write final report, final acceptance JSON, and skill extension only after all gates pass.
