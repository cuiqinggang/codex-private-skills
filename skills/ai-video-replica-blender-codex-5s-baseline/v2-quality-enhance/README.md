# V2 Quality Enhance Extension

This extension captures the P2 pass for improving the P1 5 second Blender + Codex baseline.

P2 is a visual quality enhancement on top of the P1 closed-loop proof. It does not change the P1 baseline script, P1 `.blend`, or P1 MP4. It does not represent a full 23 second replica, pixel-level matching, or a ComfyUI/Wan workflow.

## What P2 Adds

- Procedural material roughness and bump variation.
- Layered red energy orb: core, halo, soft shell, and orbiting energy points.
- Split magic circle animation with outer and inner counter-rotation.
- More varied debris with subtle rotation and floating keyframes.
- Candle flame geometry and warm light flicker.
- Darker atmosphere, red haze, stronger center emphasis, and DOF camera push.
- V1/V2 comparison frame workflow and visual scoring.

## When To Use

Use this extension when the 5 second P1 baseline already renders and the next goal is to improve visual quality without expanding scope to a full video.

## P3 Direction

P3 can extend the same structure to a longer 20 second shot, but only after keeping P2 verification green.
