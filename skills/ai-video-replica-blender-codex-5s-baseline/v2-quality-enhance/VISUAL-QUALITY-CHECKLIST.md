# Visual Quality Checklist

Score each item from 0 to 5.

| Item | PASS Guidance |
| --- | --- |
| Red energy ball layering | Core, halo, outer shell, pulse, or orbiting points should be visible. |
| Magic circle complexity and glow | Rings, triangle/star structure, ticks, dots, and red emission should be denser than P1. |
| Debris / particle motion feel | Multiple varied fragments should surround the circle, with rotation or floating keyframes. |
| Candle / warm light realism | At least 3 candles or warm light columns with visible warm illumination or flicker. |
| Dark value structure | Background is darker than P1 and center red light reads stronger. |
| Camera motion | Push, arc, or DOF should create a more cinematic feeling than P1. |
| Table / background integration | Table and background should be subdued and support the ritual subject. |
| Overall reference-video mood | The scene should feel closer to a dark red ritual setup than P1. |

## PASS Rule

- Total score >= 26/40.
- Red energy ball layering must be nonzero.
- Magic circle complexity and glow must be nonzero.
- Dark value structure must be nonzero.
- Overall reference-video mood must be nonzero.

This checklist is for P2 minimum visual quality only. It is not a final art-direction review.
