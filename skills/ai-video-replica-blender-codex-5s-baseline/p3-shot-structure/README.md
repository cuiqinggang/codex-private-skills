# P3 Shot Structure Extension

This extension captures the P3 pass: expanding the verified 5 second P2 quality shot into a 15 second small complete shot.

P3 does not replace P1 or P2. It does not attempt the full 23 second source, pixel-level matching, ComfyUI/Wan, or external AI video generation.

## P3 Structure

- Establish, 0-5s: wider view, smaller red orb, readable table/candles/circle.
- Intensify, 5-10s: camera push, red orb growth, stronger magic circle, more active debris.
- Climax, 10-15s: closest composition, largest red energy read, strongest circle glow.

## Core Outputs

- 15 second Blender Python template.
- 450 frame render target at 30fps.
- Stage preview extraction workflow.
- Shot-structure visual checklist.
- Verification script pattern for duration, vertical frame, fps, and phase previews.
