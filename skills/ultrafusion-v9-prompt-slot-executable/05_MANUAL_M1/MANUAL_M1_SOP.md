# Manual-M1 SOP

1. 判断任务是否值得运行，冻结预算与成功标准。
2. 新建 RUN_ID 与 manifest。
3. 对原问题一次性直答生成 A_Initial；保存原文、模型、条件、时间与 SHA-256。
4. 封存 A_Initial；A/B/C/D 工作区不得读取。
5. 验证插槽和命令包哈希。
6. 独立运行 A；运行 B 比较核验并形成新稿；运行 C 取舍融合；运行 D 陌生稿终审。
7. 保存 D_Final 原文和哈希，锁定。
8. 只打开 A_Initial 比较副本，以同一事实、逻辑、反例、边界、可执行性口径比较。
9. 记录模型调用、人工操作、时间和费用，给出采用/精简/继续测试/停止结论。
10. 归档运行包；核心资产永不写回。
