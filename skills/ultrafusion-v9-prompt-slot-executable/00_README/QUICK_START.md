# 快速开始

1. `python 09_AUTOMATION/scripts/run_static_acceptance.py`
2. 新建 `RUN_ID`，复制 `05_MANUAL_M1/RUN_MANIFEST.template.json`。
3. 生成一次 A_Initial，保存原文与哈希并封存。
4. 按 `04_COMMAND_PACKAGE_REGISTRY/MANUAL_PACKAGE_USAGE.md` 顺序调用 CP_A、CP_B、CP_C、CP_D。
5. 锁定 D_Final 后才打开 A_Initial 比较副本。
6. 填写 `VALUE_REPORT.template.md`，记录质量与全部成本。

核心资产哈希不一致时停止；不得现场修复原件。
