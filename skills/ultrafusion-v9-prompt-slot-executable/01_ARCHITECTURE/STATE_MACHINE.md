# 状态机

部署：`INIT → ENV_DISCOVERED → BASELINE_PROTECTED → CORE_ASSETS_INVENTORIED → CORE_ASSETS_HASHED → CORE_ASSETS_LOCKED_READONLY → CORE_ASSETS_REGISTERED → V9_FRAMEWORK_CREATED → MANUAL_M1_READY → VALIDATION_RUNNING → ACCEPTED|REJECTED → RELEASE_CANDIDATE → USER_DECISION_REQUIRED`。

运行：`RUN_CREATED → QUESTION_REGISTERED → A_INITIAL_GENERATED → A_INITIAL_SEALED → A_STAGE_READY → A_STAGE_COMPLETE → B_STAGE_READY → B_STAGE_COMPLETE → C_STAGE_READY → C_STAGE_COMPLETE → D_STAGE_READY → D_FINAL_LOCKED → A_INITIAL_COMPARISON_COPY_OPENED → VALUE_COMPARISON_COMPLETE → RUN_ACCEPTED|RUN_REJECTED`。

异常：`BLOCKED`、`FAILED`、`PARTIAL_PASS`、`ROLLED_BACK`、`CORE_ASSET_MISMATCH`、`READONLY_VIOLATION`、`NEEDS_USER_AUTHORIZATION`。`READONLY_VIOLATION` 必须立即停止并生成事故报告。
