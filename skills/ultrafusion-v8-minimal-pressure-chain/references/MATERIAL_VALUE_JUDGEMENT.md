# 材料价值判断

状态：高价值

## 判断理由

这份材料值得沉淀为技能包，因为它解决了 UltraFusion 反复出现的几个问题：

- 提示词过长。
- 审计流程过重。
- 路线越来越多，容易混乱。
- 为了追求质量而把 V8 又做回 V7。
- 缺少轻量但有效的质量门禁。

它保留了 V7 的核心价值：

- 分层压力。
- 逐层评分。
- 最终 Gain 验收。

但它删掉了 V7 的重型部分：

- 不恢复 V15 长注入。
- 不恢复长 C/D 模板。
- 不默认完整基准评测。

## 可复用规则

```text
简单问题走 GPT 直答。
复杂、高价值问题走 V8.2 极简压力链。
A/B/C/D 每层都要有具体扣分点、自评分、已修复内容。
低于 8.5 必须修复一次。
最终用 Gain 判断链路是否值得。
```
