# DeepSeek 上传安全包规则

日期：2026-07-06

## 触发场景

遇到下面情况时使用：

- DeepSeek 上传失败。
- DeepSeek 提示文件格式不支持。
- DeepSeek 提示上传文件数量过多。
- 需要把 UltraFusion 技能包发给 DeepSeek 审核。

## 历史问题

之前的 139 包适合本地归档，但不适合 DeepSeek 网页上传。

原因：

- 文件数量太多。
- ZIP 压缩包容易被 DeepSeek 网页判定为不支持。
- 整个文件夹上传不稳定。

## 可复用规则

给 DeepSeek 的审核包应单独做上传安全版：

1. 优先使用 TXT。
2. 文件数量尽量少，最好 1 到 3 个。
3. 不让用户上传 ZIP。
4. 不让用户上传整个文件夹。
5. 把需要审核的核心内容平铺到一个或少数几个文本文件里。
6. 保留完整技能包在本地，只上传审核材料。
7. 明确标出“先上传这个文件”和“复制这个问题”。

## 验收标准

- 文件数低于平台限制。
- 不依赖 ZIP。
- 不包含无关备份文件。
- DeepSeek 能根据平铺文本评估质量、架构和速度。
