# FAILURE REVIEW

## 必查失败模式

- 逐份摘要冒充主题 Wiki。
- 关键结论没有 source_id 或页码/章节/URL。
- PPT 或营销材料单独支撑高风险结论。
- 新资料静默覆盖旧结论。
- 把预测数字与实际结果混写。
- 只做结构测试，没有真实问答回查。
- 把包内自报 PASS 当独立验收。
- 全库无差别重写，破坏增量维护。
- 来源登记后迟迟不产出首个可验证页面，执行在规划或研究中空转。
- 自定义 `artifact_validation=PASS`，但正式验证器实际返回 FAIL。
- registry 使用项目外路径，导致知识库不能独立移动、复核或交付。

## 复盘记录模板

日期｜场景｜症状｜根因｜受影响页面｜修复｜新增回归题｜证据路径｜是否关闭
