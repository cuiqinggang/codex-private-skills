# Mature Replay Method

## Purpose

Use a completed successful task as a reusable pattern without flooding context with historical logs.

## Method

1. 选择一个已经完成的成功任务。
2. 只读取 final report 和必要 evidence。
3. 提炼成熟模式。
4. 不复制所有历史日志。
5. 生成 replay readback。
6. 生成 gate map。
7. 生成 failure pattern。
8. 生成 adaptation guide。
9. 用脚本验证 replay package 是否完整。

## Required Outputs

- mature-case-readback.md
- reusable-gate-map.md
- failure-pattern-summary.md
- adaptation-guide.md
- verification result

## Anti-Pattern

Yesterday replay is not copying the entire previous run. It is extracting the working structure, risk controls, and verification method.
