# Final Report Template

## purpose

Write the final evidence report for a skill package governance task.

## inputs

- task id
- source readback
- backup report
- changed files
- script outputs
- smoke traps
- final verification

## forbidden scope

- claiming PASS without verification
- omitting residual risks

## gates

1. summarize objective
2. summarize changes
3. cite evidence paths
4. cite script outputs
5. state safety confirmations
6. emit final status codes

## required evidence

- final verification
- script outputs
- changed file list

## script verification

Final report must be checked by package-specific verification.

## final status codes

- ECC_FINAL_REPORT_READY

## failure status codes

- ECC_FINAL_REPORT_STOP
