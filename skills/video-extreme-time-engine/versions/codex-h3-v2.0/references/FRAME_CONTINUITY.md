# 逐帧连续性合同

每帧都以首帧维持场景身份、上一合格源图维持动作继承；允许实际输入有完整一对一派生记录的规范化 PNG，并记录其原始模型输出。验收者必须实际看图，工具统计仅提供辅助。所有 56 张分别记录 PASS / REVISE / REJECT，未看图记 NOT_REVIEWED，禁止批量假设通过。

## 固定动作轨迹

| 帧段 | 动作目标 | 连续性观察 |
| --- | --- | --- |
| 001–008 | 起始构图，手自然接近布料 | 手的位置连续趋近；首帧可静态，后续不能复制 |
| 009–016 | 手指接触布料，逐渐受力 | 指尖接触关系可信，手指数量和形态稳定 |
| 017–024 | 布料边缘逐步提起 | 布边高度渐增，无突跳、穿模或反向 |
| 025–032 | 整理褶皱，木勺可有轻微响应 | 褶皱有因果，木勺不自发漂移 |
| 033–040 | 布料逐渐放回并恢复平整 | 运动衔接，桌面/果篮遮挡关系可信 |
| 041–048 | 手结束整理并缓慢撤离 | 手与布脱离自然，撤离方向持续 |
| 049–056 | 漂亮收尾与轻微镜头推进 | 对象稳定、动作完整、结尾未突切 |

轨迹须在首帧合格后按实际构图固定。可用归一化坐标、目标区域、布边高度、接触状态与镜头推进行程记录规划；输出图仍须逐帧观察确认。规划值不是模型执行值。禁止每帧随机重新决定动作方向。

## 每帧检查项

1. 主体：一只手，解剖合理；指尖与布料接触、遮挡和受力正确，没有融化、额外手指或穿模。
2. 道具：果篮、两个橙子、小南瓜、空玻璃瓶、木勺、米色条纹布数量与身份稳定；玻璃透明，无突然实心化。
3. 场景：木桌和厨房背景稳定；左上暖阳、阴影方向、曝光与色温连续。
4. 相邻运动：相邻帧的方向、幅度、遮挡与镜头推进衔接，阶段边界无突变。
5. 摄影品质：真实、清晰、自然，主体未因缩放/压缩失去可用细节。

## 相邻帧检查

同时查看首帧、上一合格帧、当前帧，必要时查看三帧窗口与逐帧联系表。精确文件哈希与解码像素哈希重复检查是来源风险筛查；不能仅凭哈希不同认定内容独立。近重复指标、亮度变化、差分图、光流等只用于定位可疑帧，不生成代替源图，也不自动认证动作合理。

任何差异阈值必须写明工具、单位与阈值来源，不能随意调阈值把失败变成通过。静止背景应保持稳定；背景大幅差异通常是漂移。相同画面若属于动作或镜头静止，也要区别真实独立生成与复制来源。目标需要动作推进时，多帧近静止须检查实际动作不足和生成失败。

## 记录格式

```text
frame_index / attempt_id / current_source / first_ref / previous_accepted_ref
generation_evidence / actual_dimensions / source_sha256
subject / props / scene / lighting / trajectory / photographic_quality
adjacent_change_observed / exact_duplicate / near_duplicate_review
reviewer / reviewed_at / evidence_image / result / defect / recovery
```

某帧 REVISE 或 REJECT 时停止依赖链，以同一合格锚点重试；本次失败原件保留到独立 attempt 目录。新候选通过后才更新当前链。每次返工记录原因、耗时和依赖影响。合格源图链与候选数量分别统计；11 个失败候选不能计作 11 个已接受正式帧。

只有 56 个正式编号每个都有完整来源、实际看图 PASS 和连续性结论，才开放 A 模式成片。联系表看图无法代替实际播放审核，编码后还需对实际视频逐帧复核。
