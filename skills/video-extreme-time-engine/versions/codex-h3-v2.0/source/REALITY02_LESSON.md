## 复用规则

1. 先复用成熟已验证接口和资产，检查真实“双参考编辑”输入形式。服务存在、权重存在、支持 reference 参数，都不能单独证明可连续控制微小动作。记录模型实际暴露的参数；未知模型名和 seed 照实标未暴露。
2. 正式长链前做小样。小样至少包含多步相邻受控移动，连续使用首帧与上一合格帧；同时覆盖静态区保留、正确动作方向和进入接触阶段的能力。不能用一次成功微动、全图不同 SHA 或单张摄影 PASS 作为长链能力认证。
3. 区分计划与实测。提示词里的“6像素”“ONE PERCENT”等都是计划；实际位移、阶段语义、指尖间隙必须由真实查看决定。SIFT/光流可辅助定位，但不能把少量匹配或计划值写成精确物理进度。
4. 当前帧失败就返修当前帧。每次输入仍用上一合格图与首帧，保留失败候选的 request/call/result/raw/review。不能把失败图输入后继，不能提前触布，不能靠后续瞬跳追赶阶段。
5. 同一精度动作连续三次失败时冻结依赖链并明确能力阻塞；保留旧合格图、所有候选和冻结轨迹。禁止宽限数值、改变判定、复制帧、程序平移主体或时间插值冒充合格真源帧。本次 C4“过大、过大、近零”均保持 REVISE。
