## 本轮实际返修经验（2026-10-12）

主控独立 first5 审查把 002–005 连续性记为 REVISE，报告相邻位移 002→003 约 40 px、003→004 约 12 px。真实模型来源及文件差异不能认证自然连续运动；需要实际方向/幅度检查。上述数字为主控量测报告，本包未独立测量。主控准备停止当前 CLI 从失败链继续生成，用当前 Codex 内置 imagegen 版本化返修；执行安排不等于修复成功，失败资产和调用链仍须保留。修复早期帧时旧下游标 STALE，直到重新核验来源与连续性才能继续。

旧音轨技术可解码且有声音，但用户实际听检反馈浑浊、内容难辨或不合适，必须设 `AUDIO_CONTENT_REVISE`；不能沿用技术通过为听感通过。新 B 使用同一 CC0 布料录音版本化剪辑，真实 `B_audio_audit.json` 为 `TECHNICAL_PASS_LISTENING_PENDING`，有 112000 samples 精确母版、动作脉冲、电平与无量测削波证据，但听感及最终画面同步仍未认证。拟音脉冲之间的预定静音应按动作解释，不能只用整段 RMS 判无声，也不能用音频波形替代听检。

可执行新规则：逐帧来源门禁、连续性门禁和声音内容门禁分别记状态；来源正确不覆盖 REVISE，技术通过不覆盖用户实际质量反馈。保留旧版和新 B，等待实际验收后才选择最终版本。精确 C 盘证据及返修接续见 RECENT_USE_LOG；不改变代理、系统或原资产。
