# GPT 10秒真实素材宣传短片资料包流程

日期：2026-07-07

## 适用场景

当用户要做“10秒爆款宣传片”“短视频宣传剧本”“让GPT生成短片”“免费AI资料/免费教学宣传短片”时，先走这个流程。

## 核心定位

这不是PPT轮播，也不是重新生成动画。

目标是把真实素材、宣传图、AI能力图、用户文案、参考视频经验，整理成一个可交给 GPT 的短片导演资料包。

## 工作流

1. 读取用户提供的视频、图片、文字资料。
2. 如果有参考视频，先转写并提炼导演方法。
3. 汇总已有宣传图、能力图、真实场景图和核心文案。
4. 输出 GPT 可直接使用的资料包：
   - 创意简报
   - 10秒结构
   - 镜头表
   - 旁白文案
   - 屏幕字幕
   - 素材清单
   - 音乐硬规则
   - 验收清单
5. 用户确认后，再进入成片、剪辑或交给 GPT 生成。

## 音乐硬规则

不要让 GPT 生成音乐。

背景音乐只能使用：

- 以前本地视频中已经验证过舒服的音乐；
- 用户明确提供并确认的音乐；
- 已知质量稳定的免版权音乐，并经过人工试听确认。

GPT 只能写音乐风格和使用规则，例如：

```text
背景音乐：使用已经验证过舒服的轻快背景音乐，音量压低，不抢旁白；不要生成新音乐。
```

禁止写：

```text
生成一段轻快背景音乐。
让AI生成免版权音乐。
```

## 10秒推荐结构

| 时间 | 任务 |
|---|---|
| 0-2秒 | 强钩子：反差、痛点、注意力 |
| 2-6秒 | 证明：学习、辅导、办公、创作等场景 |
| 6-8秒 | 价值：免费资料、免费教学、3000元价值感 |
| 8-10秒 | 行动：留言“AI学习” |

## 免费AI资料宣传的首选文案

```text
不是AI取代人，
是会用AI的人，正在超过不会用的人。
孩子学习、家长辅导、工作创作，
AI学习资料加免费教学，
想要资料，留言：AI学习。
```

## 验收标准

- 10秒结构清楚。
- 前2秒有钩子。
- 不是动画重绘，保持真实素材感。
- 音乐规则明确：不生成音乐。
- 有旁白、字幕、画面描述、剪辑节奏。
- 平台风险已提示：抖音/视频号不得露电话、微信、二维码等导流信息。
