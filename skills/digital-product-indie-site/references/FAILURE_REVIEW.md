# Failure Review

Use this file when a future run drifts from the intended product type.

## Known Failure Modes

- Building only a homepage or marketing shell without product pages.
- Treating an AI image tool, PDF chat tool, company registration site, or generic SaaS dashboard as the target.
- Adding checkout without automatic delivery.
- Forgetting license, refund, file format, and delivery terms.
- Omitting seller-side order records.
