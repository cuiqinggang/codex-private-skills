# AI Company Knowledge OS Integration

Current main project:

AI Company Knowledge OS / Obsidian AI company operating system.

Core goal:

Integrate knowledge bases, projects, old assets, Codex skills, clickable acceptance pages, visual evidence, and stage gates into a personal AI company operating system.

This skill package helps by:

1. Giving Codex a routing rule for choosing the right plugin, skill, browser, local tool, or connector.
2. Turning the video's plugin ideas into an executable development loop.
3. Supporting Stage 3.2 and later work around clickable entries, dashboards, page restoration, browser validation, and visual proof.
4. Preventing blind plugin installation, blind networking, and blind writes.
5. Reinforcing the user's visual proof acceptance preference.

Recommended default route for current AI Company work:

Product Design -> Build Web Apps -> Browser validation -> Visual Proof Acceptance -> deployment report.

External services such as Figma, Supabase, Vercel, and GitHub should remain candidate capabilities until the user gives a concrete task and authorization.
