# Codex App Plugin Workflow Orchestrator

This skill package preserves a Chinese video lesson about Codex App development plugins as a reusable workflow for the user's long-term Codex system.

The video's useful lesson is the closed loop:

Idea or requirement -> product design -> design/prototype input -> web or app build -> browser validation -> data/backend planning -> deployment -> GitHub collaboration -> visual proof.

This package deliberately avoids blind plugin installation. It records routing rules, safety checks, and visual acceptance requirements so future Codex tasks can decide which capability is appropriate before using or requesting a connector.

Primary user context:

- AI Company Knowledge OS
- Obsidian AI company operating system
- Codex Desktop long-term skill system
- clickable acceptance pages and visual proof
