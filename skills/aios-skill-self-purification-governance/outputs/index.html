Red Lines

  • Never unattended auto-merge formal skills.
  • Never auto-delete user hard rules.
  • Never auto-delete failure reviews.
  • Never auto-modify high-risk system operation rules.
  • Never auto-expand total-control trigger scope.
  • Never generalize project-local rules into global rules.
  • Never overwrite formal files just because a score improved.
  • Formal merges require user or GPT Gate Review.
  • All long maintenance tasks must pass runtime gate.
  • Insufficient elapsed_minutes forbids PASS.
