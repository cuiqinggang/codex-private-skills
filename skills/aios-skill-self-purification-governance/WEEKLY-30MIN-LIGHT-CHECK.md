# Weekly 30min Light Check

Minimum runtime: 30 minutes.

Checkpoint requirement:

- start checkpoint,
- 15min checkpoint,
- final checkpoint.

Scope:

- recent skills,
- new skills,
- modified skills,
- frequently-used skills,
- duplicate triggers,
- conflicting instructions,
- missing acceptance pages,
- high-risk automation wording,
- rejected-edit buffer updates.

Allowed outputs:

- issue list,
- risk list,
- candidate patch buffer,
- rejected edit buffer,
- review page,
- runtime evidence.

Forbidden:

- applying patches to formal skill files,
- deleting user hard rules,
- deleting failure reviews,
- broadening total-control triggers,
- converting local project rules into global rules,
- marking PASS without runtime evidence.
