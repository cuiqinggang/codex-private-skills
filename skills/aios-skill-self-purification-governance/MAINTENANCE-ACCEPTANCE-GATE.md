# Maintenance Acceptance Gate

Policy install acceptance:

- fixed maintenance policy exists,
- maintenance calendar exists,
- weekly 30min command exists,
- monthly 2h command exists,
- quarterly 4h command exists,
- post-project 30min command exists,
- runtime gate exists,
- acceptance gate exists,
- dashboard exists,
- manifest exists,
- auto-merge is forbidden,
- formal business skills are not modified,
- no actual 30min, 2h, or 4h maintenance run is started by this install.

Run acceptance:

- runtime gate passes,
- checkpoint evidence exists,
- reviewed scope is documented,
- candidate patches are separated from formal files,
- accepted, rejected, and needs-human-review items are separated,
- red lines are respected,
- dashboard or review page is written.
