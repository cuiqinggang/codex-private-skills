# Quarterly 4h Graph Governance

Minimum runtime: 240 minutes.

Checkpoint requirement:

- at least 16 checkpoints,
- final checkpoint must exist,
- checkpoint timeline must be written.

Scope:

- build skill relation graph,
- find duplicate skills,
- find trigger conflicts,
- find stale or orphan skills,
- identify total-control trigger expansion risk,
- produce merge suggestions,
- produce do-not-merge list,
- produce human-review queue,
- produce offline HTML review page.

The quarterly run is for medium-scale global scan and graph governance. It is not a frequent cleanup routine and it is not an automatic merge process.

Forbidden:

- direct formal merge,
- automatic deletion,
- hard-rule rewrite,
- globalizing local project rules,
- PASS without 240 minutes and sufficient checkpoints.
