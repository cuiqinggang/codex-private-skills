# 《Windows执行桥》第15版

## 使用已配置的入口

Windows 登录后由原开机任务接续固定入口 **Windows D 20261110-02**。用户发起 Windows 任务时优先直接使用这个入口，并复用该入口返回的工作区。通过各入口已有的正常授权流程访问用户指定的设备和工作区。具体文件、命令和写入操作均受当前任务授权和工具权限约束。

| 顺序 | 已配置入口 |
| --- | --- |
| D | Windows D 20261110-02 |
| A | Remote Desktop Commander |
| B | GPT-Windows-MCP-Bridge |
| C | GitHub Actions 的既有 Windows 自托管 Runner |

D 超过 3 秒未返回时记为软超时。仅在有必要时做一次只读复验。确认连接故障或入口不可用后，按 A、B、C 顺序检查已配置的入口，首个通过只读验证的入口用于接续。命令执行中的错误按业务错误处理。授权、范围或工具安全校验明确拒绝时，保留回执并停止该操作，由用户通过原入口处理。禁止为完成同一操作换通道规避拒绝。

已经受理或结果未知的写入、启动或提交先只读核对状态。确认未执行后，才在原授权范围内从未完成处接续。

## 开机后验收

1. 用户登录后发来验收提示，直接用固定 D 打开既有探针工作区 `C:/AI/DevSpace-Benchmark-20261031/fixture`，读取 `channel-probe.txt`，运行只读命令 `hostname.exe`。
2. 首次探测读到 `D_CHANNEL_PROBE_R6_OK`、`DESKTOP-4A1EGTM` 和退出码 `0`，并且全程无需手工重连、重新授权或启动服务，即登记自动接续通过。
3. 用户要求验收某次整机重启时，另核对 Windows 启动时间和内核启动事件。用户明确要求先取调用前证据时，先记录该证据，再开始探测。

## 现有自动恢复与提醒

保留 V14 已部署的登录任务、每两分钟健康检查、ngrok 自动重连和持续故障声音提醒。连接排查先读健康记录和任务回执。此技能的日常流程只使用既有入口，任何认证、权限、计划任务、系统或网络配置的变更都由相应的管理流程处理。
