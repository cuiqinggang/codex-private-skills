# 《GPT直连Windows双路执行桥 V11.0》——C 优先强制门禁（正式版）
版本：11.0；发布日期：2026-10-19
继承：V10.0 动态发现 + V10.1 判定程序；后向保留历史文件，不改变代理/隧道配置。

## 唯一正式执行顺序
1. 每个 Windows 任务从 C（Remote Desktop Commander）list_devices 动态发现目标电脑的在线 ID，禁止沿用旧离线 ID。
2. C ping + 无副作用 PowerShell 真实探针均成功则 LOCK_C。此时必须由 C 执行，不得选择 A 或 B。
3. C 检查失败时重新 list_devices 后限一次有界复验。UNKNOWN、旧 ID 离线、单次超时、命令业务失败不得冒充 C 不可用。
4. 切换 A 前，执行端必须经过 guard_route.py 门禁；仅在两次明确失败、有可核验故障证据、且处在无未决副作用的安全检查点时允许。A 明确失败有证据才允许 B。
5. 每个任务重新验证，不继承上次降级许可；审计 task_id、设备、时间、探针、失败证据、路由结果。Exactly-once：有 UNKNOWN 执行结果先对账，不重复副作用操作。
6. 不修改 FlClash、网络代理、虚拟网卡、密钥、隧道，不中断用户工作浏览器。

## 实现入口
- SKILL.md：正式入口指向本文件。
- guard_route.py：可执行的降级决策门禁，拒绝码 3；允许码 0。所有受控 A/B 包装器必须先调用门禁。
- V10.0、V10.1 文件保留用于审计历史。
- 仅有规则和门禁代码不能强制拦截 ChatGPT 原生 MCP 直连 A：需在每个外部执行入口接入并完成跨会话回归才可声称全局强制拦截已经完成。
