# GPT直连Windows双路执行桥 V9.0 — 确定性路由规范
版本：9.0；修订日期：2026-10-16；继承 V8.0 的既有能力与安全约束，不更改代理、FlClash、网络、密钥与现有隧道。
## 唯一优先级
C > A > B。C 是固定首选，A 是第一备用，B 是第二备用。
每个新任务必须先探测并优先调用 C；C 的实际命令执行成功即锁定 C，绝不为便利、习惯、速度猜测或历史原因选择 A/B。
只有 C 出现明确的连接或业务执行失败，并且一次有界快速重试仍失败，才允许切换 A；只有 C、A 均有明确失败证据，才允许使用 B。
不能把旧设备 ID 离线、单次超时、网页标记、上一任务选择 A 等同于当前 C 故障。判定以当前 C 的真实业务命令回执为准。
## 确定性决策
1. 新任务：CHECK_C -> C_PASS 则 EXECUTE_C；其余通道不得调用。
2. C_FAIL：RETRY_C_ONCE -> C_PASS 则 EXECUTE_C；连续失败才 CHECK_A。
3. A_PASS -> EXECUTE_A；A_FAIL -> CHECK_B；B_PASS -> EXECUTE_B；全部失败 -> STOP_AND_REPORT。
4. 切换时记录任务 ID、检测时间、通道、命令回执、失败原因、切换依据；不可无证据降级。
5. 后续新任务重新从 C 开始，不将上一次故障降级永久化。进行中的任务仅在安全检查点切换，保持 exactly-once，避免重跑副作用。
## 绝对安全边界
不得关闭已登录专用浏览器；不得更改、关闭或重启 FlClash、Windows 系统代理、虚拟网卡或网络配置；不得擅自删除文件/密钥或重建隧道。
## 验收
静态规则审核不能代替运行验证。需用同一真实命令验证 C 优先、C 失败才转 A、A 失败才转 B、C 恢复后新任务回 C；不得故意断开用户网络代理。
## 定位
本文件是 V9.0 的独立路由规则冻结记录；原 V8.0 技能正文定位尚待核对，因此不声称原文件已同步，也不声称执行器已自动强制应用此规则。
