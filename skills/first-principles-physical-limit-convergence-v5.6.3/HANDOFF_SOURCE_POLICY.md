# 现实交接来源规则（Shared-Source First）

本文件是维护/交接规则，不修改 v5.6.3 已认证运行逻辑，不改变版本号。

## 唯一规则

现实交接包必须显式写清三件事：

1. **权威仓库**
2. **固定提交**
3. **冻结入口路径**

只要这三项齐全，Codex 必须直接读取该网络共同工作区，不得先扫描 C 盘猜测正式来源。

## 来源优先级

```text
网络共同私库固定提交 + 冻结入口
→ 唯一权威来源

本地 C:\... 工作区
→ 仅现实执行/落地目录
→ 不是正式源
→ 不得用于判断“有没有技能包/冻结包”
```

## 正式命令包最小必填

```text
REPO=<共同私库>
COMMIT=<固定提交>
ENGINE_PATH=<引擎冻结路径>
TASK_PATH=<本次现实交接入口>
LOCAL_WORKSPACE=<仅执行落地点，可选>
```

缺任一 `REPO / COMMIT / ENGINE_PATH / TASK_PATH`：

```text
交接包不完整
→ 不允许让Codex自由搜索本机替代
→ 回报缺失字段
```

## 防复发

以后生成现实 Codex 命令时，若正式来源位于共同私库，必须直接写出上述四项。
不得只写“读取 v5.6.3”或只写本地工作区名称。
