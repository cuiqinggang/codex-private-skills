# v4.6.1 验收

```text
METHOD_STEPS=2
STEP_1=VIRTUAL
STEP_2=REAL
THIRD_STEP=NONE

OBJECTIVE=T*=min(T_VALID_RUN)

VIRTUAL_REAL_PREEXECUTION_GATE=REQUIRED_WHEN_FEASIBLE

IF GPT_CAN_REAL_PREEXECUTE_CRITICAL_PUBLIC_SUBPATH:
  MUST_PREEXECUTE=YES
  EVIDENCE_REQUIRED=YES
  PREEXEC_PASS_REQUIRED_BEFORE_FREEZE=YES

IF GPT_CANNOT_EQUIVALENTLY_PREEXECUTE_ENVIRONMENT_SPECIFIC_REMAINDER:
  MARK=UNEXECUTABLE_BY_GPT
  LEAVE_ONLY_THAT_REMAINDER_FOR_REAL

PREEXEC_FAIL:
  ACTION=FIX_OR_SWITCH_OR_BLOCK_IN_VIRTUAL
  CODEX_RELEASE=BLOCK

REAL_FAIL:
  ACTION=MINIMAL_REALITY_DELTA -> STOP -> RETURN_TO_VIRTUAL
  TIMER_RESET=NO
```

Acceptance meaning:

- “虚拟成熟”不再允许只凭推理判断关键公开路径可行；
- 能由 GPT 当前现实工具实际做的部分必须先做成功；
- 证据进入冻结包；
- 不能等价预跑的本机差异仍由 Codex REAL 认证；
- 预跑只在预期降低完整闭环 T_VALID_RUN 时执行，不扩张成无价值测试工程。
