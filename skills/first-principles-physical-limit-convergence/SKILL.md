# 极限短时间引擎 v4.3.0

## 唯一核心

```text
T_VALID = 从任务开始到第一个现实有效结果出现的端到端时间
T* = min(T_VALID)
```

所有判断只用一条规则：

```text
先过有效硬门，再只比较 T_VALID。
```

不能保证有效、缩短时间或减少未来重复失败/测量的内容，删除。
与 T_VALID 的关系不清楚，不得冻结为最优。

## 一虚一实

标签只允许：

```text
【页面名｜任务名｜序号｜虚】
【页面名｜任务名｜序号｜实】
```

### 虚

只做：从现实底座和动态成熟方案中，冻结当前预测 T_VALID 最短的有效方案。

完成必须有：

```text
有效门=通过
预测T_VALID=有
冻结方案=有
```

### 实

只做：按冻结方案执行，量出真实有效性和真实 T_VALID。

完成必须有：

```text
有效=通过
现实T_VALID=有
```

失败只允许：

```text
最小现实差异 -> 停止 -> 回虚
```

执行器不得现场改方案。

## 其他能力

现实底座、数字孪生、成熟方案池、验证器、缓存、GPU、JEV、自动化都不是新步骤；只有能保证有效或降低总 T_VALID 才保留。

JEV 在 v4 成熟冻结前必须完成自身成熟，具体节点仍只在总 T_VALID 更短时使用。

现实底座只吸收以后能缩短 T_VALID 或避免重复失败/测量的最小事实。

## 收口

```text
虚无预测时间 -> 未完成
实无现实时间 -> 未完成
答不出当前现实最短有效时间 -> 任务未收口
```

没有第三步；一步自动化等“一虚一实”现实成熟后再接现有自动化技能。
