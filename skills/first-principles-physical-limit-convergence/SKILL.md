# 极限短时间引擎 v4.4.1

## 根基：现实底座

```text
本地 AI 现实底座永久资产
local-ai-reality-foundation
当前版本=v1.1.0
```

它不是第三步，而是“虚/实”共同的现实根基。

虚开始前必须读取与任务有关的最小充分现实；缺少会影响有效性或 T_VALID 的关键现实事实时，虚未完成。

实结束后必须做现实底座吸收检查：只有能缩短未来 T_VALID 或避免重复失败/重复测量的新现实事实才吸收，否则不吸收、不升版。

## 唯一锚定物

```text
T_VALID = 从任务开始到第一个现实有效结果出现的端到端时间
T* = min(T_VALID)
```

所有规则都服从：

```text
先过有效硬门，再只比较 T_VALID。
```

不能保证有效、缩短当前或未来 T_VALID、或避免重复失败/重复测量的内容，删除。

## 虚

```text
【页面名｜任务名｜序号｜虚】
```

基于现实底座，冻结当前预测 T_VALID 最短的有效方案。

完成必须有：

```text
现实底座=足够
有效门=通过
预测T_VALID=有
冻结方案=有
```

## 实

```text
【页面名｜任务名｜序号｜实】
```

严格执行冻结方案，量出真实有效性和真实 T_VALID。

完成必须有：

```text
有效=通过
现实T_VALID=有
现实底座吸收检查=完成
```

失败只允许：

```text
最小现实差异 -> 停止 -> 回虚
```

执行器不得现场改变冻结方案。

## 收口

```text
虚无现实根基/预测时间/冻结方案 -> 未完成
实无现实有效结果/现实时间 -> 未完成
答不出当前现实最短有效时间 -> 未收口
```

只有“虚/实”，无第三步。
