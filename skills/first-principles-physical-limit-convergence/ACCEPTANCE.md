# Acceptance — first-principles-physical-limit-convergence v3.1.0

## 唯一验收

当前方法只允许三个核心：

```text
CORE_1 = 极限短时间
CORE_2 = 成熟方案集群
CORE_3 = 高智能虚拟成熟
```

必须满足：

```text
CORE_COUNT=3
CORE_4_EXISTS=NO
THREE_CORE_WHITELIST=PASS
```

## 下一步白名单

任何下一步必须明确标注：

```text
CORE=1
或
CORE=2
或
CORE=3
```

不能直接映射：

```text
BLACKLIST=YES
EXECUTE=NO
```

## 历史规则

旧版本、旧 command pack、L0/L1/L2/L3/L4、Shadow Pilot、Assisted Pilot 等：

```text
HISTORICAL_REFERENCE=ALLOWED
CURRENT_METHOD_AUTHORITY=NO
```

它们只有在内容被重新映射到三核心后，才可以作为当前方案的一部分。

## 顺序

```text
1 极限短时间
-> 2 成熟方案集群
-> 3 高智能虚拟成熟
```

现实实现与案例验证属于第 3 核心冻结方案的验证动作，不建立第四层。

## 失败

现实验证失败：

```text
REALITY_DELTA
-> RETURN_TO CORE_3
-> RE-MATURE
-> RE-FREEZE
-> RE-VERIFY
```

不得现场产生新的方法路线。
