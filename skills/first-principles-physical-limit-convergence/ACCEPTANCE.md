## 自动执行控制层

自动控制面已经成为母技能的可选执行层，但当前仍处于验证期：

```text
AUTOMATION_CONTROL_PLANE_SPEC=PASS
AUTOMATION_ARCHITECTURE=CODEX_FIRST_NUMBERED_GITHUB_BUS
CODEX_PLAN_AUTHORITY=NONE
CODEX_NO_FREE_EXPLORATION=PASS_BY_DESIGN
AUTOMATION_MATURITY=L0_SPEC_READY
CODEX_FIRST_SHADOW_PILOT=NOT_YET_EXECUTED
ASSISTED_REAL_TASK_PILOT=NOT_YET_EXECUTED
MULTI_SCENARIO_REGRESSION=NOT_YET_EXECUTED
AUTOMATION_MODULE_MATURE_REUSABLE=NO
```

成熟度必须严格按：

```text
L0 SPEC_READY
-> L1 SHADOW_PILOT_PASS
-> L2 ASSISTED_REAL_TASK_PASS
-> L3 MULTI_SCENARIO_REGRESSION_PASS
-> L4 MATURE_REUSABLE
```

禁止跳级。

只有达到 `L4 MATURE_REUSABLE` 后，其他技能包才允许把自动控制面作为成熟依赖直接唤醒。

L4 前，自动化只允许用于它自己的验证任务，不得因“设计看起来正确”就宣告成熟无人值守。

自动化验证还必须证明：

```text
MANUAL_COPY_PASTE_REQUIRED=NO
GPT_RETAINS_PLAN_AUTHORITY=YES
CODEX_PLAN_AUTHORITY=NONE
CODEX_ONLY_HAS_BOUNDED_EXECUTION_FLEXIBILITY=YES
NO_LOCAL_REPLAY=YES
GITHUB_REMOTE_TRUTH=YES
CHECKPOINT_RESUME=YES
UNKNOWN_OUT_OF_CONTRACT=BLOCKED_OR_RETURN_TO_GPT
```
