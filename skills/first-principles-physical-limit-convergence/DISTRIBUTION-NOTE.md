# Distribution Note — v3.1.5

v3.1.5 不增加第四核心、不增加第四步骤。

它只给 v3.1.4 的任务定位门禁补上一个关键约束：

> 每一条正式执行命令都必须在定位标签最后明确写出它真实属于三个核心中的哪一个，而且必须使用中文核心名。

唯一可见格式：

```text
【实际页面名｜具体任务名｜序号｜核心归属】
```

第四字段只允许：

```text
极限短时间
成熟方案集群
高智能虚拟成熟
```

原前三个字段含义不变：

```text
在哪个页面
页面里的哪个任务
这个任务的第几条 GPT 正式命令
```

新增第四字段只回答：

```text
这条命令真实属于三个核心中的哪一个
```

如果无法唯一归属，GPT 不得发布。
如果一条命令跨多个核心，GPT 必须先拆分。
如果标签和正文实际任务不一致，接收端必须阻断。

v3.1.5 同时取消 v3.1.4 中“4..6 修复窗口”的语义。

序号现在只有一个意义：

```text
顺序计数
```

Codex / Reasonix / 本地执行器只有冻结命令执行权。

现实失败时：

```text
记录现实差异
-> STOP
-> 返回 GPT 页面
```

禁止：

```text
Codex 自己建立修复任务
Codex 自己决定修复
Codex 自己重新设计
Codex 自己找另一条路线
```

修正、重新虚拟成熟、重新冻结都属于 GPT 页面。

正式分支：

`codex/first-principles-physical-limit-convergence-v3.1.5`
