# Distribution Note — v3.1.0

v3.1 只修一个问题：防止实际执行偏离已经明确的三核心。

不再增加执行层、Schema、Gate、成熟度阶梯或第四套规则。

唯一白名单：

```text
1. 极限短时间
2. 成熟方案集群
3. 高智能虚拟成熟
```

任何当前动作必须直接映射到其中一个；否则：

```text
BLACKLIST
DO_NOT_EXECUTE
```

历史资料、旧流程、L0/L1/L2/L3/L4 等可以保留和引用，但没有当前方法权。
