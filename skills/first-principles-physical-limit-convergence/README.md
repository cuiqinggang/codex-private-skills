# 第一性原理极限短时间引擎 v3.1.4

## 只保留三个核心

```text
1. 极限短时间
2. 成熟方案集群
3. 高智能虚拟成熟
```

这三个就是唯一白名单。任何方案、流程、规则、状态、旧方法或下一步，只要不能直接映射到 1/2/3，就是黑名单。

## 唯一流程

```text
1 极限短时间
-> 2 成熟方案集群
-> 3 高智能虚拟成熟
```

第 3 核心完成成熟方案组合、虚拟推演、冻结最终方案，并按冻结方案进行现实实现与案例验证。

## v3.1.4 任务定位

每个正式任务使用一行定位标签：

```text
【定位｜页=P01·中文页面名｜任务=T01·中文任务名｜序=001｜STEP=2·虚拟成熟｜CORE=3·高智能虚拟成熟｜ROLE=ORDER·命令｜状态=OPEN·已下发】
```

ORDER 与 ANSWER 通过 `页 + 任务 + 序 + STEP + CORE` 精确配对。正常目标 3 次内闭环；第 3 次未完成先记录原因，最多到第 6 次；第 6 次仍未闭环则停止并重新建立任务，不允许无限编号。
