# 第一性原理极限短时间引擎 v4.1.0

## 一句话

```text
虚：把方案做到成熟、做到预测最短并冻结
实：按冻结方案在物理现实里证明
```

失败：

```text
实 -> Reality Delta -> STOP -> 虚
```

唯一锚定：

```text
T*=min(T_VALID)
```

## 正式标签

```text
【页面名｜任务名｜序号｜虚】
【页面名｜任务名｜序号｜实】
```

第四字段只有一个字。

## v4.1 比 v4.0 新增什么

1. “虚/实”替代长阶段名；
2. 每个任务结束强制做 Reality Foundation 吸收检查；
3. Foundation 变成版本化、自包含、历史不覆盖的现实资产；
4. 动态成熟方案池明确不把旧赢家永久化；
5. 一步自动化明确延后；
6. 未来不重造自动化，优先适配现有 `gpt-codex-convergence-orchestrator@1.5.2`。

## 当前不做的事

不把两步强行自动化。
先用真实任务把“虚↔实”跑成熟，再升级。

`codex/first-principles-physical-limit-convergence-v4.1.0`
