## v3 顶层统一解释

v3 将历史能力统一到三个核心：

```text
极限短时间
-> 成熟方案集群
-> 高智能虚拟成熟
```

历史中所有 KEEP/ROLLBACK、T_PHY、T_MACHINE_STAR、Failure Index、随机交付、T_TFVR、自动控制面、Shared Fact Source、99/FREEZE 等，继续保留；它们现在都作为上述三条核心的实现细节或证据。

## v3 EVOLUTION

v3 不再把大量实现规则放在最高层，而只保留：

1. **极限短时间**：唯一优化指标；
2. **成熟方案集群**：先吸收现实已有完整解，覆盖完整时禁止重新发明；
3. **高智能虚拟成熟**：搜索、组合、排错优先在虚拟层完成，现实主要负责标定与认证。

操作流程变为：

```text
Gate 0 Mature Solution Cluster
-> VALID / resource boundary / T_PHY_VALID
-> minimal real calibration
-> GPT Virtual-99
-> deterministic real certification
```

## 历史映射继续有效

- `INDEPENDENT_99_PATH` -> 仅在成熟方案集群存在明确未解决 primitive 时开启。
