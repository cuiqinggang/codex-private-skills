## STEP 1 — TASK + SINGLE PHYSICAL LIMIT + MRE

1. 冻结 `TASK_CONTRACT / TASK_COMPLETED / CORRECTNESS / QUALITY / STABILITY / SAFETY / TIMING_BOUNDARY`。
2. 冻结 `ACTIVE_HARDWARE_BOUNDARY`：只包含当前真实安装、可用、允许用于本任务的硬件。
3. 继承远端共同事实中的可比历史证据；禁止从零重复探索。
4. 建立物理因果链和不可避免工作量。
5. **只发布一个正式物理极限标准**：

```text
T_PHY_TOTAL_REFERENCE=<一个端到端时间数字或区间>
```

Generation、Path、I/O、load、decode 等分量只能留在内部计算底稿，不得作为并列正式“物理极限板”。
6. 对复杂系统做一次预定义结束条件的 `MRE`，得到真实运行态。
7. 建立：

```text

+ STATIC_FACTS
+ MRE_OBSERVATIONS
+ EMPIRICAL_PRIORS
= REAL_STATE_MODEL
```

MRE 完成后停止并返回 GPT；不得自动进入下一实验。
