# v4.7.1 虚→实原子发布门回归测试

## 目的
防止“虚已经成熟，但没有发布 Codex 现实验收命令”的悬空状态再次出现。

## 必须 PASS 的状态转换
1. VIRTUAL_ACTIVE
2. 冻结门全部 PASS
3. 分配 NEXT_SEQUENCE
4. 生成【页面名｜任务名｜序号｜实】
5. 生成自包含 Codex 现实验收命令
6. 发布/自动发送现实命令
7. REAL_COMMAND_EMITTED=YES
8. 仅此时允许 VIRTUAL_COMPLETE=YES / CURRENT_PHASE=REAL

## 必须 BLOCK 的反例
- 冻结门 PASS，但只回复“虚完成”；
- HANDOFF_READY=PASS，但没有命令正文；
- 已生成命令草稿，但没有分配序号；
- CURRENT_PHASE=REAL，但 REAL_COMMAND_EMITTED!=YES；
- Reality FAIL 回虚后沿用旧现实命令而不递增序号。

任一反例出现：
VIRTUAL_COMPLETE=NO
CURRENT_PHASE=VIRTUAL
TRANSITION_BLOCKED=HANDOFF_NOT_EMITTED

## Reality FAIL
同一 TASK_TIME_ID；累计时间不清零；NEXT_SEQUENCE=LAST_VALID_EMITTED_SEQUENCE+1；重新冻结后同一轮再次触发原子发布门。

## 验收
VIRTUAL_COMPLETE_IMPLIES_REAL_COMMAND_EMITTED=TRUE
REAL_PHASE_IMPLIES_REAL_COMMAND_EXISTS=TRUE
HANDOFF_READY_WITHOUT_COMMAND=INVALID
FREEZE_PASS_WITHOUT_SEQUENCE=INVALID
REAL_FAIL_DOES_NOT_RESET_TASK_TIME_ID=TRUE
REAL_FAIL_DOES_NOT_RESET_SEQUENCE=TRUE
