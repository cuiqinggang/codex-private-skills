# 版本变化

## v4.6.1
- 新增“虚内现实预跑证据门”：能由 GPT 当前现实能力低成本执行的关键公开子路径，冻结前必须实际跑通并形成证据。
- 预跑仍属于 VIRTUAL 内部动作，不新增第三步。
- GPT 无法等价复现的本机/账号/GPU/登录态/Windows执行上下文差异必须显式标记，只把这部分剩余风险交给 REAL。
- 预跑失败必须在虚中修正、换成熟路径或 BLOCK；禁止把同一条未经证明的路径直接发布给 Codex 反复试错。
- 唯一优化目标不变：T*=min(T_VALID_RUN)。
