# 候选准入、许可证与安全边界

候选最低证据：原始 HTTPS 来源、最近维护日期或稳定版本、用途、真实示例、依赖和许可证。Star、点赞、聚合站描述和二手视频只能用于发现，不能作为采用证据。

## 许可证

- `VERIFIED`：已在原仓库或官方发布物确认；只有 `reuse_allowed=true` 才可复制兼容代码，并保存来源与通知。
- `NO_COPY`：来源可读但不允许复制；只学习方法并独立实现。
- `UNKNOWN`：没有可核验许可证；不得复制代码或原文，默认 `DEFER` 或 `REJECT`。

许可证不确定时不做法律结论，转人工复核。SPDX 标识用于机器记录，但不能替代阅读许可证正文和项目级例外。

## 安全与适配

检查 API/付费服务、凭据、遥测、网络写入、安装器、递归删除、提权、注册表/服务/计划任务、Docker/WSL 和未锁定依赖。不得为对标执行未经审查的外部脚本。Windows/Codex 不适配时，可以吸收无依赖方法，但不得把不适配链路设为默认。

外部能力与本地高度重复且无重要指标提升时 `KEEP_LOCAL` 或 `REJECT`。连续搜索没有新证据、候选均为包装站、许可证未知、或无法构造同任务对标时停止并 `DEFER`，不得为数量强行吸收。
