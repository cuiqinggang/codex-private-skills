# 漂亮女孩激情热舞｜图片-音乐滚动预测法 2.0

## 状态
- VERSION=2.0
- STATE=FROZEN
- MODE=VIRTUAL_MATURITY
- 主线唯一：严格逐图滚动预测
- 禁止：抽帧、跳帧、扩大步长、按秒预测、阶段性改规则、用生成帧替代真实揭晓帧

## 唯一预测循环
1. 输入当前真实图片 F_n。
2. 绑定 F_n→F_(n+1) 时间区间内的真实音乐片段 M_n。
3. 使用此前已从真实揭晓中学到的规律，预测下一张 P_(n+1)。
4. 立即揭晓真实 F_(n+1)。
5. 计算 FRAME_PREDICTION_ERROR，并更新规律。
6. 下一轮必须以真实 F_(n+1) 为输入，禁止使用 P_(n+1) 继续滚动。
7. 有多少真实帧就连续做多少步，直到素材末端。

公式：
```
当前真实图片 F_n
+ 严格对应音乐 M_n
+ 历史已学规律 R_n
→ 预测 P_(n+1)
→ 揭晓真实 F_(n+1)
→ 更新 R_(n+1)
```

## 判定规则
- 有效：随着真实揭晓次数增加，预测误差形成可重复的下降/收敛趋势，并优于最简单的一帧保持基线。
- 音乐有效：在同一图像预测结构下，加入严格对应音乐后必须稳定优于不加音乐。
- 无效：误差不下降、长期不收敛、或不能优于一帧保持基线。
- 0.01% 仅作为“允许测试简化”的门槛，不作为为了保住方法而增加模块的理由。
- 若判无效：直接冻结失败，不增加抽帧、多步、状态机、复杂动作标签等结构救场。
