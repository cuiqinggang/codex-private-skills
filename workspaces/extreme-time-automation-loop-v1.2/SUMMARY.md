# 极限短时间自动化闭环 v1.2｜历史摘要

```ini
STATUS=SUPERSEDED
SUPERSEDED_BY=极限短时间自动化闭环 v2.0
```

v1.2 的有效贡献：
- 单一端到端 `T*=min(T_VALID)`；
- Reality Contract 先于架构；
- 成熟完整方案优先；
- 自有 Skill / 状态机 / GPT+Codex+n8n+GitHub 无优先权；
- `CHANGE_SCOPE=ROOT_CAUSE_SCOPE`。

被 v2.0 替代的关键原因：
- v1.2 仍保留“成熟方案不足时可新增实现/自研”的出口；
- v2.0 删除该出口，并将 `MATURE_SOLUTION_EXISTS=TRUE` 作为当前任务域固定前提；
- v2.0 采用成熟方案后继续攻击对完整 T_VALID 有明确收益的瓶颈。
