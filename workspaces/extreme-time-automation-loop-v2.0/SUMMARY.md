## 当前正式目标

`T_VALID` 是从系统已经拥有足够信息开始现实推进，到成熟结果完成并通过最终验收的全部现实时间。

v2.0 是极限效率方法，不是固定架构模板。

## 当前主路线候选

```text
用户目标
→ GPT 高智能判断
→ 优先直接成熟工具
→ 必要时 Codex / Reasonix / Browser / GitHub runner / 其他执行器
→ 现实结果
→ 自动验证
→ FINAL_VALID
```

执行器不固定；只有对完整 T_VALID 有贡献的层才保留。
