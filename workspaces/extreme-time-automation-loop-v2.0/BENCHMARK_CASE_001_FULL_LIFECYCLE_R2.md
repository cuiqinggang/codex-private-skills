# 标准题 001 R2｜已完成适度复杂真实任务｜从需求到成熟版

## 测试目的

这道题不测“成熟成品运行一次的速度”，而测：从原始需求提出开始，到系统做出成熟版并完成最终现实验收，整个项目闭环需要多长时间。

## 测试输入

只向候选提供当初的原始用户需求、必要现实环境和权限边界。

测试期间隐藏：旧最终实现、旧修复过程、旧最终冻结结果、旧最终代码。

这些历史材料只在测试结束后由验收端用于判断候选是否真正达到成熟要求。

## 统一起点

T0：候选系统收到完整原始需求，并且拥有开始工作的必要权限与环境，不再等待普通补充信息的现实时间。

## 统一终点

T1：成熟版真实存在，最终用户流程现实通过，机器可验事实已经自动验收，普通人肉胶水已消除，项目达到 FINAL_VALID（最终有效）。

## 完整计时范围

需求理解 + 完成条件定义 + 成熟方案搜索 + 方案比较 + 选路 + 成熟能力组合 + 虚拟成熟 + 现实执行 + 等待 + 失败 + 根因分析 + 修正/换路 + 重试 + 最终验收 + 成熟完成。
