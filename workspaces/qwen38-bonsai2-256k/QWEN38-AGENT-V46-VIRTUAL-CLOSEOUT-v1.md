# 千问3.8 27B1 — v4.6 本地智能体能力边界｜虚拟成熟最终冻结 v1

## 唯一目标
建立本地智能体的能力边界图：找出稳定 PASS 区、失败/不稳定边界，并对所有 PASS 能力格唯一优化 min T_VALID。组合为 Bonsai 2 27B + JEV 概率判断加速器 + 自适应 Thinking + 独立确定性验证器；超出本地边界时升级 GPT。

## 路由冻结
- 明确确定任务 → 本地 27B，Thinking OFF。
- 有限、结构化、可验证判断 → 若预计端到端更快则 JEV。
- JEV 低置信/失败/不可用 → 回本地 27B；JEV 不是单点依赖。
- 轻微歧义 → LOW_512。
- 局部失败 → MEDIUM_2048。
- 多回执冲突 → HIGH_8192。
- HIGH 后仍无法安全收敛或需要重新设计 → STOP → GPT。

## 16 个 token 冲突修复
旧套件把 252-255K Prompt 与 HIGH_8192 直接叠加，16 个案例超过 262144。v4 保持 8K～245K 原 Prompt 档位；只有真实溢出案例改为最大上下文总预算：
Prompt + 工具定义 + Thinking + 输出保留 <= 262144。
原冲突=16；修复后超窗=0。
