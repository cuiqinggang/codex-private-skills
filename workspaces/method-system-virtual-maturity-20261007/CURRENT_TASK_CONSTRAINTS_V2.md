- 唯一标准：T*=min(T_VALID)，先进入 VALID 再比较完整时间。

- 只升级真正负责的版本，且只做最小必要修复。
- 修复后必须从 TASK_ACCEPTED 重新完整重跑。
- 首次完整贯通 FINAL_VALID 后，必须再从头完整复跑一次。
